CRITICAL

1. PHP ออกแพตช์ฉุกเฉิน PHP2Shell เสี่ยงรันโค้ดโดยไม่ต้องเข้าสู่ระบบ

PHP2ShellCVE-2026-109618CVE-2026-109619

PHP เผยแพร่แพตช์วันที่ 21 ต.ค. แก้ช่องโหว่ร้ายแรงสองรายการที่อาจนำไปสู่การรันโค้ดจากระยะไกลโดยไม่ต้องยืนยันตัวตน ผู้ดูแลต้องอัปเดตตัว PHP ที่ใช้งานจริง ไม่ใช่เพียงอัปเดต CMS หรือปลั๊กอิน

ประเด็น: PHP2Shellสถานะ: มีแพตช์ฉุกเฉินการดำเนินการ: อัปเดต PHP ที่ให้บริการเว็บ
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ทีม PHP ประกาศ CVE-2026-109618 และ CVE-2026-109619 เมื่อ 21 ต.ค. เกี่ยวข้องกับความเสียหายของสถานะภายในและหน่วยความจำระหว่างประมวลผลคำขอเว็บ ผู้ผลิตระบุความเสี่ยงต่อ PHP ที่ให้บริการคำขอเว็บ และความเสี่ยงสูงสุดใน mod_php ซึ่งมีการสาธิตเส้นทางโจมตีก่อนรันโค้ดแอปพลิเคชัน ข่าว Reuters รายงานคำยืนยันของ Amazon เรื่องความพยายามใช้ช่องโหว่ แต่ไม่ควรตีความว่าเว็บไซต์ทุกแห่งถูกเจาะแล้ว

ผลกระทบ

หากโจมตีสำเร็จ ผู้โจมตีอาจรันโค้ดในบริบทของบริการเว็บและเข้าถึงข้อมูลที่บริการนั้นมีสิทธิ์ การจำกัดเครือข่ายหรือปรับค่าบางรายการช่วยลดการเปิดรับความเสี่ยง แต่ผู้ผลิตระบุว่าไม่ใช่การแก้ไขที่สมบูรณ์

ข้อเสนอแนะ

อัปเดตเป็น PHP 8.5.12, 8.4.27, 8.3.36 หรือ 8.2.35 ตามสายรุ่น หรือแพ็กเกจที่ผู้ดูแลระบบปฏิบัติการยืนยันว่าแก้แล้ว ตรวจ PHP-FPM และ worker ทุกตัวให้ใช้รุ่นใหม่หลังเริ่มบริการใหม่ หากยังแก้ไม่ได้ให้จำกัดการเข้าถึงบริการที่เสี่ยง พร้อมตรวจ Log และไฟล์เปลี่ยนแปลงผิดปกติ

ประกาศ 21 ต.ค. 2569
แหล่งข้อมูล:PHP Security AdvisoryReuters — การรายงานความพยายามโจมตี
CRITICAL

2. GitLab แก้ CVE-2026-110264 ระดับ 10.0 กระทบระบบติดตั้งเองหลายรุ่น

GitLabCVE-2026-110264CVSS 10.0

GitLab ออก Critical Patch วันที่ 21 ต.ค. แก้ Integer Overflow ที่อาจทำให้ผู้โจมตีซึ่งไม่ได้เข้าสู่ระบบรันโค้ดบนเซิร์ฟเวอร์ได้ภายใต้เงื่อนไขบางประการ ต้องตรวจรุ่นที่ติดตั้งเองแม้เคยอัปเดตในรอบก่อนแล้ว

ประเด็น: GitLabสถานะ: ยังไม่พบหลักฐานโจมตีที่ยืนยันในข้อมูลที่ตรวจการดำเนินการ: อัปเดต GitLab ตามสายรุ่น
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

GitLab ระบุว่า CVE-2026-110264 เกิดระหว่างคอมไพล์ regular expression และให้คะแนน CVSS 10.0 กระทบ CE/EE ตั้งแต่รุ่น 7.0 ในช่วงรุ่นที่ระบุใน Advisory โดยมีการออกแพตช์ย้อนหลังนอกสายรุ่นมาตรฐานด้วย GitLab-managed infrastructure ได้รับแพตช์แล้ว ส่วนข้อมูลที่ตรวจรอบนี้ยังไม่มีหลักฐานยืนยันการใช้ช่องโหว่นี้โจมตีจริง

ผลกระทบ

การรันโค้ดบนระบบพัฒนาซอฟต์แวร์อาจกระทบซอร์สโค้ด ข้อมูลโครงการ และความลับที่ระบบเข้าถึงได้ การประเมินความเสียหายต่อ CI/CD เป็นความเสี่ยงที่ต้องตรวจตามสิทธิ์ของแต่ละระบบ ไม่ใช่ข้อยืนยันว่าโครงการถูกแก้ไขแล้ว

ข้อเสนอแนะ

ตรวจและอัปเดตเป็น 19.5.1, 19.4.3, 19.3.6, 19.2.9, 19.1.9, 19.0.10 หรือ 18.11.13 ตามสายรุ่นและแนวทางอัปเกรด ใช้กฎตรวจจับที่ GitLab เผยแพร่ตรวจ Log ย้อนหลัง วางแผนช่วงหยุดบริการและฐานข้อมูลก่อนอัปเกรด โดยเฉพาะระบบ single-node

ประกาศ 21 ต.ค. 2569

3. ติดตาม GlobalProtect CVE-2026-0257 หลัง Unit 42 อัปเดตคำแนะนำรับมือ Ransomware

PAN-OSCVE-2026-0257Active Exploitation

Unit 42 อัปเดตคำแนะนำวันที่ 20 ต.ค. หลังพบการใช้ช่องโหว่ GlobalProtect เพื่อเปิดทางเข้าระบบโดยกลุ่ม Ransomware เป็นข่าวติดตามช่องโหว่เดิม ไม่ใช่ช่องโหว่เพิ่งค้นพบวันนี้

ประเด็น: PAN-OSสถานะ: Unit 42 ยืนยันพบการใช้โจมตีการดำเนินการ: ตรวจแพตช์และ VPN Session
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Unit 42 ระบุการใช้ CVE-2026-0257 เพื่อข้ามการยืนยันตัวตนใน GlobalProtect และอัปเดตคำแนะนำตรวจสอบและแก้ไขวันที่ 20 ต.ค. เวลา 13:30 น. Pacific ซึ่งตรงกับ 21 ต.ค. เวลา 03:30 น. ไทย นักวิจัยระบุ Qilin และ INC ในกิจกรรมที่สังเกตพบ ส่วน Settra เป็นข้อมูลจากรายงานภายนอกที่ Unit 42 อ้างถึง

ผลกระทบ

ผู้โจมตีอาจตั้ง VPN Session และได้จุดเริ่มต้นเข้าสู่เครือข่ายองค์กร แม้มี MFA จึงต้องตรวจสถานะการใช้ช่องโหว่ควบคู่กับการตั้งค่าบัญชี การแพตช์ไม่ยืนยันว่ากิจกรรมบุกรุกที่เกิดก่อนหน้าได้ถูกกำจัดแล้ว

ข้อเสนอแนะ

ตรวจ PAN-OS และเงื่อนไขที่ได้รับผลกระทบตาม Advisory ผู้ผลิต แล้วอัปเกรดเป็นรุ่นแก้ไข ตรวจ GlobalProtect Log และ Session เทียบสิ่งบ่งชี้ที่ Unit 42 เผยแพร่ หากพบการเชื่อมต่อสำเร็จที่เกี่ยวข้อง ให้ใช้กระบวนการตอบสนองเหตุการณ์และตรวจระบบภายในต่อ

ข่าวติดตาม: อัปเดตต้นทาง 20 ต.ค. Pacific / 21 ต.ค. ไทย

4. Onamae Desktop Cloud ญี่ปุ่นหยุดบริการหลังพบโปรแกรมไม่พึงประสงค์

CloudJapanService Disruption

Onamae.com แจ้งการเข้าถึงโดยไม่ได้รับอนุญาตและติดตั้งโปรแกรมอันตรายในสภาพแวดล้อมลูกค้าบางส่วน พร้อมระบุเซิร์ฟเวอร์ที่อาจได้รับผลกระทบ 26,739 เครื่อง การหยุดบริการเป็นมาตรการควบคุมเหตุ ไม่ใช่หลักฐานว่าเครื่องทั้งหมดติดเชื้อ

ประเด็น: Cloudสถานะ: ผู้ให้บริการยืนยันการบุกรุกการดำเนินการ: ตรวจบัญชีและแผนความต่อเนื่อง

สถานการณ์

ประกาศวันที่ 21 ต.ค. เวลา 04:00 น. ญี่ปุ่นระบุว่าตรวจพบโปรแกรมที่ผู้บุกรุกติดตั้งเมื่อ 20 ต.ค. ผู้ให้บริการเริ่มหยุดเซิร์ฟเวอร์ตามลำดับตั้งแต่ 04:00 น. ของวันที่ 21 ต.ค. ครอบคลุม Desktop Cloud ทุกแผน และระบุจำนวนที่อาจได้รับผลกระทบ 26,739 เครื่อง รายละเอียดยังสอบสวนอยู่

ผลกระทบ

ลูกค้าอาจไม่สามารถใช้งานบริการระหว่างหยุดระบบ และข้อมูลในเซิร์ฟเวอร์อาจถูกเปิดดูได้ แต่ประกาศยังไม่ยืนยันการรั่วไหลครบทุกเครื่อง การหยุดระบบกระทบงานที่พึ่งพาเครื่องเสมือนและต้องประเมินความต่อเนื่องของภารกิจ

ข้อเสนอแนะ

ผู้ใช้บริการให้เปลี่ยนรหัสผ่านและข้อมูลรับรองที่เก็บหรือใช้งานในเซิร์ฟเวอร์ รวมถึงรหัสที่ใช้ซ้ำที่อื่น ติดตามประกาศฟื้นบริการและเตรียมสภาพแวดล้อมสำรอง ระวังข้อความหลอกลวงที่อ้างเหตุการณ์เพื่อขอรหัสผ่านหรือข้อมูลชำระเงิน

5. OVHcloud เตือน CLI บางไฟล์ถูกแทนด้วยมัลแวร์ขโมย Secrets

Supply ChainOVHcloud CLICredential Theft

ข่าวติดตามวันที่ 21 ต.ค. รายงานเหตุผู้โจมตีใช้บัญชีนักพัฒนาแทนไฟล์แจกจ่าย CLI ด้วยมัลแวร์ เหตุเกิดวันที่ 19 ต.ค. และประกาศต้นทางวันที่ 20 ต.ค. ขอบเขตจำกัดตามช่วงดาวน์โหลดและไฟล์ที่ได้รับผลกระทบ

ประเด็น: Supply Chainสถานะ: ผู้ผลิตยืนยันเหตุการดำเนินการ: ตรวจช่วงดาวน์โหลดและเพิกถอน Secrets
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

OVHcloud ยืนยันว่าบัญชีนักพัฒนาที่ถูกยึดถูกใช้แทน binary ของ CLI รุ่น 0.11.0–0.15.0 วันที่ 19 ต.ค. เวลา 14:47–16:21 น. UTC+2 ผู้ใช้ที่ดาวน์โหลดก่อนช่วงดังกล่าวไม่อยู่ในขอบเขตนี้ และผู้ผลิตระบุว่าซอร์สโค้ดกับ build chain ไม่ได้รับผลกระทบ ข่าววันที่ 21 ต.ค. เป็นการติดตามเหตุเดิม

ผลกระทบ

ผู้ที่รันไฟล์อันตรายเสี่ยงถูกขโมยข้อมูลรับรองบริการคลาวด์ SSH และเครื่องมือพัฒนา ผู้ผลิตให้ถือว่า Secrets ในเครื่องที่รันไฟล์ได้รับผลกระทบ และควรเปลี่ยนหรือเพิกถอน ไม่ใช่เพียงลบโปรแกรม

ข้อเสนอแนะ

ตรวจประวัติดาวน์โหลดและการรัน CLI ในช่วงที่ประกาศระบุ หากเข้าเงื่อนไขให้เพิกถอนหรือเปลี่ยน Secrets ของบริการที่เกี่ยวข้อง ลบ binary อันตรายและติดตั้ง 0.16.0 ที่ผู้ผลิตระบุว่าไม่ถูกกระทบ พร้อมตรวจการใช้บัญชีและกุญแจผิดปกติ
