สถานการณ์

Arista เปิดเผย CVE-2026-114625 ใน VeloCloud Orchestrator แบบ On-prem และยืนยันว่าพบการใช้โจมตีจริง ช่องโหว่อาจทำให้ผู้ใช้ที่มี Session ยืนยันตัวตนระดับต่ำยกระดับเป็น Operator ได้ รัฐบาลแคนาดาระบุว่ารุ่นก่อน 5.2.3.18, 6.1.3.10 และ 6.4.2.12 ได้รับผลกระทบ และ CISA เพิ่มรายการนี้เข้า KEV เมื่อ 23 ต.ค.

ผลกระทบ

หากโจมตีสำเร็จ ผู้โจมตีอาจเข้าถึงฟังก์ชันภายในที่ควรจำกัด กระทบความลับ ความถูกต้อง และความพร้อมใช้ของ VCO กับข้อมูลที่บริหารจัดการ ระบบ Hosted ได้รับการแก้ไขโดยผู้ให้บริการแล้ว แต่ระบบ On-prem ต้องดำเนินการโดยเจ้าของระบบ

ข้อเสนอแนะ

อัปเดต VCO On-prem เป็นรุ่นแก้ไขตามสายรุ่น ตรวจ Web, Application, System และ Database Log ก่อนแก้ไขเพื่อรักษาหลักฐาน จำกัดการเข้าถึง Web Interface และตรวจพฤติกรรม Admin ผิดปกติ หากสงสัยถูกบุกรุกให้ดำเนิน Incident Response แทนการถือว่าการแพตช์เพียงอย่างเดียวลบผลกระทบเดิมได้

3. PHP แนะนำปิด Session Upload Progress ชั่วคราวสำหรับ CVE-2026-115560 ที่ยังไม่มีแพตช์

PHPCVE-2026-115560RCE

PHP เปิดเผยช่องทาง RCE เพิ่มเติมภายใต้การตั้งค่าที่พบไม่บ่อย และแนะนำตั้ง session.upload_progress.enabled=0 พร้อมเริ่ม Worker ใหม่จนกว่าจะออก Bugfix รุ่นถัดไป

ประเด็น: Web Serverสถานะ: ยังไม่มีแพตช์; มี Mitigation จากผู้พัฒนาการดำเนินการ: ตรวจ Configuration และปิด Upload Progress ตามเงื่อนไข
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

PHP เผยแพร่ Informational Advisory วันที่ 23 ต.ค. สำหรับ CVE-2026-115560 โดยปัญหาเกิดได้เมื่อแอปพลิเคชันใช้ Session Serializer บางค่า เปลี่ยน Handler ระหว่างทำงานก่อน session_start() และยังเปิด Session Upload Progress ผู้พัฒนาระบุว่าเป็นชุดเงื่อนไขที่พบไม่บ่อยและจะออก Advisory เต็มพร้อม Bugfix รุ่นถัดไป

ผลกระทบ

ภายใต้เงื่อนไขที่ระบุ ช่องโหว่อาจนำไปสู่การรันโค้ดจากระยะไกลได้ ยังไม่ควรตีความว่า PHP ทุกระบบมีเส้นทางโจมตีนี้เหมือนกัน หรือมีหลักฐานยืนยันการโจมตีจริงใน Advisory นี้ ระบบที่ไม่เปลี่ยน Serialize Handler ระหว่างทำงานไม่อยู่ในเงื่อนไขเดียวกัน

ข้อเสนอแนะ

ตรวจ php.ini และโค้ดว่าเปลี่ยน session.serialize_handler ด้วย ini_set() ก่อน session_start() หรือไม่ หากยังยืนยันไม่ได้ ให้ตั้ง session.upload_progress.enabled=0 ใน Configuration ที่มีผลก่อนประมวลผลคำขอ และเริ่ม PHP Worker ทุกตัวใหม่ ติดตามรุ่น Bugfix ถัดไปจาก PHP โดยตรง

PHP Informational Advisory 23 ต.ค. 2569

สถานการณ์

HPE เผยแพร่ชุดแก้ไขสำหรับ ArubaOS ซึ่งใช้ใน Controller, Gateway และโครงสร้างพื้นฐานไร้สายองค์กร รวม 72 ช่องโหว่ โดย 8 รายการระดับสูงสุดอยู่ในช่วง CVE-2026-79844 ถึง CVE-2026-79851 และครอบคลุมการข้ามการยืนยันตัวตน การแทรกคำสั่ง Buffer Overflow และ SQL Injection ที่อาจนำไปสู่ RCE

ผลกระทบ

ช่องโหว่ร้ายแรงหลายรายการโจมตีจากระยะไกลได้โดยไม่ต้องมีสิทธิ์และไม่ต้องมีการโต้ตอบจากผู้ใช้ อาจกระทบการควบคุมเครือข่ายไร้สายและ Gateway อย่างไรก็ตาม HPE ระบุว่ายังไม่พบ Public Exploit หรือหลักฐานการใช้โจมตีจริง ณ วันออก Advisory

ข้อเสนอแนะ

ตรวจ AOS-8 และ AOS-10 เทียบตาราง Affected/Fix ของ HPE แล้วอัปเดตตามสายรุ่น จำกัด CLI และ Web Management ให้อยู่บน VLAN เฉพาะหรือผ่าน Firewall บันทึกกิจกรรมผู้ดูแล และตรวจว่าหน้า Management ไม่เปิดต่ออินเทอร์เน็ตโดยไม่จำเป็น

ผลกระทบ

ข้อมูลหลักที่ได้รับผลกระทบประกอบด้วยอีเมล เวลาเปิดบัญชี เวลาและจำนวน Login กับ IP ครั้งล่าสุด ส่วน 43 รายการมีข้อมูลวันเกิด เพศ ประเทศหรือภูมิภาค และชื่อเล่นเพิ่มขึ้น สำหรับ 19 บัญชี e-Capcom มีข้อมูลส่วนบุคคลและประวัติการซื้อเพิ่มเติม บริษัทระบุว่าไม่มีข้อมูลบัตรเครดิตรวมอยู่
