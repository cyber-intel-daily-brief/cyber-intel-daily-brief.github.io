สถานการณ์

FBI เผยแพร่ FLASH-20261113-001 ระบุว่า ARTEX ซึ่งเป็นกรอบงานทดสอบเจาะระบบที่ขับเคลื่อนด้วย LLM ถูกผู้ไม่หวังดีหลายกลุ่มนำไปใช้ตั้งแต่เดือนสิงหาคม 2569 เพื่อทำขั้นตอนโจมตีตั้งแต่การสำรวจจนถึงการขโมยข้อมูลโดยอัตโนมัติ เป้าหมายครอบคลุมภาครัฐ การเงิน กลาโหม พลังงาน สุขภาพ เทคโนโลยี และโครงสร้างพื้นฐานอื่น โดยบางเหตุเดินหน้าจากการเริ่มโจมตีถึงสิทธิระดับสูงภายในเวลาไม่ถึง 3 ชั่วโมง FBI ยกเหตุ ConnectWise Cloud Backup ซึ่งเปิดทางให้เข้าถึงผู้เช่าปลายทางมากกว่า 2,250 รายเป็นตัวอย่างสำคัญ

ผลกระทบ

องค์กรที่เปิด Web Application, Cloud Tenant หรือระบบเชื่อมต่อคู่ค้าสู่อินเทอร์เน็ตมีเวลาตรวจจับและตอบสนองสั้นลงอย่างมาก ผู้โจมตีอาจใช้สิทธิของ Application หรือ Service Principal ที่เชื่อถืออยู่แล้วเพื่อเปลี่ยน Credential สร้าง Persistence และขโมยข้อมูลในหลาย Tenant พร้อมกัน ตัวเลขผู้เช่าปลายทางไม่ได้หมายความว่าทุกรายถูกเจาะสำเร็จ จึงต้องตรวจหลักฐานราย Tenant

ข้อเสนอแนะ

ทบทวน Application Identity และ Service Principal ของ ConnectWise/คู่ค้าทั้งหมดใน Microsoft 365 ตรวจ Entra sign-in และ Audit Log ย้อนหลังอย่างน้อยตั้งแต่ 1 ตุลาคม 2569 แยกตรวจทั้งความพยายามสำเร็จและล้มเหลว จำกัดสิทธิ Application ตาม Least Privilege และเก็บหลักฐานก่อน Rotate Credential หรือเพิกถอน Session ตามแผน Incident Response

2. Quantum Systems ยืนยันการโจมตีไซเบอร์ ขณะรายงานภายนอกชี้ไปที่ไฟล์อัปเดต QBase ที่เป็นอันตราย

สถานการณ์

Quantum Systems ผู้ผลิตระบบอากาศยานไร้คนขับของเยอรมนี ยืนยันว่าพบเหตุไซเบอร์เมื่อปลายเดือนตุลาคมและการสอบสวนพบการโจมตีที่ยังดำเนินอยู่โดยผู้ประสงค์ร้าย บริษัทระบุว่าควบคุมเหตุได้และรายงานหน่วยงานรัฐแล้ว พร้อมยืนยันว่าไม่มีความเสี่ยงต่อการใช้งานอากาศยานของผู้ใช้ในปัจจุบัน ส่วนรายละเอียดว่าไฟล์อัปเดต QBase ที่เป็นอันตรายถูกส่งผ่าน Update Server มาจากรายงาน Financial Times/Der Spiegel ที่สื่ออื่นอ้างต่อ ไม่ใช่รายละเอียดที่บริษัทเปิดเผยโดยตรง

ผลกระทบ

หากระบบแจกจ่ายอัปเดตถูกใช้เป็นช่องทางจริง เหตุอาจกระทบความเชื่อมั่นต่อ Software Supply Chain ของระบบวางแผนภารกิจและเครื่องควบคุมภาคพื้นดิน การตอบสนองเชิงป้องกันทำให้กองทัพเยอรมนีระงับการบินโดรนบางส่วนชั่วคราว แม้บริษัทระบุภายหลังว่าใช้งานได้อย่างปลอดภัยแล้ว

ข้อเสนอแนะ

หน่วยงานที่ใช้ QBase ควรยืนยัน Hash/ลายเซ็นดิจิทัลและแหล่งที่มาของแพ็กเกจอัปเดตกับผู้ผลิต แยกตรวจ Endpoint ที่รับอัปเดตช่วงปลายตุลาคม สร้าง Baseline ของ Process และ Network Connection หลังการอัปเดต และประสาน Quantum Systems/หน่วยงานกำกับก่อนนำเครื่องที่มีข้อสงสัยกลับสู่ภารกิจ

สถานการณ์

TSMC ยื่นเอกสารต่อ SEC ระบุว่าพบข้อมูลส่วนบุคคลของพนักงานปัจจุบันและอดีตถูกเผยแพร่บนเว็บไซต์ภายนอกโดยไม่ได้รับอนุญาต บริษัทตรวจยืนยันว่าข้อมูลตรงกับข้อมูลที่เก็บในบริการระบบของผู้ให้บริการ Cloud แต่ไม่เกี่ยวข้องกับการดำเนินงานหรือข้อมูลลูกค้า และยังไม่พบหลักฐานว่าระบบของ TSMC ถูกเจาะ บริษัทกำลังแจ้งผู้ได้รับผลกระทบและทำงานร่วมกับผู้ให้บริการ หน่วยงานสอบสวน และผู้เชี่ยวชาญภายนอก

ผลกระทบ

ข้อมูลบุคลากรที่รั่วอาจถูกใช้ทำ Spear Phishing, Identity Fraud หรือ Social Engineering ต่อพนักงานและอดีตพนักงาน ความเสี่ยงสำคัญอยู่ที่ความเชื่อมโยงระหว่างข้อมูลจากผู้ให้บริการภายนอกกับบัญชีองค์กร แม้ยังไม่มีหลักฐานว่าระบบผลิตหรือข้อมูลลูกค้าได้รับผลกระทบ

ข้อเสนอแนะ

องค์กรควรตรวจสัญญาและสิทธิการเข้าถึงของผู้ให้บริการ Cloud ที่ประมวลผลข้อมูลพนักงาน บังคับ MFA และ Conditional Access สำหรับระบบ HR/บุคลากร เฝ้าระวัง Phishing ที่อ้างฝ่ายบุคคลหรือสิทธิประโยชน์ และแจ้งพนักงานให้ยืนยันคำขอเปลี่ยนข้อมูลการเงินผ่านช่องทางที่สอง

ข้อเสนอแนะ

สถานการณ์

ActiveCloud ผู้ให้บริการ Cloud ในเบลารุสรายงานเหตุ Ransomware ที่เข้ารหัสโครงสร้างพื้นฐานบางส่วน ส่งผลให้บริการ Hosting, Corporate Email, Virtual Server และช่องทางสนับสนุนหยุดชะงักหลายวัน บริษัทกู้บริการหลักกลับมาแล้ว แต่ลูกค้าบางรายยังประสบปัญหาในการเปิด Virtual Machine และยังไม่เปิดเผยช่องทางที่ผู้โจมตีใช้เข้าถึง จากผลสอบสวนที่เผยแพร่ยังไม่พบหลักฐานว่าข้อมูลลูกค้าถูกขโมย

ผลกระทบ

ลูกค้าที่พึ่งพา E-Cloud, E-Cloud Protected และ SmartMail อาจเผชิญการหยุดให้บริการ เว็บไซต์และอีเมลธุรกิจใช้งานไม่ได้ รวมถึงความล่าช้าในการกู้ Virtual Machine การไม่พบหลักฐานขโมยข้อมูลในขณะนี้ไม่เท่ากับการยืนยันว่าไม่มีการรั่วไหล จึงยังต้องติดตามผลสอบสวน

ข้อเสนอแนะ

ลูกค้าควรตรวจความสมบูรณ์ของ VM และ Backup ก่อนนำกลับใช้งาน เปลี่ยน Credential ที่ใช้บริหาร Cloud หากมีความเสี่ยง ตรวจ Log และ Network Connection หลังการกู้คืน และทดสอบแผนสำรองนอกผู้ให้บริการเดียวเพื่อรองรับกรณี Control Plane, Email และ Support ล่มพร้อมกัน
