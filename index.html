สถานการณ์

ConnectWise ยืนยันว่ากำลังสอบสวน Malicious Activity ซึ่งกระทบ ScreenConnect Partner บางราย ขณะที่ Huntress ตรวจพบ MSP 6 ราย, Endpoint อย่างน้อย 286 เครื่อง และ 47 องค์กร ผู้โจมตีใช้ฟังก์ชัน Run Command ของ ScreenConnect ที่ถูกยึดเพื่อติดตั้ง Remote-access Client อีกชุดลงบนเครื่องลูกค้า โดยยังไม่ยืนยันว่า Initial Access เกิดจากช่องโหว่ใหม่หรือการใช้บัญชี/ฟังก์ชันที่ถูกต้องในทางมิชอบ

ผลกระทบ

การยึดระบบ Remote Monitoring and Management ของ MSP ทำให้ผู้โจมตีขยายผลไปยังลูกค้าหลายองค์กรจากจุดเดียว และอาจรักษาการเข้าถึงนอก ScreenConnect Environment เดิม ความเสี่ยงสูงเป็นพิเศษต่อบัญชี Technician และเครื่องที่มี Interactive Session กับปลายทางต้องสงสัย

ข้อเสนอแนะ

หลีกเลี่ยง Interactive Session ไปยังเครื่องต้องสงสัย ใช้ Security Tool แยกต่างหากตรวจสอบ Endpoint ทบทวน Account Activity เพิกถอน Active Session รีเซ็ต Credential จากเครื่องที่เชื่อถือได้ และยืนยัน MFA ตรวจ Run Command, Client ID และการติดตั้ง RMM ที่ไม่รู้จัก พร้อมแยกเครื่องที่พบพฤติกรรมผิดปกติทันที

2. CISA เพิ่ม Cisco BroadWorks CVE-2026-20320 เข้า KEV หลังพบการโจมตีจริง

Cisco BroadWorksCVE-2026-20320CISA KEV

ช่องโหว่ XXE ใน BroadWorks OCI-P เปิดทางให้ผู้โจมตีจากระยะไกลอ่านไฟล์ Configuration ที่ละเอียดอ่อน; Cisco มีรุ่นแก้ไขแล้วและไม่มี Workaround

ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

CISA เพิ่ม CVE-2026-20320 ของ Cisco BroadWorks เข้า Known Exploited Vulnerabilities Catalog หลังพบหลักฐานการโจมตีจริง ช่องโหว่เกิดใน OCI XML Parser ที่อนุญาต External Entity Resolution โดยค่าเริ่มต้น ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนสามารถส่ง XML ที่สร้างขึ้นเฉพาะไปยัง OCI-P Service เพื่ออ่านไฟล์จากระบบด้วยสิทธิของ BroadWorks User

ผลกระทบ

ข้อมูล Configuration ที่ถูกอ่านอาจเปิดเผยรายละเอียดระบบหรือข้อมูลที่ช่วยให้ผู้โจมตีขยายผลในสภาพแวดล้อมโทรคมนาคม ช่องโหว่กระทบ BroadWorks Application Delivery Platform, Application Server, Profile Server และ Xtended Services Platform ตามรุ่นใน Advisory

ข้อเสนอแนะ

อัปเกรดไปยัง BroadWorks RI.2026.07 หรือรุ่นแก้ไขที่ Cisco ระบุโดยเร็ว เนื่องจากไม่มี Workaround จำกัดการเข้าถึง OCI-P จากเครือข่ายที่จำเป็นเท่านั้น และตรวจ Log สำหรับ XML Request หรือ File-access Pattern ผิดปกติ หน่วยงานที่อยู่ภายใต้ข้อกำหนด CISA ต้องแก้ไขภายในกำหนดของ KEV

RailwaySecret ExposureAI Credentials

ผู้โจมตีเชื่อมช่องโหว่หลายจุดและเข้าถึง Environment Variable ของ Workspace สูงสุด 1.85%; Railway ประเมินความเสียหายจากการใช้ AI Key โดยไม่ได้รับอนุญาตราว 740,000 ดอลลาร์

สถานการณ์

Railway เปิดเผยผลสอบสวนเหตุ 20–21 ตุลาคมว่า ผู้โจมตีเชื่อม Exploit หลายจุด เคลื่อนที่ข้ามระบบ และถอดรหัส Environment Variable ของ Workspace สูงสุด 1.85% หรือประมาณ 100,000 แห่ง ขอบเขตยังรวม Linked-account Token ของผู้ใช้ 1,852 ราย ซึ่ง Railway ยกเลิกและแจ้งผู้ใช้แล้ว

สถานะ: Intermediate ที่เกี่ยวข้องถูกเพิกถอน; ลูกค้าถูกย้ายหรือออกใหม่เผยแพร่: eMudhra / รายงาน 11 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

eMudhra เพิกถอน RSA Intermediate CA เพิ่มอีก 8 รายการ หลังการสอบสวนพบว่า Custom Python Script ที่ใช้ย้าย Key ระหว่าง HSM ในเดือนเมษายน 2568 ประมวลผล Private Key ผ่าน Host Memory ซึ่งไม่สอดคล้องกับ Certificate Policy แม้ RSA Key ชุดนี้ไม่ได้อ่อนแอแบบ ECDSA Intermediate 8 รายการแรก

ผลกระทบ

Intermediate บางรายการใช้สำหรับออก TLS และ Code-signing Certificate และมีการใช้งานจริงจนถึงต้นเดือนพฤศจิกายน การเพิกถอนอาจทำให้ Certificate Chain ที่เกี่ยวข้องต้องถูกออกใหม่หรือย้าย และเหตุการณ์กระทบความเชื่อมั่นต่อกระบวนการ Key Ceremony และ WebPKI

ข้อเสนอแนะ

องค์กรที่ใช้ Certificate จาก eMudhra ควรตรวจ Chain และสถานะ Revocation ยืนยันว่ามี Replacement Certificate แล้ว และทดสอบ TLS/Code-signing Validation บน Browser, Server และระบบที่ใช้ Custom Trust Store ผู้ให้บริการ CA ควรคง Private Key ภายใน HSM และตรวจ Key Strength/Key Match ทุก Ceremony
