01 สถานการณ์

CISA อัปเดต Alert เมื่อ 9 ต.ค. 2569 เพื่อเพิ่ม CVE-2026-88779 และ CVE-2026-107406 ในขอบเขตคำเตือน NetScaler ADC และ NetScaler Gateway พร้อมชี้แจงความสัมพันธ์ของ CVE-2026-88779 กับ CVE-2026-88771 ก่อนหน้านี้ CISA ยืนยันว่า CVE-2026-88771 และ CVE-2026-88772 เป็นช่องโหว่ Zero-day ที่เปิดทางให้ Remote Code Execution และมีการใช้โจมตีจริงทั่วโลก

02 ผลกระทบ

อุปกรณ์ NetScaler มักอยู่บริเวณขอบเครือข่ายและรองรับการเข้าถึงจากภายนอก หากถูกโจมตีอาจทำให้ผู้โจมตีรันคำสั่งบนอุปกรณ์ เข้าถึงข้อมูลรับรอง หรือใช้เป็นจุดเริ่มต้นเข้าสู่ระบบภายใน การอัปเดตเพียงอย่างเดียวอาจไม่ลบร่องรอยหรือการเข้าถึงที่เกิดขึ้นก่อนหน้า

03 ข้อเสนอแนะ

ตรวจสอบรุ่นและสถานะอุปกรณ์ตาม Citrix Security Bulletin ใช้คำแนะนำของ CISA และ Citrix เพื่อตรวจ Indication of Compromise ก่อนอัปเดต และรักษาหลักฐานนิติวิทยาศาสตร์หากสงสัยว่าถูกเจาะ จำกัด Management Interface จากอินเทอร์เน็ตและติดตาม Log ของการเข้าถึงผิดปกติหลังแก้ไข
