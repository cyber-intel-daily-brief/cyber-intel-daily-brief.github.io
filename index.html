สถานการณ์

Broadcom จัด CVE-2026-123890 เป็นช่องโหว่ Critical ใน VMware Directory Service ของ vCenter Server และระบุว่าไม่มี Workaround ส่วน Google Threat Intelligence Group และ Mandiant รายงานว่ากลุ่ม ARMORY CASTLE ซึ่งสงสัยว่าเชื่อมโยงกับจีน ใช้ช่องโหว่นี้เป็น Zero-day ผ่านเครื่องมือ BONESAW เพื่อสร้างบัญชี SSO Administrator ดึงฐานข้อมูล และเคลื่อนย้ายภายในเครือข่าย

ผลกระทบ

การยึด vCenter อาจทำให้ผู้โจมตีควบคุมโครงสร้างพื้นฐาน Virtualization เข้าถึงข้อมูลรับรองและกุญแจ SAML ตลอดจนใช้สิทธิ์ระดับผู้ดูแลกับระบบ Virtual Machine จำนวนมาก

ข้อเสนอแนะ

อัปเดตตาม VMSA-2026-0009 ทันที ได้แก่ vCenter 8.0 U3m, VCF/VSF 9.1.1.0200 หรือ 9.0.2.0200 และ VCF 5.2.5 ตามสาขาที่ใช้ พร้อมตรวจการเชื่อมต่อผิดปกติไปยัง vCenter, การสร้าง SSO Admin และการเข้าถึง vmdird/LMDB ย้อนหลัง

สถานการณ์

การสอบสวนพบการเข้าถึง Server หนึ่งเครื่องโดยไม่ได้รับอนุญาต และอาจมีการเข้าถึง Credential บางรายการบนแพลตฟอร์ม N-able แยก Server ออกจากระบบ หมุนเวียน Credential ภายใน เพิกถอน Customer API Token และ OAuth Token และ Reset Password ของ Local User โดยระบุว่ายังไม่มีหลักฐานว่ากล่องจดหมายหรือข้อมูลลูกค้าถูกเข้าถึง

ผลกระทบ

ลูกค้าอาจไม่สามารถใช้ Portal, API, Logging, Mailbox Synchronization และ Quarantine บางส่วน แม้ Email Flow และ Spam Filtering ยังคงทำงาน ความเสี่ยงหลักอยู่ที่ Credential และ Token ที่อาจถูกเข้าถึงก่อนการเพิกถอน

ข้อเสนอแนะ

ปฏิบัติตามคำแนะนำเฉพาะของ N-able ออก Token ใหม่หลังได้รับอนุญาต ตรวจ Automation ที่พึ่งพา API และทบทวน Log การยืนยันตัวตนหรือการตั้งค่าที่ผิดปกติหลังบริการกลับมา
