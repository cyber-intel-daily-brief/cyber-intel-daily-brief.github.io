ผลกระทบ

Veeam เผยแพร่ KB4948 เมื่อ 27 ต.ค. ระบุช่องโหว่ CVE-2026-108142 ใน CDP Coordinator Service ซึ่งเปิดให้ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนข้ามกลไก Authorization ได้ ช่องโหว่มีคะแนน CVSS v4.0 เท่ากับ 9.1 และกระทบ Veeam Backup & Replication รุ่น 13.1.1.18 และรุ่น 13.1 ก่อนหน้า รวมถึง 13.0.2.29 และรุ่น 13.0 ก่อนหน้า

ข้อเสนอแนะ

อัปเดตเป็น Veeam Backup & Replication 13.1.2 build 13.1.2.57 หรือ 13.0.3 build 13.0.3.63 ตรวจการเปิดให้เข้าถึง CDP Coordinator Service จำกัดเครือข่ายบริหาร และทบทวน Log/การเปลี่ยนแปลงนโยบายสำรองข้อมูลที่ผิดปกติ

ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

GMO Internet รายงานความคืบหน้าเหตุ Onamae.com Desktop Cloud ว่าเมื่อ 27 ต.ค. ตรวจพบผู้ที่เชื่อว่าเป็นผู้โจมตีเผยแพร่ข้อมูลซึ่งอ้างว่าเกี่ยวข้องกับบริษัทและลูกค้า บริษัทกำลังตรวจสอบความถูกต้อง และเมื่อ 28 ต.ค. ยืนยันว่า Domain ของเว็บไซต์ดังกล่าวถูกนำลงแล้ว

ผลกระทบ

เหตุการณ์อาจนำไปสู่การเปิดเผยข้อมูลลูกค้า การหลอกลวงซ้ำ และความเสี่ยงต่อ Credentials ที่เก็บใน Server Environment อย่างไรก็ตาม GMO ระบุว่า ณ รายงานวันที่ 27 ต.ค. ยังไม่ยืนยันการโจมตี Ransomware บนอุปกรณ์ที่วิเคราะห์เสร็จ และการสืบสวนยังดำเนินอยู่

ข้อเสนอแนะ

ลูกค้าควรเปลี่ยน Credentials ที่เคยเก็บหรือใช้งานบนระบบจากเครื่องสะอาด ตรวจบัญชีและ Server Log ระวัง Phishing ที่อ้างเหตุการณ์นี้ ห้ามเข้าชมหรือเผยแพร่เว็บไซต์/ข้อมูลของผู้โจมตี และติดตามประกาศ GMO เพื่อยืนยันขอบเขตเฉพาะราย
