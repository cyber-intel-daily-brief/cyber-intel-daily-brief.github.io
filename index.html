สถานการณ์

Drupal เปิดเผย CVE-2026-118539 ใน Commerce Core ซึ่งปกป้อง Route และ Entity Field บางส่วนไม่เพียงพอ ทำให้เกิด Access Bypass และอาจสร้างผลกระทบทางการเงินต่อผู้ค้า ผู้ดูแลโครงการได้รับรายงานความพยายามสั่งซื้อฉ้อโกงบนเว็บไซต์จริง และระบุว่าช่องโหว่นี้กำลังถูกใช้โจมตี

ผลกระทบ

ร้านค้าออนไลน์ที่ใช้ Commerce Core รุ่นที่ได้รับผลกระทบอาจมี Order หรือเงื่อนไขธุรกรรมถูกแก้ไขโดยไม่ได้รับอนุญาต ส่งผลต่อรายได้ ความถูกต้องของคำสั่งซื้อ และการตรวจสอบทางบัญชี

ข้อเสนอแนะ

อัปเดต Commerce Core 3.x เป็น 3.3.13 หรือสาย 2.x เป็น 8.x-2.41 ทันที ตรวจสอบ Order ย้อนหลังเพื่อหาความไม่สอดคล้อง ตรวจ Log ของ Route ที่เกี่ยวข้อง และจำกัดการเปลี่ยนแปลงระบบระหว่างการตรวจสอบ

สถานการณ์

Chainalysis เปิดเผยเมื่อ 30 ต.ค. ว่าตรวจพบผู้โจมตีภายนอกใช้ Offensive Agentic Techniques เข้าถึงระบบและเครื่องมือภายในโดยไม่ได้รับอนุญาต ข้อมูลลูกค้าที่ไม่จัดเป็นข้อมูลอ่อนไหวบางส่วน เช่น User ID ชื่อ อีเมล และบทบาทในองค์กร ถูกเข้าถึง ขอบเขตของแต่ละองค์กรยังอยู่ระหว่างตรวจสอบ

ผลกระทบ

ข้อมูลระบุตัวบุคคลและบทบาทองค์กรอาจถูกนำไปใช้ทำ Spear Phishing หรือ Social Engineering แบบเจาะจง อย่างไรก็ตาม บริษัทระบุว่ายังไม่พบหลักฐานเข้าถึงกราฟ คดี ผลการค้นหา รหัสผ่านแบบข้อความชัด MFA Secret หรือ Session Token และยืนยันว่าเหตุนี้ไม่เกี่ยวข้องกับ Binance

ข้อเสนอแนะ

ผู้ใช้ Chainalysis ควรเปิดใช้ MFA ตรวจคำขอ Reset Password และ Authentication Prompt ที่ผิดปกติ แจ้งเตือนบุคลากรเกี่ยวกับ Phishing ที่อ้างข้อมูลบทบาทงาน และติดตามรายละเอียดขอบเขตจาก Account Manager โดยไม่รีบสรุปเทคนิคหรือผู้โจมตีเกินข้อมูลที่เปิดเผย
