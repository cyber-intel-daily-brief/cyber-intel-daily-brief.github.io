1. F5 BIG-IP APM — CVE-2026-94127 ถูกนำไปใช้โจมตีจริง
Heap-based buffer overflow กระทบ BIG-IP APM เมื่อ Access Policy และ OAuth profile อยู่บน virtual server เดียวกัน และอาจนำไปสู่ unauthenticated RCE
CVE-2026-94127Active ExploitationRemote Access Edge
CRITICAL

สถานการณ์

F5 เผยแพร่ Security Advisory เมื่อ 22 ก.ย. 2569 และ Canadian Centre for Cyber Security ระบุว่า F5 รายงานการ exploit in the wild แล้ว เงื่อนไขสำคัญคือ BIG-IP APM ที่มี Access Policy และ OAuth profile บน virtual server เดียวกัน

ผลกระทบ

BIG-IP APM มักอยู่บริเวณขอบเครือข่ายและเกี่ยวข้องกับการเข้าถึงระยะไกล/ตัวตน หากถูกยึดครองอาจกระทบความลับ ความถูกต้อง และความพร้อมใช้ รวมถึงเพิ่มความเสี่ยงต่อการเคลื่อนย้ายเข้าสู่เครือข่ายภายใน

ข้อเสนอแนะ

ตรวจ Inventory/configuration ของ BIG-IP APM ทันที ติดตั้ง hotfix/รุ่นแก้ไขตาม F5 Advisory จำกัด Management Interface จาก Internet และตรวจ log/telemetry ย้อนหลัง หากพบข้อบ่งชี้การบุกรุกให้ทำ forensic triage ก่อนหรือควบคู่การแก้ไข

ผลกระทบ

การยึด Security Gateway หรือ Management plane อาจทำให้ผู้โจมตีได้จุดยืนที่มีสิทธิ์สูงต่อระบบเครือข่าย และดำเนิน reconnaissance/lateral movement ต่อระบบภายใน

ข้อเสนอแนะ

ติดตั้ง fixes/Jumbo Hotfix ตามรุ่นที่ได้รับผลกระทบทันที ตรวจ anomalous certificate-based Mobile Access logins, second-stage activity และ internal port/service scanning รวมถึงใช้ IOC/hunting guidance ของผู้ผลิต

3. WordPress Core — CVE-2026-87902 Path Traversal อาจนำไปสู่ RCE
WordPress 7.1.2 แก้ช่องโหว่ Critical ที่ผู้โจมตีไม่ต้องยืนยันตัวตนอาจทำให้ page-template resolution include local PHP file นอก active theme directories
CVE-2026-87902WordPress CoreCritical Security Release
CRITICAL

สถานการณ์

WordPress ออก 7.1.2 เมื่อ 22 ก.ย. 2569 และระบุ CVE-2026-87902/GHSA-7hp8-65ch-5whp พร้อม backport ไปยังสาขาที่ยังได้รับ security fixes; รุ่น 6.9.9 ถูกเผยแพร่ในวันเดียวกันเพื่อแก้ปัญหานี้ในสาย 6.9

ผลกระทบ

เว็บไซต์ที่ยังใช้รุ่นที่ได้รับผลกระทบและมีเงื่อนไข server/theme ตรงกับช่องโหว่อาจถูก include local PHP file ที่เลือกได้ และอาจพัฒนาไปสู่ remote code execution

ข้อเสนอแนะ

เร่งอัปเดต WordPress Core เป็น security release ล่าสุดของสาขาที่ใช้งาน ตรวจ web access/error logs, file integrity และไฟล์ PHP ที่สร้างหรือแก้ไขผิดปกติ พร้อมใช้ WAF/virtual patching เป็นชั้นเสริมระหว่าง rollout

5. EvilTokens — Device-code Phishing และ Token Theft ใน Microsoft 365
Microsoft ระบุว่า EvilTokens สนับสนุน phishing-as-a-service และ AI-assisted targeting โดยเกี่ยวข้องกับการ compromise มากกว่า 12,000 inboxes ในกว่า 10,000 องค์กรทั่วโลก
Device Code PhishingToken TheftBEC
HIGH

สถานการณ์

Microsoft Threat Intelligence เผยรายละเอียดเมื่อ 22 ก.ย. 2569 ว่า EvilTokens ใช้ device code authentication flow เพื่อให้เหยื่ออนุมัติ session ของผู้โจมตีโดยไม่ต้องเปิดเผยรหัสผ่าน จากนั้นใช้ token เพื่ออ่านอีเมล สร้าง inbox rules ลงทะเบียนอุปกรณ์ และทำ Microsoft Graph reconnaissance

ผลกระทบ

องค์กร Microsoft 365 อาจเผชิญ account takeover, email exfiltration, BEC, persistence ผ่าน token/device registration และการใช้ข้อมูลภายในสร้าง social engineering ที่เฉพาะเจาะจง แม้ผู้ใช้มี MFA

ข้อเสนอแนะ

ปิด device code flow หากไม่จำเป็น หรือจำกัดด้วย Conditional Access ตรวจ anomalous OAuth device-code authentication, token exchange, device registration, Graph API activity และ malicious inbox rules หากพบเหตุให้ revoke sessions/tokens และพิจารณาปิดบัญชีชั่วคราวเพื่อ containment

6. RemControl — Android Banking Trojan แบบ Malware-as-a-Service
Group-IB เปิดเผย RemControl เมื่อ 23 ก.ย. 2569 เป็น Android banking trojan ที่มุ่งเป้าธนาคารในยุโรป ตะวันออกกลาง และแคนาดา พร้อม phishing overlays และ remote-control functions
AndroidBanking TrojanMaaS
HIGH

สถานการณ์

Group-IB รายงาน RemControl ซึ่งเผยแพร่ผ่านแคมเปญที่ปลอมเป็นแอป TVTap และใช้ social engineering ให้ติดตั้ง APK จากนอกแหล่งทางการ ตัวมัลแวร์ใช้ Accessibility abuse, phishing overlays และ remote-control functions

ผลกระทบ

ผู้ใช้ Android ที่ติดตั้งแอปจากแหล่งภายนอกมีความเสี่ยงต่อการขโมย PIN/credential การดักข้อมูลหน้าจอและการควบคุมธุรกรรม ความเสี่ยงต่อหน่วยงานเพิ่มขึ้นเมื่ออุปกรณ์ส่วนบุคคลใช้เข้าถึงอีเมล ระบบงาน หรือข้อมูลราชการ

ข้อเสนอแนะ

กำหนดให้ติดตั้งแอปจาก managed/official stores เท่านั้น บังคับใช้ MDM/Mobile Threat Defense สำหรับอุปกรณ์ที่เข้าถึงระบบราชการ จำกัด sideloading และ Accessibility permissions ที่ไม่จำเป็น พร้อมประชาสัมพันธ์ไม่ให้ติดตั้ง APK จากโฆษณาหรือลิงก์ที่อ้างบริการสตรีมมิงฟรี
Group-IB Blog — RemControl, 23 Sep 2026

ข้อพิจารณาสำหรับหน่วยงาน

ให้เริ่มจากยืนยัน Exposure ของ Internet-facing identity/VPN edge และ management plane ได้แก่ F5 BIG-IP APM, Check Point และ VeloCloud จากนั้นตรวจ WordPress Core ที่เผยแพร่สู่ Internet และดำเนิน identity hunting สำหรับ Microsoft 365 device-code flow ควบคู่กับการควบคุมอุปกรณ์ Android ที่เข้าถึงข้อมูลของหน่วยงาน
