สถานการณ์

Cursor เปิดเผยผลสอบสวนว่าเหตุเริ่มจาก Access Key ที่บริษัทออกให้ Fireworks ถูกเปิดเผย ผู้โจมตีใช้ข้อมูลที่ได้เข้าถึง SaaS และ Source Code บางส่วน ก่อนใช้ Credential ที่ขโมยมาใส่ Anthropic Claude Code Extension รุ่นปลอม 2.1.312 และ 2.1.313 ลงใน Cache ของ Cursor Marketplace เมื่อ 29 ตุลาคม Extension อยู่ราว 11 ชั่วโมงและอาจถูกส่งให้ผู้ใช้สูงสุด 5,000 ราย โดย Anthropic และ Open VSX ไม่ได้ถูกเจาะ

ผลกระทบ

Extension พยายามเก็บข้อมูลเครื่อง เพิ่ม SSH Key เปิด Reverse SSH Tunnel และสร้าง Persistence บน Windows หรือ macOS Cursor ระบุว่า API Credential ถูกเปิดเผยในลูกค้าน้อยกว่า 0.01% และเหตุถูกควบคุมแล้ว แต่การถอน Extension อย่างเดียวอาจไม่ลบ Persistence หรือ Credential ที่ถูกขโมย

ข้อเสนอแนะ

ผู้ที่ติดตั้งหรืออัปเดต Anthropic.claude-code 2.1.312 หรือ 2.1.313 จาก Cursor Marketplace ในช่วงที่ระบุ ให้ใช้สคริปต์ตรวจสอบของ Cursor กำจัด SSH Key, Tunnel, Scheduled Task หรือ LaunchAgent และหมุนเวียน Credential ที่แจ้งเตือน องค์กรควรตรวจ Extension Cache, Marketplace Trust และการใช้ Secret ใน Support Ticket/Agent Trace

PostgreSQL Global Development Group ออก PostgreSQL 18.7, 17.12, 16.16, 15.20 และ 14.25 เพื่อแก้ช่องโหว่และข้อบกพร่องหลายรายการ ช่องโหว่สำคัญ CVE-2026-6460 คะแนน CVSS 8.8 เป็น Type Confusion ที่เปิดให้ผู้มีสิทธิสร้าง Object รันโค้ดตามอำเภอใจในบริบท OS User ของ Database ผ่าน ALTER ...
