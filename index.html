Active scanning targets CVE-2026-61500 in Rejetto HTTP File Server

CRITICAL
CVE-2026-61500Remote Code ExecutionActive Scanning

พบการสแกนหา Rejetto HTTP File Server ที่มีช่องโหว่ CVE-2026-61500 ซึ่งสามารถนำไปสู่การปลอม Session ผู้ดูแลระบบและสั่งการเครื่องแม่ข่ายจากระยะไกลได้ ระบบ HFS ที่เปิดให้เข้าถึงจากอินเทอร์เน็ตและยังไม่ได้อัปเดตควรได้รับการตรวจสอบโดยเร่งด่วน

01 สถานการณ์

VulnCheck และแหล่งข่าวด้านความมั่นคงปลอดภัยไซเบอร์รายงานการตรวจพบการสแกนหา Rejetto HTTP File Server ที่มีช่องโหว่ CVE-2026-61500 โดยช่องโหว่เกิดจากการสร้าง Session Signing Key ที่คาดเดาได้ใน HFS รุ่น 3.0.0 ถึง 3.2.0 ผู้โจมตีจากภายนอกสามารถใช้ข้อมูลจากกระบวนการ Login เพื่อสร้าง Administrator Session ปลอม และนำไปสู่การสั่งการระบบจากระยะไกลได้ ปัจจุบันมีหลักฐานการสแกนและ probing ต่อระบบจริง แต่ยังไม่มีข้อมูลยืนยันจากแหล่งอ้างอิงว่ามีการยึดระบบสำเร็จในวงกว้าง

02 ผลกระทบ

หากระบบที่มีช่องโหว่ถูกโจมตีสำเร็จ ผู้โจมตีอาจเข้าควบคุม HFS ด้วยสิทธิ์ผู้ดูแล เข้าถึง แก้ไข หรือนำไฟล์ออกจากระบบ รวมถึงติดตั้งมัลแวร์หรือใช้เครื่องดังกล่าวเป็นจุดเริ่มต้นในการเข้าถึงระบบอื่นภายในเครือข่าย ความเสี่ยงจะเพิ่มขึ้นอย่างมีนัยสำคัญเมื่อ HFS เปิดบริการจากอินเทอร์เน็ตโดยตรง

03 ข้อเสนอแนะ

ให้ตรวจสอบว่ามี Rejetto HFS อยู่ในการใช้งานหรือไม่ โดยเฉพาะระบบที่เปิดจากอินเทอร์เน็ต หากพบ HFS รุ่นต่ำกว่า 3.2.1 ให้ดำเนินการอัปเดตเป็นรุ่นแก้ไขหรือรุ่นล่าสุดโดยเร็ว พร้อมตรวจสอบ Log การเข้าสู่ระบบ Administrator Session และคำสั่งที่ถูกเรียกใช้งานย้อนหลัง หากพบพฤติกรรมผิดปกติ ให้แยกระบบและดำเนินการตรวจสอบตามกระบวนการตอบสนองเหตุการณ์

Citrix NetScaler พบ Zero-Day ที่ถูกนำไปใช้โจมตีแบบเจาะจง

CVE-2026-88779 affects NetScaler ADC/Gateway deployments using SAML

HIGH
CVE-2026-88779Zero-DayNetScaler

Citrix เปิดเผยช่องโหว่ CVE-2026-88779 ใน NetScaler ADC และ NetScaler Gateway ที่ใช้งาน SAML โดยมีรายงานการโจมตีระบบที่ยังไม่ได้รับการแก้ไขและทำให้บริการหยุดชะงัก ผู้ดูแลระบบควรตรวจสอบเงื่อนไขการตั้งค่าและอัปเดตตาม Security Bulletin โดยเร็ว

01 สถานการณ์

Citrix เปิดเผยช่องโหว่ CVE-2026-88779 ใน NetScaler ADC และ NetScaler Gateway ซึ่งเป็นปัญหา Memory Overflow ที่สามารถทำให้บริการหยุดทำงานภายใต้เงื่อนไขที่ระบบถูกตั้งค่าเป็น SAML Service Provider หรือ SAML Identity Provider ช่องโหว่มีคะแนน CVSS v4.0 เท่ากับ 8.7 และมีรายงานการโจมตีแบบเจาะจงต่อระบบที่ยังไม่ได้รับการแก้ไข โดยผลกระทบที่ผู้ผลิตยืนยันคือ Denial of Service ยังไม่มีข้อมูลทางการที่ยืนยันว่าช่องโหว่นี้สามารถใช้ทำ Remote Code Execution ได้

02 ผลกระทบ

หากระบบที่ได้รับผลกระทบยังไม่ได้รับการแก้ไข ผู้โจมตีอาจทำให้บริการ NetScaler ไม่พร้อมใช้งานซ้ำ ๆ ส่งผลต่อระบบ Remote Access การยืนยันตัวตน หรือบริการที่พึ่งพา NetScaler ในการเชื่อมต่อจากภายนอก เหตุการณ์ดังกล่าวอาจกระทบต่อความต่อเนื่องในการให้บริการขององค์กร โดยเฉพาะหน่วยงานที่ใช้งาน NetScaler เป็นจุดเชื่อมต่อหลักจากอินเทอร์เน็ต

03 ข้อเสนอแนะ

ให้ตรวจสอบการตั้งค่า NetScaler ADC/Gateway ว่าตรงตามเงื่อนไข SAML ที่ได้รับผลกระทบหรือไม่ และอัปเดตเป็นรุ่นที่ Citrix ระบุใน Security Bulletin โดยเร็ว สำหรับระบบที่เปิดให้เข้าถึงจากอินเทอร์เน็ต ควรตรวจสอบเหตุการณ์ Restart, Crash และ Log ที่ผิดปกติย้อนหลัง พร้อมจำกัดช่องทางบริหารจัดการให้เข้าถึงได้เฉพาะเครือข่ายที่ได้รับอนุญาต

South Korea orders sector-wide security reviews after a series of financial breaches

HIGH
South KoreaFinancial SectorASEAN/Indo-Pacific

หน่วยงานกำกับดูแลด้านการเงินของเกาหลีใต้เรียกประชุมฉุกเฉินหลังเกิดเหตุโจมตีและข้อมูลรั่วไหลในสถาบันการเงินหลายแห่ง โดยสั่งตรวจสอบระบบที่เปิดให้เข้าถึงจากภายนอก การยืนยันตัวตน และการควบคุมสิทธิ์ พร้อมระบุว่ายังไม่สามารถตัดความเป็นไปได้ของการใช้ AI ในการโจมตี

ประเด็น: Financial Sectorสถานะ: Ongoing Investigationการดำเนินการ: ตรวจ External Exposure

01 สถานการณ์

Financial Services Commission (FSC) ของเกาหลีใต้ได้เรียกประชุมฉุกเฉินร่วมกับหน่วยงานกำกับดูแลและสถาบันการเงิน หลังพบเหตุข้อมูลรั่วไหลและการโจมตีทางไซเบอร์ต่อสถาบันการเงินหลายแห่ง โดยทางการระบุว่าหลายเหตุการณ์เกี่ยวข้องกับหน้าเว็บหรือ Server ภายนอกที่ใช้สนับสนุนการทำงานและได้รับการดูแลน้อยกว่าระบบหลัก FSC สั่งให้ภาคการเงินตรวจสอบระบบที่เปิดสู่ภายนอก การยืนยันตัวตน และการควบคุมสิทธิ์ทั้งหมด ขณะที่การตรวจสอบสาเหตุและวิธีการโจมตียังดำเนินอยู่ และยังไม่สามารถตัดความเป็นไปได้ว่าผู้โจมตีใช้ AI ช่วยในการโจมตี

02 ผลกระทบ

เหตุการณ์ที่เกิดขึ้นกับหลายสถาบันในช่วงเวลาใกล้เคียงกันสะท้อนความเสี่ยงจากระบบสนับสนุนหรือ External-facing Services ที่อาจกลายเป็นจุดอ่อนของทั้งองค์กร หากข้อมูลส่วนบุคคลถูกนำไปใช้ต่อ อาจเกิดความเสียหายจาก Voice Phishing, Smishing หรือการหลอกลวงแบบเจาะจง นอกจากนี้เหตุการณ์ดังกล่าวยังมีนัยสำคัญต่อภูมิภาค Indo-Pacific เนื่องจากเป็นการโจมตีต่อโครงสร้างพื้นฐานทางการเงินในประเทศเอเชีย

03 ข้อเสนอแนะ

ให้หน่วยงานตรวจสอบรายการระบบและบริการที่เปิดให้เข้าถึงจากภายนอก รวมถึงหน้าเว็บหรือ Server ที่ใช้สนับสนุนการทำงานภายใน ตรวจสอบ Authentication, Access Control และข้อมูลที่สามารถเรียกดูได้ให้เหลือเท่าที่จำเป็น ควรเพิ่มการเฝ้าระวังการสแกนและการเข้าถึงจากต่างประเทศ และหากพบข้อมูลรั่วไหลให้เตรียมมาตรการป้องกันการนำข้อมูลไปใช้ใน Phishing หรือ Social Engineering ต่อเนื่อง

01 สถานการณ์

Dell เปิดเผยช่องโหว่ CVE-2026-86360 ใน Dell System Update (DSU) รุ่นก่อน 2.3.0.0 ซึ่งเป็นเครื่องมือสำหรับบริหารการอัปเดต BIOS, Firmware และ Software บนโครงสร้างพื้นฐาน Server ช่องโหว่เป็น Path Traversal และได้รับคะแนน CVSS 9.6 โดยผู้ผลิตระบุว่าผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนและสามารถเข้าถึงระบบจากระยะไกลอาจใช้ช่องโหว่เพื่อเข้าถึง File System และรันโค้ดด้วยสิทธิ์ Root ได้ ปัจจุบันยังไม่พบข้อมูลยืนยันจาก Dell ว่ามีการนำช่องโหว่นี้ไปใช้โจมตีจริง

02 ผลกระทบ

หากถูกโจมตีสำเร็จ ผู้โจมตีอาจเข้าควบคุมแอปพลิเคชันและระบบปฏิบัติการที่เกี่ยวข้องในระดับสูงสุด ทำให้สามารถแก้ไขไฟล์สำคัญ ติดตั้งเครื่องมือเพิ่มเติม หรือใช้ Server เป็นจุดขยายการโจมตีไปยังระบบอื่น ความเสี่ยงมีความสำคัญเป็นพิเศษในองค์กรที่ใช้ DSU บริหาร PowerEdge Server จำนวนมาก

03 ข้อเสนอแนะ

ให้ตรวจสอบ Dell System Update ที่ติดตั้งบนเครื่องแม่ข่ายทั้งหมด และอัปเดตเป็นรุ่น 2.3.0.0 หรือใหม่กว่าตามคำแนะนำของ Dell พร้อมจำกัดการเข้าถึงระบบบริหารจัดการจากเครือข่ายที่ไม่จำเป็น ตรวจสอบการเปลี่ยนแปลงไฟล์และการรันคำสั่งด้วยสิทธิ์สูงย้อนหลัง หากพบพฤติกรรมผิดปกติให้ดำเนินการตรวจสอบเครื่องแม่ข่ายเพิ่มเติมก่อนนำกลับเข้าสู่การใช้งานปกติ

Microsoft เปิดเผยช่องโหว่ CVE-2026-96940 ใน Microsoft Exchange Server ซึ่งเกิดจากการควบคุมสิทธิ์ที่ไม่เพียงพอ และออก Security Update นอกกำหนดเพื่อแก้ไขปัญหา ผู้โจมตีจำเป็นต้องมีการยืนยันตัวตนก่อนจึงจะใช้ช่องโหว่ได้ และอาจเข้าถึง Mailbox ของผู้ใช้อื่นภายในองค์กรเดียวกันเพื่ออ่านข้อความและไฟล์แนบได้ Microsoft ระบุว่ายังไม่พบหลักฐานการนำช่องโหว่นี้ไปใช้โจมตีจริง แต่จัดระดับความเป็นไปได้ของการนำไปใช้ว่า Exploitation More Likely

02 ผลกระทบ

หากผู้โจมตีมีบัญชีในระบบอยู่แล้ว การใช้ช่องโหว่อาจทำให้ขอบเขตการเข้าถึงข้อมูลขยายไปยัง Mailbox ของบุคลากรรายอื่น ส่งผลต่อความลับของอีเมล เอกสารแนบ และข้อมูลภายในองค์กร เหตุการณ์ดังกล่าวอาจถูกใช้ร่วมกับบัญชีที่ถูกขโมยเพื่อรวบรวมข้อมูลสำหรับการโจมตีแบบเจาะจงหรือ Business Email Compromise

03 ข้อเสนอแนะ

สำหรับ Exchange Server แบบ On-premises ให้ตรวจสอบรุ่นที่ใช้งานและติดตั้ง Security Update ที่ Microsoft กำหนดโดยเร็ว พร้อมตรวจสอบ Account ที่มีพฤติกรรมเข้าถึง Mailbox ผิดปกติและ Audit Log ที่เกี่ยวข้อง Exchange Online ได้รับการแก้ไขฝั่งบริการแล้ว แต่หน่วยงานที่มี Exchange Server หรือ Exchange Management Tools ภายในองค์กรยังควรตรวจสอบสถานะการอัปเดตให้ครบถ้วน

01 สถานการณ์

Central Population Register (CPR) ของเดนมาร์กประกาศเมื่อวันที่ 5 ตุลาคม 2569 ว่าพบการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาตในระบบทะเบียนประชาชน โดยผู้ไม่หวังดีใช้สิทธิ์ที่บริษัทเอกชนแห่งหนึ่งได้รับอนุญาตให้ใช้ค้นข้อมูลใน CPR เพื่อเข้าถึงชื่อ ที่อยู่ หมายเลข CPR และข้อมูลที่เกี่ยวข้องของผู้ลงทะเบียนประมาณ 8.8 ล้านรายการ CPR ได้ระงับสิทธิ์ของบริษัทดังกล่าว และประสานหน่วยงานคุ้มครองข้อมูลและตำรวจเพื่อสอบสวนเหตุการณ์ต่อไป

02 ผลกระทบ

ข้อมูลประจำตัวจำนวนมากที่ถูกเข้าถึงอาจถูกนำไปใช้ประกอบการหลอกลวงแบบเจาะจง การสวมรอย หรือ Social Engineering แม้เหตุการณ์นี้ไม่ได้เกิดจากการเจาะฐานข้อมูลโดยตรง แต่แสดงให้เห็นความเสี่ยงจาก Trusted Third-party Access และสิทธิ์ที่ถูกใช้งานผิดวัตถุประสงค์ในระบบที่เก็บข้อมูลสำคัญระดับประเทศ

03 ข้อเสนอแนะ

ให้หน่วยงานที่มีระบบแลกเปลี่ยนข้อมูลกับบุคคลภายนอกทบทวนสิทธิ์ของ Third Party และตรวจสอบว่าข้อมูลที่คู่สัญญาสามารถเข้าถึงได้ถูกจำกัดตามหลัก Least Privilege ควรกำหนดการตรวจจับ Automated Query หรือปริมาณการเรียกข้อมูลผิดปกติ และมีขั้นตอนระงับสิทธิ์ได้อย่างรวดเร็ว หากพบพฤติกรรมผิดปกติให้เก็บ Log และหลักฐานเพื่อใช้ในการสืบสวนก่อนแก้ไขหรือปิดช่องทาง

01 สถานการณ์

FortiGuard Labs รายงานมัลแวร์ ClingSTUN ซึ่งทำงานเป็น Back-connect Proxy Backdoor และมุ่งโจมตีอุปกรณ์ Linux/IoT ที่เปิดให้เข้าถึงจากอินเทอร์เน็ตผ่านช่องโหว่ที่ทราบอยู่แล้ว เมื่อเข้าควบคุมอุปกรณ์ได้ มัลแวร์จะสร้าง Persistence และใช้บริการ STUN สาธารณะเพื่อค้นหา Public IP/Port Mapping และรักษาการเชื่อมต่อผ่าน NAT นอกจากนี้ยังมีความสามารถในการแพร่กระจายต่อไปยังอุปกรณ์ที่มีช่องโหว่อื่น

02 ผลกระทบ

อุปกรณ์ที่ถูกยึดอาจถูกนำไปใช้เป็น Proxy เพื่อปกปิดต้นทางของผู้โจมตีหรือสนับสนุนกิจกรรมโจมตีต่อระบบอื่น ทำให้การตรวจสอบต้นทางของ Traffic ทำได้ยากขึ้น และอาจทำให้องค์กรกลายเป็นส่วนหนึ่งของโครงสร้างพื้นฐานโจมตีโดยไม่ทราบ การใช้ STUN ซึ่งเป็น Protocol ที่มีการใช้งานตามปกติในบางบริการยังเพิ่มความยากในการแยก Traffic ที่เป็นอันตรายออกจากการใช้งานที่ถูกต้อง

03 ข้อเสนอแนะ

ให้จัดทำบัญชีอุปกรณ์ Linux/IoT ที่เปิดให้เข้าถึงจากอินเทอร์เน็ต ตรวจสอบ Firmware และช่องโหว่ที่ยังไม่ได้รับการแก้ไข พร้อมปิดบริการที่ไม่จำเป็นและลด Internet Exposure ควรตรวจสอบ STUN/UDP Traffic ร่วมกับ Process ที่ผิดปกติ การเชื่อมต่อออกภายนอก และ Keepalive ที่เกิดซ้ำ โดยไม่ควร Block STUN ทั้งหมดจากชื่อ Protocol เพียงอย่างเดียว หากพบอุปกรณ์ต้องสงสัยให้แยกออกจากเครือข่ายและตรวจสอบ Persistence ก่อนนำกลับมาใช้งาน
