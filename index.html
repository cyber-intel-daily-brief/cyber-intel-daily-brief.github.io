พบการโจมตีสวิตช์ Zyxel GS1900 ผ่านช่องโหว่ที่อาจทำให้ผู้โจมตีสามารถสั่งงานบนอุปกรณ์และใช้เป็นจุดตั้งต้นภายในเครือข่ายได้
CVE-2026-7273CISA KEVActive Exploitation
CRITICAL

สถานการณ์

GreyNoise รายงานแคมเปญโจมตีสวิตช์ Zyxel GS1900 โดยพบการโจมตีอุปกรณ์จำนวน 996 เครื่องใน 48 ประเทศ และมี telemetry ที่ระบุอุปกรณ์ในประเทศไทย 28 เครื่อง ทั้งนี้ มีการเชื่อมโยงการปฏิบัติการกับผู้ดำเนินการที่ใช้ภาษาจีน และมีการกล่าวถึงความเป็นไปได้ของความเกี่ยวข้องกับ Red Heron แต่ข้อมูล attribution ยังควรพิจารณาตามระดับความเชื่อมั่นของแหล่งข้อมูลต้นทาง

ผลกระทบ

หากผู้โจมตีสามารถยึดการควบคุมสวิตช์ได้ อาจใช้เป็นจุดตั้งต้นเพื่อควบคุมหรือสังเกตการสื่อสารภายในเครือข่าย และอาจขยายผลไปยังระบบอื่นที่เชื่อมโยงอยู่ สำหรับประเทศไทย มี telemetry ยืนยันการพบอุปกรณ์ที่เกี่ยวข้อง แต่ไม่พบข้อมูลยืนยันว่าเป็นระบบของหน่วยงานใดโดยเฉพาะ

ข้อเสนอแนะ

ให้ตรวจสอบ Inventory ของ Zyxel GS1900 และเวอร์ชันเฟิร์มแวร์ที่ใช้งานอยู่ พร้อมดำเนินการอัปเดตตามคำแนะนำของผู้ผลิต จำกัดการเข้าถึง Management Interface ให้เฉพาะเครือข่ายผู้ดูแลระบบ และตรวจสอบ Configuration/Command Log รวมถึงพฤติกรรมการเชื่อมต่อย้อนหลัง หากพบ IOC จากแหล่งต้นทางให้เพิ่มเข้าสู่ SIEM/OpenCTI เพื่อใช้ในการ Threat Hunting
GreyNoise

Check Point ยืนยันการโจมตีช่องโหว่ในระบบ Security Management ซึ่งอาจกระทบระบบควบคุมนโยบายความปลอดภัยส่วนกลาง
CVE-2026-93616CVSS 9.8Active Exploitation
CRITICAL

สถานการณ์

Check Point เปิดเผยช่องโหว่ pre-authentication ใน Security Management และระบุว่ามีการนำช่องโหว่ไปใช้โจมตีจริง ช่องโหว่ดังกล่าวอาจเปิดโอกาสให้ผู้โจมตีเข้าถึงระบบบริหารจัดการก่อนผ่านกระบวนการยืนยันตัวตนตามปกติ

ผลกระทบ

ระบบ Security Management เป็นจุดควบคุมนโยบายด้านความปลอดภัยส่วนกลาง หากถูกยึดครองอาจส่งผลต่อการจัดการ Firewall Policy, Object, Rule Base และองค์ประกอบควบคุมอื่นของระบบที่อยู่ภายใต้การบริหารเดียวกัน

ข้อเสนอแนะ

ให้ตรวจสอบรุ่นและระดับ Hotfix/Take ที่ใช้งานอยู่ และติดตั้งการแก้ไขตามประกาศของ Check Point โดยเร็ว จำกัด Management Access ให้เฉพาะเครือข่ายที่เชื่อถือได้ พร้อมตรวจสอบ Audit Log, Login Activity และ Configuration Change ย้อนหลังตาม IOC/แนวทางในเอกสารของผู้ผลิต
Check Point

ผลกระทบ

หาก Orchestrator ถูกยึดครอง ผู้โจมตีอาจสามารถเปลี่ยนแปลง Configuration หรือใช้ศูนย์กลางบริหารจัดการเพื่อกระจายผลกระทบไปยัง Edge devices และหลายสาขาที่อยู่ภายใต้การควบคุมเดียวกัน

มัลแวร์ประเภท Remote Access Trojan สามารถเปิดทางให้ผู้โจมตีควบคุมเครื่อง เก็บข้อมูล และดำเนินการต่อเนื่องภายในระบบได้ โดย TTP ดังกล่าวมีความเกี่ยวข้องกับเป้าหมายภาครัฐและความมั่นคงในภูมิภาค

ข้อเสนอแนะ

Microsoft รายงานแคมเปญ Device Code Phishing ที่มุ่งขโมย Access Token และขยายผลเข้าสู่ Mailbox และบริการ Microsoft 365
Storm-2992Entra IDM365
HIGH

สถานการณ์

Microsoft รายงานการปฏิบัติการที่เกี่ยวข้องกับ EvilTokens/Storm-2992 ซึ่งใช้ Device Code Phishing เพื่อหลอกให้ผู้ใช้งานอนุมัติการเข้าสู่ระบบ จากนั้นผู้โจมตีใช้ Token ที่ได้เพื่อเข้าถึง Mailbox และอาจลงทะเบียนอุปกรณ์หรือดำเนินกิจกรรมเพิ่มเติมใน Microsoft Entra ID

ผลกระทบ

การขโมย Token อาจทำให้ผู้โจมตีเข้าถึงบัญชีได้โดยไม่ต้องทราบรหัสผ่านในช่วงที่ Session/Token ยังใช้งานได้ และอาจนำไปสู่การอ่านอีเมล การตั้งค่า Forwarding Rule หรือการใช้บัญชีเป็นจุดเริ่มต้นในการโจมตีต่อเนื่อง

ข้อเสนอแนะ

ให้ตรวจสอบ Device Code Sign-in, Token Activity, New Device Registration, Mailbox Rule และ OAuth/Graph Activity ที่ผิดปกติ จำกัดหรือปิด Device Code Flow หากไม่มีความจำเป็น ใช้ Conditional Access ให้เหมาะสม และเพิกถอน Session/Token ของบัญชีที่ต้องสงสัย พร้อมทบทวน MFA
