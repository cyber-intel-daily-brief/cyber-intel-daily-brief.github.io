CRITICAL

1. ยืนยันการรันโค้ดจาก PHP2Shell บน Honeypot แล้ว หลังพบ 35 Shell จาก 6 Sensors

CVE-2026-109618PHP2ShellActive Exploitation

นักวิจัยยืนยันเส้นทาง Packet-to-Process ที่สอดคล้องกับ CVE-2026-109618 บน PHP 8.4.26 แบบ Apache mod_php; หลักฐานนี้ยังไม่ยืนยันเส้นทางแยกของ CVE-2026-109619

ประเด็น: Internet-facing PHP / Web Serverสถานะ: ยืนยัน RCE บน Honeypot; ไม่ใช้เป็นหลักฐาน Attributionการดำเนินการ: ตรวจ Log ตามกฎ CISA และเร่งลด Exposure/อัปเดต
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

รายงานทางเทคนิควันที่ 24 ต.ค. ระบุหลักฐานจาก Honeypot 6 Sensors พบ 35 Shell ที่ยืนยันได้บนเป้าหมาย PHP 3 ระบบ โดยสภาพแวดล้อมที่ถูกโจมตีสำเร็จเป็น PHP 8.4.26 แบบ Single-worker Apache mod_php หลักฐาน Packet-to-Process สอดคล้องกับ CVE-2026-109618 แต่ผู้วิจัยระบุชัดว่ายังไม่สามารถแยกยืนยันเส้นทางของ CVE-2026-109619 ได้

ผลกระทบ

องค์กรที่เปิด PHP ต่ออินเทอร์เน็ตอาจถูกสั่งรันคำสั่งในบริบทของ Web Server หากเข้าเงื่อนไขที่ได้รับผลกระทบ การพบ Shell บน Honeypot ทำให้ความเสี่ยงเปลี่ยนจากเชิงทฤษฎีเป็นกิจกรรมที่ยืนยันแล้ว แต่แหล่งที่มาของ Traffic ไม่ใช่หลักฐานระบุตัวผู้โจมตี

ข้อเสนอแนะ

ตรวจสอบ Web และ Process Logs ด้วยกฎ SIGMA ที่ CISA เผยแพร่ แยกและเก็บหลักฐานจากเครื่องต้องสงสัย จำกัดการเข้าถึง PHP จากอินเทอร์เน็ต และอัปเดตตามคำแนะนำของผู้ดูแล PHP/ระบบปฏิบัติการ ห้ามสรุปว่าปลอดภัยจากการไม่พบ IOC เพียงชุดเดียว

ยืนยันหลักฐาน 24 ต.ค. 2569; รายงานสรุป 26 ต.ค. 2569

2. Wasmtime ออกแพตช์ช่องโหว่ Sandbox Escape ระดับ 9.9 สองรายการ

CVE-2026-115889CVE-2026-115893WebAssembly

CVE-2026-115889 กระทบ Cranelift ทุกสถาปัตยกรรมในสายรุ่นก่อน 43 บางช่วง และ CVE-2026-115893 กระทบ AArch64 หลายรุ่น; ยังไม่มีรายงานการโจมตีจริง

ประเด็น: Cloud Runtime / Application Sandboxสถานะ: มีแพตช์; ยังไม่พบ In-the-Wild Exploitationการดำเนินการ: สำรวจ Wasmtime แบบฝังและ Rebuild ด้วยรุ่นแก้ไข
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Bytecode Alliance เปิดเผยช่องโหว่ระดับ Critical สองรายการใน Cranelift ของ Wasmtime รายการแรกทำให้การจัดดัชนี SSA ล้นและ Miscompile จนอาจ Escape Sandbox ได้บนทุกสถาปัตยกรรม ส่วนรายการที่สองทำให้คำสั่ง br_table ขนาดใหญ่มากกระโดดไปยังตำแหน่งที่ผู้โจมตีควบคุมบน AArch64 ทั้งสองรายการมี CVSS 9.9 และต้องอาศัยโมดูล Wasm ที่สร้างขึ้นเฉพาะ

ผลกระทบ

บริการที่รัน Wasm จากผู้ใช้หรือแหล่งที่ไม่ไว้วางใจอาจสูญเสียขอบเขตการแยก Sandbox และกระทบความลับ ความถูกต้อง และความพร้อมใช้งานของ Host Process ความเสี่ยงสูงเป็นพิเศษสำหรับ Multi-tenant Runtime และ Plugin Platform

ข้อเสนอแนะ

สำหรับสาย 36 อัปเดตเป็น 36.0.19; สำหรับ AArch64 สาย 48/49 ให้อัปเดตอย่างน้อย 48.0.7 หรือ 49.0.4 และสายใหม่ใช้ 50.0.0 ขึ้นไปตามประกาศ สำรวจผลิตภัณฑ์ที่ฝัง Wasmtime เพราะต้อง Rebuild Application ไม่ใช่เพียงอัปเดตแพ็กเกจบนเครื่อง

3. แคมเปญ Replay Token เจาะ Microsoft 365 อย่างน้อย 79 องค์กร

Microsoft 365Token ReplayBusiness Email Compromise

Huntress พบ 497 Successful Sign-ins จาก Token ที่ขโมยผ่าน AiTM, Device-code Phishing และ Social Engineering พร้อมอุปกรณ์ Entra ปลอมอย่างน้อย 48 เครื่อง

ประเด็น: Identity / Cloud Emailสถานะ: ยืนยันการบุกรุกหลายองค์กรช่วง 14 ก.ค.–22 ก.ย.การดำเนินการ: Revoke Sessions และตรวจ MFA, Entra Devices, Inbox Rules
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Huntress รายงานแคมเปญสิบสัปดาห์ที่นำ Session หรือ Token หลังผ่าน MFA มา Replay ต่อ Microsoft 365 พบเหตุที่ตอบสนองใน 79 องค์กร รวม 497 Successful Sign-ins จากความพยายามมากกว่า 200,000 ครั้ง ผู้โจมตีลงทะเบียนอุปกรณ์ Entra ปลอมอย่างน้อย 48 เครื่อง เปลี่ยนวิธี MFA และสร้าง Inbox Rules เพื่อซ่อนอีเมล

ผลกระทบ

การเปลี่ยนรหัสผ่านเพียงอย่างเดียวอาจไม่ตัดการเข้าถึง หาก Session, อุปกรณ์ หรือวิธี MFA ที่ผู้โจมตีเพิ่มยังคงอยู่ บัญชีที่ถูกยึดอาจถูกใช้เพื่อฉ้อโกงทางอีเมล ซ่อนการสนทนา และรักษาการเข้าถึงระยะยาว

ข้อเสนอแนะ

เพิกถอน Sessions พร้อม Reset รหัสผ่าน ตรวจและลบอุปกรณ์ Entra กับวิธี MFA ที่ไม่รู้จัก ตรวจ Inbox Rules และ Enterprise Applications บังคับ Conditional Access ครอบคลุมผู้ใช้ แอป และ Client ทุกชนิด และจำกัด Device-code Flow ตามความจำเป็น

4. มหาวิทยาลัยโคเปนเฮเกนแจ้งข้อมูลบุคคลราว 525,000 รายถูกเข้าถึง

Data BreachEducationPersonal Data

ผู้โจมตีเข้าถึงฐานข้อมูลในระบบทดสอบซึ่งมีข้อมูลระบุตัวบุคคลย้อนหลังหลายสิบปี; มหาวิทยาลัยระบุว่ายังไม่พบผลกระทบต่อระบบปฏิบัติการหลัก

ประเด็น: Data Protection / Educationสถานะ: เหตุการณ์ถูกควบคุมและแจ้งหน่วยงานคุ้มครองข้อมูลเดนมาร์กการดำเนินการ: ประเมินผู้เกี่ยวข้องและเตรียมรับ Phishing/Identity Fraud
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

มหาวิทยาลัยโคเปนเฮเกนระบุว่าผู้โจมตีเข้าถึงระบบทดสอบที่มีข้อมูลของบุคคลประมาณ 525,000 ราย รวมถึงชื่อ หมายเลขประจำตัวประชาชน และข้อมูลติดต่อในบางกรณี อีกทั้งพบว่าข้อมูล PIN ของนักศึกษาและพนักงานประมาณ 20,000 รายอาจได้รับผลกระทบ เหตุการณ์ถูกควบคุมและรายงานต่อหน่วยงานคุ้มครองข้อมูลแล้ว

ผลกระทบ

ข้อมูลระบุตัวบุคคลสามารถถูกนำไปใช้สร้าง Phishing ที่น่าเชื่อถือหรือประกอบการฉ้อโกงตัวตนได้ อย่างไรก็ดี ประกาศมหาวิทยาลัยระบุว่ายังไม่พบว่าระบบปฏิบัติการหลักถูกบุกรุกหรือบริการหยุดชะงัก

ข้อเสนอแนะ

องค์กรการศึกษาควรแยกข้อมูลจริงออกจาก Test Environment ลดอายุข้อมูลและสิทธิ์เข้าถึง ตรวจการนำข้อมูล Production ไปใช้ทดสอบ และเตรียมการสื่อสารกับผู้ได้รับผลกระทบ ผู้ใช้งานควรระวังข้อความที่อ้างข้อมูลส่วนบุคคลเพื่อขอรหัสผ่านหรือ PIN

MagentoE-commerceWeb Skimmer

สถานการณ์

6. DreamHost บังคับรีเซ็ตรหัสผ่าน Email และ FTP/SFTP บางบัญชีระหว่างแก้เหตุขัดข้อง

สถานการณ์

หน้า Status ของ DreamHost ระบุ Service Disruption และกำหนดให้เจ้าของบัญชีรีเซ็ตรหัสผ่านสำหรับผู้ใช้ Email และ FTP/SFTP บางส่วน โดยส่งคำแนะนำไปยังเจ้าของบัญชีที่ได้รับผลกระทบแล้ว ผู้ใช้กลุ่มดังกล่าวจะเข้าสู่ระบบไม่ได้จนกว่าจะตั้งรหัสผ่านใหม่ ขณะเดียวกันบริษัทระบุว่าได้ผลักดันการแก้ไข File Manager และกำลังติดตามผล

ผลกระทบ

องค์กรที่ใช้ DreamHost อาจประสบปัญหาเข้าถึง Email หรือ File Transfer และมีความเสี่ยงจากข้อความปลอมที่ฉวยโอกาสอ้างขั้นตอนรีเซ็ตรหัสผ่าน ยังไม่มีข้อมูลจากต้นทางเพียงพอให้สรุปว่าเป็น Data Breach หรือข้อมูลถูกขโมย
