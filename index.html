1. cPGuard Update Channel ถูกยึดเพื่อส่ง Malicious Update ไปยัง Linux Server

cPGuardSupply ChainCredential Theft

ผู้โจมตีใช้โครงสร้าง Update ของ OPSSHIELD แจก Script ที่ทำงานด้วยสิทธิ Root ใน cPGuard 5.88.12–5.88.19 และมีข้อมูลบางส่วนถูกดึงออกไป

สถานะ: เร่งกู้คืนและหมุนเวียน Credentialเผยแพร่: OPSSHIELD 3 พ.ย.; รายงานเพิ่มเติม 4 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

OPSSHIELD เปิดเผยว่าผู้โจมตีเข้าถึง Billing/Licensing Infrastructure และขโมยสิทธิสำหรับเผยแพร่ Update ก่อนส่ง Malicious Script ผ่าน cPGuard Update Channel เมื่อ 2 พฤศจิกายน รุ่น 5.88.12–5.88.19 อยู่ในช่วงได้รับผลกระทบ และบริษัทตรวจพบว่าผู้โจมตีดึงข้อมูลบางส่วนที่ Script รวบรวมจาก Licensing Server

ผลกระทบ

Script ทำงานด้วยสิทธิ Root และอาจรวบรวมรหัสผ่านระบบ ค่า MariaDB/MySQL, Command History และข้อมูล SSH การอัปเดตเพื่อลบ Backdoor ไม่สามารถยกเลิกความเสี่ยงจาก Credential ที่อาจถูกขโมยแล้ว

ข้อเสนอแนะ

อัปเดต cPGuard เป็น 5.88.25 หรือใหม่กว่า ตรวจ Update History และไฟล์ที่ Advisory ระบุ หมุนเวียนรหัสผ่านฐานข้อมูล Cloud Account และ SSH Key จากระบบที่เชื่อถือได้ พร้อมตรวจการเข้าถึงย้อนหลังและแยก Server ที่สงสัย

OPSSHIELD 3 พ.ย.; รายงานเพิ่มเติม 4 พ.ย. 2569
