1. GitLab เตือนช่องโหว่ CVE-2026-85706 ถูกใช้โจมตีจริง

Cybersecurity12 ต.ค. 2569

GitLab ยืนยันว่าช่องโหว่ Path Traversal ระดับ CVSS 10.0 ถูกเพิ่มในบัญชี CISA KEV และพบการใช้โจมตีระบบจริง ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนอาจอ่านไฟล์บนเซิร์ฟเวอร์ GitLab แบบติดตั้งเองได้

ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

01 สถานการณ์

GitLab ออกข้อมูลตรวจจับเพิ่มเติมหลัง CVE-2026-85706 ถูกเพิ่มใน CISA Known Exploited Vulnerabilities ช่องโหว่อยู่ใน repository commits API และกระทบ GitLab CE/EE รุ่นที่อยู่ในช่วงตามประกาศ ผู้ให้บริการระบุว่า GitLab.com และ GitLab Dedicated ได้รับการแก้ไขแล้ว

02 ผลกระทบ

ไฟล์ที่อ่านได้อาจรวมข้อมูลตั้งค่า Token หรือความลับของ CI/CD ซึ่งสามารถนำไปใช้ขยายผลเข้าสู่ซอร์สโค้ด ระบบส่งมอบซอฟต์แวร์ หรือ Cloud ได้

03 ข้อเสนอแนะ

ผู้ใช้ Self-managed GitLab ควรอัปเดตเป็นรุ่นแก้ไขตามประกาศทันที หมุนเวียนความลับที่อาจถูกอ่าน ตรวจ Log ตามกฎตรวจจับของ GitLab และแยกระบบที่พบพฤติกรรมต้องสงสัย

01 สถานการณ์

Intermarché และผู้ค้าปลีกรายอื่นรายงานว่าหน่วยแสดงสินค้าแช่เย็นและแช่แข็งหยุดทำงานหลังผู้ให้บริการระบบทำความเย็นถูกโจมตี เหตุกระทบร้านค้าหลายร้อยแห่ง และทางการฝรั่งเศสกำลังสอบสวนขอบเขตและความเชื่อมโยงของความเสียหาย

02 ผลกระทบ

ความเสี่ยงครอบคลุมความปลอดภัยของอาหาร การหยุดบริการ ความสูญเสียสินค้า และความปลอดภัยทางกายภาพจากความร้อนหรือเพลิงไหม้ เหตุนี้แสดงให้เห็นผลกระทบจากระบบ OT/IoT ที่เชื่อมต่อระยะไกล

03 ข้อเสนอแนะ

สำรวจระบบควบคุมความเย็นที่เปิดสู่อินเทอร์เน็ต จำกัดการเข้าถึงผ่าน VPN และ MFA แยกเครือข่าย OT ตรวจบัญชีผู้ให้บริการภายนอก และเตรียมแผนควบคุมอุณหภูมิแบบ Manual พร้อมการแจ้งเตือนนอกระบบ

การสอบสวนพบแผงวงจรเพิ่มเติมภายในอุปกรณ์ ซึ่งอาจดักข้อมูลที่แสดงระหว่างตั้งค่าและส่งออกผ่านการสื่อสารของตัวเอง Ledger ขอให้ผู้ค้าปลีกที่เกี่ยวข้องหยุดจำหน่ายระหว่างสอบสวนและติดต่อผู้ได้รับผลกระทบ

02 ผลกระทบ

03 ข้อเสนอแนะ

ซื้ออุปกรณ์จากผู้ผลิตหรือช่องทางที่ได้รับอนุญาต ตรวจซีลและความผิดปกติทางกายภาพ ห้ามใช้ Seed Phrase ที่เคยแสดงบนอุปกรณ์ต้องสงสัย และย้ายสินทรัพย์ไปยังกระเป๋าใหม่จากอุปกรณ์ที่เชื่อถือได้หากพบความผิดปกติ

5. Telegram Desktop ก่อน 7.2.9 เสี่ยงส่งไฟล์ออกเมื่อคลิกลิงก์ที่สร้างขึ้นเฉพาะ

Cybersecurity12 ต.ค. 2569

CVE-2026-107181 เป็นช่องโหว่การแทรกคำสั่งผ่าน IPC ใน Telegram Desktop ก่อนรุ่น 7.2.9 ผู้โจมตีอาจล่อให้ผู้ใช้คลิกลิงก์ tg:// ที่สร้างขึ้นเฉพาะเพื่อส่งไฟล์ในเครื่องออกไปโดยไม่ต้องยืนยันเพิ่มเติม

ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

01 สถานการณ์

ช่องโหว่เกิดจากการจัดการ Record Separator ไม่เหมาะสมในกลไก Single-instance IPC และต้องอาศัยการโต้ตอบของผู้ใช้ มีการเผยแพร่ข้อมูลโดย CNA และมีการแจ้งเตือนในช่องทาง Telegram ที่อ้างถึงรุ่นก่อน 7.2.9

02 ผลกระทบ

ไฟล์ภายในเครื่องรวมถึงข้อมูล Session อาจถูกส่งไปยังบัญชีหรือช่องทางของผู้โจมตี ส่งผลต่อความลับของการสื่อสารและอาจนำไปสู่การยึดบัญชี

03 ข้อเสนอแนะ

อัปเดต Telegram Desktop เป็น 7.2.9 หรือใหม่กว่า หลีกเลี่ยงลิงก์ tg:// จากแหล่งไม่รู้จัก ตรวจ Session ที่เข้าสู่ระบบอยู่ และเพิกถอน Session ผิดปกติ

6. AvisLoader ใช้ Tox แบบ Peer-to-Peer เพื่อลดผลจากการยึดโดเมนควบคุม

Cybersecurity12 ต.ค. 2569

Varonis Threat Labs วิเคราะห์ AvisLoader ซึ่งเป็นมัลแวร์โหลดเดอร์บน Windows ที่ใช้เครือข่าย Tox แบบ Peer-to-Peer เป็นช่องทางสั่งการ และพบเครื่องมือ ClickFix ในโครงสร้างพื้นฐานที่ตรวจพบ

ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

01 สถานการณ์

นักวิจัยพบ Loader แผงควบคุม และหน้า ClickFix บนเซิร์ฟเวอร์ Staging ที่เปิดเผย AvisLoader ออกแบบให้ไม่พึ่งโดเมน C2 แบบเดิม จึงทำให้การปิดโดเมนหรือ Sinkhole เพียงอย่างเดียวมีข้อจำกัด

02 ผลกระทบ

เครื่องที่ติดเชื้อสามารถรับคำสั่งและดาวน์โหลด Payload เพิ่มเติมผ่านช่องทางที่กระจายตัว ทำให้การสกัดกั้นด้วย Domain blocklist อย่างเดียวอาจไม่เพียงพอ

03 ข้อเสนอแนะ

อบรมผู้ใช้ไม่ให้รันคำสั่งจากหน้าเว็บที่อ้างว่าแก้ CAPTCHA ใช้ EDR ตรวจ PowerShell/Command Prompt ที่ถูกเปิดจากเบราว์เซอร์ ควบคุมการใช้ Tox ที่ไม่จำเป็น และใช้ Network behavior analytics ร่วมกับ Endpoint telemetry
