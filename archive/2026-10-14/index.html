CRITICAL

1. Ivanti Connect Secure ถูกโจมตีผ่านชุดช่องโหว่ Zero-Day

CVE-2026-104935เปิดเผย 13 ต.ค. 2569

Volexity พบการเชื่อมช่องโหว่เพื่อเข้าถึง VPN โดยไม่ยืนยันตัวตนและขโมยข้อมูลรับรอง ควรอัปเดตพร้อมตรวจสอบร่องรอยการบุกรุก

ประเด็น: CVE-2026-104935สถานะ: นักวิจัยพบการโจมตีจริงการดำเนินการ: อัปเดตและตรวจสอบ Forensics
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Volexity เปิดเผยเมื่อ 13 ตุลาคมว่าพบ UTA0576 ใช้ชุดช่องโหว่บน Ivanti Connect Secure โดยเริ่มพบการใช้โจมตีตั้งแต่ 3 ตุลาคม ผู้โจมตีเข้าถึงระดับ root และมุ่งขโมยข้อมูลรับรองจากอุปกรณ์และ Active Directory. ส่วน Authentication Bypass และ RCE อยู่ภายใต้ CVE-2026-104935 ขณะที่ช่องโหว่ยกระดับสิทธิ์ยังอยู่ระหว่างจัดทำแพตช์ตามรายงานต้นทาง

ผลกระทบ

การเข้าถึงอุปกรณ์ VPN อาจทำให้ข้อมูลรับรองและความลับของเครือข่ายภายในถูกเปิดเผย การประเมินของรายงานนี้คือองค์กรควรตรวจการเคลื่อนย้ายเข้าสู่ระบบอื่นร่วมด้วย

ข้อเสนอแนะ

ติดตั้งแพตช์ตาม Ivanti Advisory โดยเร็ว ตรวจ Network และ Memory Forensics เมื่อสงสัยการบุกรุก ผลตรวจ Integrity Checker ที่ไม่พบความผิดปกติไม่เพียงพอที่จะยืนยันว่าปลอดภัย. ตรวจบัญชีและข้อมูลรับรองที่อุปกรณ์เข้าถึงได้ และหมุนเวียนข้อมูลรับรองเมื่อพบหลักฐานความเสี่ยง

แหล่งข้อมูล:Volexity
HIGH

2. Windows Shell มีช่องโหว่ข้ามการป้องกันที่ถูกใช้โจมตีจริง

CVE-2026-96951เปิดเผย 13 ต.ค. 2569

Microsoft ออกอัปเดต Windows Shell สำหรับ CVE-2026-96951 และ CISA ระบุว่ามีการใช้โจมตีจริง ให้เร่งตรวจการติดตั้งอัปเดต

ประเด็น: CVE-2026-96951สถานะ: CISA ระบุ Active Exploitationการดำเนินการ: ติดตั้ง Security Update
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Microsoft CNA ระบุว่า CVE-2026-96951 เป็นช่องโหว่ข้ามคุณลักษณะความปลอดภัยใน Windows Shell โดยมี CVSS 8.8 ระเบียน CISA ADP ระบุสถานะการโจมตีเป็น active และเพิ่มใน KEV เมื่อ 13 ตุลาคม. Rapid7 อธิบายผลต่อ Mark of the Web และระบุว่าต้องอาศัยผู้ใช้เปิดไฟล์หรือเข้าชมเว็บไซต์ที่เป็นอันตราย

ผลกระทบ

การข้ามกลไกเตือนความเสี่ยงอาจลดโอกาสที่ผู้ใช้ตรวจพบเนื้อหาอันตราย การประเมินของรายงานนี้คือเครื่องที่รับไฟล์จากภายนอกควรได้รับความสำคัญในการแก้ไข

ข้อเสนอแนะ

ตรวจ Windows รุ่นและ Build ที่ใช้งานเทียบกับ MSRC และติดตั้ง Security Update ที่ตรงรุ่น ตรวจยืนยันผลหลังอัปเดตและรีสตาร์ตตามข้อกำหนด. เฝ้าระวังการเปิดไฟล์ต้องสงสัยและพฤติกรรมผิดปกติด้วย Endpoint telemetry

3. GitLab แก้ช่องโหว่ RCE ใน CI/CD Regular Expression Compiler

CVE-2026-97229ประกาศ 12 ต.ค. / ข่าว 13 ต.ค. 2569

GitLab CE/EE แบบติดตั้งเองมีช่องโหว่ CVSS 10.0 ที่อาจให้ผู้ไม่ยืนยันตัวตนรันโค้ดบนเซิร์ฟเวอร์ได้ ผู้ผลิตออกแพตช์แล้ว

ประเด็น: CVE-2026-97229สถานะ: ไม่พบข้อมูลยืนยันการโจมตีจริงการดำเนินการ: อัปเกรดรุ่นแก้ไข
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

GitLab ประกาศแพตช์เมื่อ 12 ตุลาคม และมีข่าวเผยแพร่เมื่อ 13 ตุลาคม ช่องโหว่ CVE-2026-97229 เกี่ยวกับการตรวจ Regular Expression ใน CI/CD ไม่เพียงพอ ซึ่งอาจทำให้รันโค้ดได้ภายใต้เงื่อนไขที่เกี่ยวข้อง. กระทบ CE/EE รุ่น 19.2 ก่อน 19.2.8, 19.3 ก่อน 19.3.5 และ 19.4 ก่อน 19.4.2 ไม่พบข้อมูลยืนยันการโจมตีจริงจากประกาศที่ตรวจ

ผลกระทบ

หากใช้โจมตีสำเร็จ ความลับและความถูกต้องของซอร์สโค้ดหรือระบบ CI/CD อาจได้รับผลกระทบ การประเมินนี้เน้นความเสี่ยงของระบบส่งมอบซอฟต์แวร์ที่เปิดให้เข้าถึงจากภายนอก

ข้อเสนอแนะ

อัปเกรดเป็น 19.2.8, 19.3.5 หรือ 19.4.2 ตามสายรุ่นที่ใช้ หรือรุ่นใหม่กว่าที่แก้ไขแล้ว ตรวจ Pipeline และกิจกรรมผิดปกติย้อนหลัง. หากพบหลักฐานบุกรุก ให้แยกระบบและตรวจความเสี่ยงของ Secrets ที่เกี่ยวข้อง

4. Ghostscript เสี่ยงรันโค้ดจาก PDF ที่สร้างขึ้นเฉพาะ

CVE-2026-39919ข่าวใหม่ 13 ต.ค. / CNA 15 ก.ย. 2569

ข่าววันที่ 13 ตุลาคมทบทวนความเสี่ยงจาก PDF ที่ผ่าน Ghostscript ช่องโหว่เดิมมีแพตช์ใน 10.08.0 แล้ว ต้องตรวจระบบแปลงเอกสารและสร้างภาพตัวอย่าง

ประเด็น: CVE-2026-39919สถานะ: ไม่พบข้อมูลยืนยันการโจมตีจริงการดำเนินการ: ตรวจแพตช์ Ghostscript
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ข่าววันที่ 13 ตุลาคมกล่าวถึง CVE-2026-39919 ซึ่งเปิดเผยในระเบียน CNA ตั้งแต่ 15 กันยายน ช่องโหว่ Heap Buffer Overflow เกิดขณะประมวลผล JPEG 2000 ภายใน PDF และอาจนำไปสู่การรันโค้ด. CNA ระบุรุ่นก่อน 10.08.0 ได้รับผลกระทบ จึงไม่ใช่ช่องโหว่ที่เพิ่งเปิดเผยวันนี้ ไม่พบข้อมูลยืนยันการโจมตีจริงจากแหล่งต้นทางที่ตรวจ

ผลกระทบ

บริการที่รับ PDF จากภายนอกและส่งต่อให้ Ghostscript ประมวลผลอาจได้รับผลกระทบ ขอบเขตการเข้าถึงขึ้นกับแอปพลิเคชันและสิทธิ์ของกระบวนการ ไม่ควรถือว่า WordPress ทุกระบบเปิดให้โจมตีได้โดยไม่ยืนยันตัวตน

ข้อเสนอแนะ

ตรวจ Ghostscript และแพตช์ที่ผู้จัดจำหน่าย Backport ไว้ อัปเดตเป็น 10.08.0 หรือรุ่นที่แก้ไขแล้ว. หากยังแก้ไขไม่ได้ ให้จำกัดการรับ PDF หรือระงับการแปลง PDF ที่ไม่เชื่อถือ และแยกบริการประมวลผลเอกสารจากข้อมูลสำคัญ

แหล่งข้อมูล:VulnCheck CNAArtifex SoftwareBleepingComputer
HIGH

5. Docker Hub แก้การโอน PAT ที่เสี่ยงต่อ Container Supply Chain

CVE-2026-105445ประกาศ 12 ต.ค. / ข่าว 13 ต.ค. 2569

Docker เปิดเผยปัญหาการโอน Personal Access Token ระหว่างแปลงบัญชีเป็นองค์กร แก้ระบบแล้วและไม่พบหลักฐานการใช้โจมตีจากการตรวจสอบ

ประเด็น: CVE-2026-105445สถานะ: ผู้ผลิตไม่พบหลักฐานการใช้โจมตีการดำเนินการ: ตรวจแจ้งเตือนและ PAT
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Docker ประกาศเมื่อ 12 ตุลาคมว่า CVE-2026-105445 อาจทำให้ PAT เดิมถูกโอนไปเป็นของผู้ใช้ที่ถูกกำหนดเป็นเจ้าขององค์กรโดยไม่เปลี่ยน Secret ผู้ถือ Token อาจ Pull, Push หรือ Delete Image ตามสิทธิ์ของ Token. ผู้ผลิตแก้ระบบตั้งแต่ 30 กันยายน แจ้งผู้ได้รับผลกระทบ 2 ตุลาคม และระงับ Token ที่เกี่ยวข้อง 8 ตุลาคมโดยมีข้อยกเว้นตามคำขอ ไม่พบหลักฐานการใช้โจมตีตามการสอบสวน

ผลกระทบ

Image ที่เผยแพร่ภายใต้ชื่อที่เชื่อถือได้อาจถูกเปลี่ยนแปลงหาก Token ถูกนำไปใช้โดยมิชอบ การประเมินของรายงานนี้คือความเสี่ยงครอบคลุมกระบวนการนำ Container เข้าสู่ระบบผลิต

ข้อเสนอแนะ

ตรวจอีเมลแจ้งเตือนของ Docker และทบทวน PAT ในบัญชี เพิกถอน Token ที่ไม่รู้จักหรือไม่ใช้งาน และเลือก Organization Access Token สำหรับงานองค์กร. ผู้ผลิตระบุว่าผู้ที่ไม่ได้รับแจ้งไม่อยู่ในกลุ่มที่ได้รับผลกระทบ และไม่ต้องดำเนินการแก้ไขเฉพาะเหตุนี้
