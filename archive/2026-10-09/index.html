1. สหรัฐฯ ยึดเครื่องมือ Microscan และ FishHub ที่เชื่อมโยงกับ Flax Typhoon

Flax Typhoon infrastructure disruption

APTCritical InfrastructureIndo-Pacific

01 สถานการณ์

กระทรวงยุติธรรมสหรัฐฯ และ FBI ประกาศยึดเครื่องมือ Microscan และ FishHub ตามคำสั่งศาลเมื่อ 8 ต.ค. 2569 เอกสารของสหรัฐฯ กล่าวหาว่าผู้ปฏิบัติการของ Integrity Technology Group ที่เชื่อมโยงกับ Flax Typhoon ใช้เครื่องมือดังกล่าวสแกนและในบางกรณีบุกรุกโครงสร้างพื้นฐานสำคัญและเครือข่ายอื่น การระบุความเชื่อมโยงกับรัฐจีนเป็นข้อกล่าวอ้างและการประเมินของหน่วยงานสหรัฐฯ

02 ผลกระทบ

เครื่องมือสแกนและ Phishing สามารถสนับสนุนการเข้าถึงเครือข่ายและข้อมูลโดยไม่ได้รับอนุญาต การยึดโครงสร้างพื้นฐานไม่ใช่หลักฐานว่าการเข้าถึงที่ผู้โจมตีเคยสร้างไว้ในระบบเหยื่อถูกกำจัดทั้งหมด จึงต้องตรวจสอบระบบภายในควบคู่กัน

03 ข้อเสนอแนะ

ให้ผู้ดูแลโครงสร้างพื้นฐานสำคัญตรวจสอบ Log ของระบบที่เปิดสู่อินเทอร์เน็ตและบัญชีที่มีการเข้าสู่ระบบผิดปกติ ทบทวน MFA และกระบวนการยืนยันข้อความที่ขอข้อมูลรับรอง หากพบหลักฐานการเข้าถึงที่ไม่ได้รับอนุญาต ให้เก็บหลักฐาน แยกระบบ และประสานทีมตอบสนองเหตุการณ์

2. IDCF Cloud ถูก Ransomware กระทบ 495 องค์กรและหน่วยงานท้องถิ่น

IDCF Cloud ransomware and recovery impact

CRITICAL
RansomwareCloudJapan

IDC Frontier ยืนยันเหตุ Ransomware ในบางส่วนของ East Japan Region 1 กระทบผู้ใช้บริการ 495 องค์กรและหน่วยงานท้องถิ่น ประกาศวันที่ 8 ต.ค. ระบุว่าข้อมูลในระบบที่ได้รับผลกระทบอาจนำออกหรือกู้คืนได้ยาก และต้องพึ่งสำรองข้อมูลของลูกค้าเอง

ประเด็น: Ransomwareสถานะ: ผู้ให้บริการยืนยันเหตุการดำเนินการ: ตรวจสำรองข้อมูลและแผนกู้คืน
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

01 สถานการณ์

IDC Frontier อัปเดตสถานการณ์เมื่อ 8 ต.ค. หลังบริการบางส่วนหยุดตั้งแต่ 7 ต.ค. เวลา 03:40 น. ตามเวลาญี่ปุ่น เหตุ Ransomware กระทบ tesla, henry, pascal และ joule ใน East Japan Region 1 โดยมีลูกค้า 495 องค์กรและหน่วยงานท้องถิ่นได้รับผลกระทบ เส้นทางบุกรุกและขอบเขตผลกระทบโดยละเอียดยังอยู่ระหว่างสอบสวน

02 ผลกระทบ

เครื่องเสมือนในส่วนที่ได้รับผลกระทบหยุดและไม่สามารถเริ่มทำงานใหม่ได้ ผู้ให้บริการระบุว่าการนำข้อมูลออกหรือกู้คืนมีแนวโน้มทำได้ยาก และการกู้คืนต้องใช้สำรองข้อมูลที่ลูกค้าถือครองเอง เหตุการณ์นี้จึงเสี่ยงต่อความต่อเนื่องของบริการและการสูญเสียข้อมูล

03 ข้อเสนอแนะ

ให้ผู้ใช้บริการตรวจสอบ Region และ Zone ที่ใช้งาน พร้อมประสานผู้ให้บริการเรื่องการสร้างสภาพแวดล้อมใหม่ ตรวจความครบถ้วนของสำรองข้อมูลที่แยกจากบริการเดิมและทดสอบการกู้คืน สำหรับองค์กรที่ใช้คลาวด์อื่น ให้ทบทวนแผนสำรองข้อมูลนอกระบบและระยะเวลาฟื้นฟูภารกิจ

อัปเดต 8 ต.ค. 2569 · แหล่งข้อมูล:IDC Frontier — ประกาศฉบับที่ 3

3. Cisco NX-OS พบ CVE-2026-76471 อาจรันโค้ดด้วยสิทธิ์ root ผ่าน NX-API

Cisco NX-API remote code execution vulnerability

CRITICAL
CVE-2026-76471CVSS 9.8Network Infrastructure

Cisco เปิดเผยช่องโหว่ใน NX-API ของ NX-OS ซึ่งอาจให้ผู้โจมตีรันโค้ดด้วยสิทธิ์ root หรือทำให้อุปกรณ์หยุดให้บริการบนรุ่นและการตั้งค่าที่ได้รับผลกระทบ Cisco อัปเดต Advisory เมื่อ 8 ต.ค. และระบุว่ายังไม่ทราบถึงการใช้ช่องโหว่นี้โจมตีจริง

ประเด็น: CVE-2026-76471สถานะ: ยังไม่พบการใช้โจมตีตาม Ciscoการดำเนินการ: ตรวจ NX-API และอัปเดตรุ่นแก้ไข
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

01 สถานการณ์

Cisco เผยแพร่ Advisory เมื่อ 7 ต.ค. และอัปเดตเมื่อ 8 ต.ค. สำหรับ CVE-2026-76471 คะแนน CVSS 9.8 กระทบ Nexus 3000 และ Nexus 9000 ในโหมด standalone NX-OS ที่เปิด NX-API และใช้รุ่นที่มีช่องโหว่ สำหรับ UCS 6300 ต้องมีบัญชีสิทธิ์ต่ำและโจมตีผ่าน UCS Manager XML API จึงมีระดับผลกระทบ High ต่างจาก Nexus Cisco ระบุว่ายังไม่ทราบถึงการนำช่องโหว่ไปใช้โจมตี

02 ผลกระทบ

หากโจมตีสำเร็จ ผู้โจมตีอาจรันโค้ดด้วยสิทธิ์ root หรือทำให้กระบวนการล่มและอุปกรณ์เริ่มใหม่ ส่งผลต่อความปลอดภัยและความพร้อมใช้งานของเครือข่าย ความเสี่ยงขึ้นกับรุ่นซอฟต์แวร์และฟีเจอร์ที่เปิดใช้ จึงไม่ควรเหมารวมว่าอุปกรณ์ Cisco ทุกตัวได้รับผลกระทบ

03 ข้อเสนอแนะ

ให้ตรวจรุ่นอุปกรณ์ เวอร์ชันซอฟต์แวร์ และสถานะ NX-API แล้วอัปเดตตาม Fixed Software ใน Advisory ปัจจุบัน จำกัดการเข้าถึง Management API เฉพาะเครือข่ายบริหาร และตรวจ Log ของคำขอผิดปกติหรือการเริ่มใหม่ที่ไม่ทราบสาเหตุ หากพบความผิดปกติ ให้เก็บหลักฐานและประสาน Cisco กับทีมตอบสนองเหตุการณ์

ประกาศ 7 ต.ค.; อัปเดต 8 ต.ค. 2569 · แหล่งข้อมูล:Cisco PSIRT

4. FakeGit ใช้ Repository ลวงบน GitHub แจก SmartLoader

FakeGit malicious repository campaign

HIGH
MalwareDeveloper SecuritySupply Chain

01 สถานการณ์

BleepingComputer รายงาน FakeGit เมื่อ 8 ต.ค. โดยอ้างงานวิจัย Apiiro ที่เผยแพร่ 6 ต.ค. นักวิจัยระบุว่าตรวจพบ Repository ลวง 17,610 รายการ และพบการแก้ README จำนวนมากเพื่อเปลี่ยนปลายทางดาวน์โหลดไปยัง ZIP ที่ติดตั้ง SmartLoader ตัวเลขและขอบเขตดังกล่าวเป็นข้อค้นพบของ Apiiro ณ เวลาวิจัย

02 ผลกระทบ

03 ข้อเสนอแนะ

ให้ตรวจผู้ดูแลโครงการ ประวัติการแก้ไข และปลายทางดาวน์โหลดก่อนรันไฟล์ ใช้ซอฟต์แวร์จากโครงการต้นทางที่ตรวจสอบได้ และประเมินไฟล์ในสภาพแวดล้อมแยก หากเคยรันไฟล์ต้องสงสัย ให้ตรวจเครื่อง แยกออกจากเครือข่ายเมื่อพบหลักฐาน และเปลี่ยนข้อมูลรับรองที่อาจถูกเข้าถึง

6. ASOS ยืนยันข้อมูลลูกค้าถูกเข้าถึงหลังบัญชีพนักงานถูกหลอกขโมย

ASOS credential theft and customer data breach

HIGH
Data BreachSocial EngineeringIdentity Security

ASOS แจ้งลูกค้าว่าผู้โจมตีปลอมเป็นผู้ติดต่อที่ไว้ใจเพื่อขโมยข้อมูลเข้าสู่ระบบพนักงาน แล้วใช้เข้าถึงแพลตฟอร์มภายนอกที่บริษัทใช้ ข้อมูลที่เกี่ยวข้องรวมชื่อและข้อมูลติดต่อ โดยบริษัทระบุว่าข้อมูลบัตรชำระเงินและรหัสผ่านบัญชีลูกค้าไม่ถูกเข้าถึง

ประเด็น: Data Breachสถานะ: คำยืนยัน ASOS ผ่านสื่อการดำเนินการ: เฝ้าระวัง Phishing และตรวจบัญชี
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

01 สถานการณ์

BleepingComputer เผยแพร่คำแจ้งลูกค้าของ ASOS เมื่อ 8 ต.ค. ระบุว่าบัญชีพนักงานถูกเข้าถึงหลังผู้โจมตีปลอมเป็นผู้ติดต่อที่ไว้ใจเพื่อขอข้อมูลรับรอง บัญชีดังกล่าวถูกใช้เข้าถึงข้อมูลบนแพลตฟอร์มภายนอกที่ ASOS ใช้งาน ข้อมูลที่เปิดเผยรวมชื่อ ข้อมูลติดต่อ และข้อมูลเกี่ยวกับบัญชีบางส่วน ขณะนี้ยังไม่พบจำนวนผู้ได้รับผลกระทบที่ยืนยันได้

02 ผลกระทบ

ข้อมูลชื่อและการติดต่ออาจถูกนำไปใช้สร้างข้อความหลอกลวงที่ดูน่าเชื่อถือมากขึ้น ASOS ระบุว่าข้อมูลบัตรชำระเงินและรหัสผ่านลูกค้าไม่ถูกเข้าถึง จึงไม่ควรขยายผลว่าเกิดการขโมยข้อมูลการชำระเงิน การสอบสวนยังดำเนินอยู่

03 ข้อเสนอแนะ

ให้ผู้ใช้ระวังข้อความหรือสายโทรศัพท์ที่อ้างเป็น ASOS และขอรหัสผ่าน รหัสยืนยัน หรือข้อมูลการชำระเงิน สำหรับองค์กร ให้ทบทวนการยืนยันตัวตนผู้ติดต่อ ใช้ MFA ที่ต้าน Phishing และตรวจ Log ของบัญชีที่เชื่อมแพลตฟอร์มภายนอก หากพบการใช้บัญชีผิดปกติ ให้เพิกถอน Session และตรวจสิทธิ์ที่เกี่ยวข้อง
