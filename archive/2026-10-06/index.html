1. Rejetto HFS ถูกนำไปใช้โจมตีเพื่อยึดสิทธิ์ผู้ดูแลระบบและสั่งการจากระยะไกล

CVE-2026-61500 enables forged administrator sessions and remote code execution

CRITICAL
CVE-2026-61500Active ExploitationRemote Code Execution

พบการนำช่องโหว่ CVE-2026-61500 ใน Rejetto HTTP File Server ไปใช้โจมตีจริง โดยผู้โจมตีสามารถสร้าง Administrator Session ปลอมและใช้สิทธิ์ดังกล่าวสั่งการระบบจากระยะไกลได้ ระบบ HFS ที่เปิดให้เข้าถึงจากอินเทอร์เน็ตและยังไม่ได้อัปเดตควรได้รับการตรวจสอบโดยเร่งด่วน

01 สถานการณ์

VulnCheck เปิดเผยช่องโหว่ CVE-2026-61500 ใน Rejetto HTTP File Server รุ่น 3.0.0 ถึงก่อน 3.2.1 ซึ่งเกิดจากการใช้ตัวสร้างค่าสุ่มที่ไม่เหมาะสมสำหรับ Session Signing Key และมีการเปิดเผยค่าที่เกี่ยวข้องต่อผู้ใช้ที่ยังไม่ยืนยันตัวตน ผู้โจมตีสามารถนำข้อมูลดังกล่าวไปคำนวณ Signing Key และสร้าง Administrator Session ปลอม ก่อนใช้ฟังก์ชันของระบบเพื่อสั่งการจากระยะไกลได้ ต่อมามีรายงานว่าช่องโหว่นี้ถูกนำไปใช้โจมตีจริงแล้ว

02 ผลกระทบ

หากโจมตีสำเร็จ ผู้โจมตีอาจได้รับสิทธิ์ผู้ดูแลระบบของ HFS เข้าถึง แก้ไข หรือนำไฟล์ออกจากระบบ รวมถึงติดตั้งมัลแวร์และใช้เครื่องแม่ข่ายเป็นจุดเริ่มต้นในการขยายการโจมตีไปยังระบบอื่นภายในเครือข่าย ความเสี่ยงจะสูงเป็นพิเศษเมื่อ HFS เปิดบริการจากอินเทอร์เน็ตโดยตรง

03 ข้อเสนอแนะ

ให้ตรวจสอบว่ามี Rejetto HFS อยู่ในการใช้งานหรือไม่ โดยเฉพาะระบบที่เปิดจากอินเทอร์เน็ต หากพบรุ่นที่ได้รับผลกระทบให้ปรับปรุงเป็นรุ่น 3.2.1 หรือใหม่กว่าโดยเร็ว พร้อมตรวจสอบ Administrator Session, Login Log และคำสั่งที่ถูกเรียกใช้งานย้อนหลัง หากพบพฤติกรรมผิดปกติให้แยกระบบ เก็บหลักฐาน และดำเนินการตรวจสอบตามกระบวนการตอบสนองเหตุการณ์

2. Citrix NetScaler พบ Zero-Day ที่ถูกนำไปใช้โจมตีระบบ SAML

CVE-2026-88779 affects NetScaler ADC/Gateway configured as SAML SP or IdP

HIGH
CVE-2026-88779Zero-DayNetScaler

Citrix เปิดเผยช่องโหว่ CVE-2026-88779 ใน NetScaler ADC และ NetScaler Gateway ที่ใช้งาน SAML และยืนยันว่ามีการโจมตีระบบที่ยังไม่ได้รับการแก้ไขแล้ว ผลกระทบที่ผู้ผลิตยืนยันในขณะนี้คือการทำให้บริการหยุดชะงัก

ประเด็น: Remote Access / SAMLสถานะ: Exploited in the Wildการดำเนินการ: Patch เร่งด่วน

01 สถานการณ์

Citrix เปิดเผยช่องโหว่ CVE-2026-88779 ใน NetScaler ADC และ NetScaler Gateway ซึ่งเป็นปัญหา Memory Overflow ที่กระทบระบบที่ตั้งค่าเป็น SAML Service Provider หรือ SAML Identity Provider รุ่นที่ได้รับผลกระทบรวมถึง NetScaler 14.1 ก่อน 14.1-73.41 และ 13.1 ก่อน 13.1-64.28 ตามสาขาผลิตภัณฑ์ Citrix ระบุว่าพบการโจมตีระบบที่ยังไม่ได้รับการแก้ไข โดยผลกระทบที่ยืนยันคือ Denial of Service และยังไม่มีข้อมูลทางการยืนยันว่าใช้ทำ Remote Code Execution ได้

02 ผลกระทบ

หากระบบที่ได้รับผลกระทบยังไม่ได้รับการแก้ไข ผู้โจมตีอาจทำให้บริการ NetScaler ไม่พร้อมใช้งานซ้ำ ๆ ส่งผลต่อระบบ Remote Access การยืนยันตัวตน หรือบริการที่พึ่งพา NetScaler ในการเชื่อมต่อจากภายนอก เหตุการณ์ดังกล่าวอาจกระทบต่อความต่อเนื่องในการปฏิบัติงานขององค์กร โดยเฉพาะระบบที่เป็นจุดเชื่อมต่อหลักจากอินเทอร์เน็ต

03 ข้อเสนอแนะ

ให้ตรวจสอบการตั้งค่า NetScaler ADC/Gateway ว่าตรงตามเงื่อนไข SAML ที่ได้รับผลกระทบหรือไม่ และอัปเดตเป็นรุ่นแก้ไขตาม Citrix Security Bulletin โดยเร็ว ควรตรวจสอบเหตุการณ์ Restart, Crash และ Log ที่ผิดปกติย้อนหลัง พร้อมจำกัดช่องทางบริหารจัดการให้เข้าถึงได้เฉพาะเครือข่ายที่ได้รับอนุญาต หากพบหลักฐานการโจมตีให้ดำเนินการตรวจสอบเพิ่มเติมก่อนนำระบบกลับมาใช้งานตามปกติ

3. เกาหลีใต้ยกระดับรับมือเหตุโจมตีไซเบอร์ต่อสถาบันการเงินหลายแห่ง

South Korea orders sector-wide security reviews after multiple financial-sector intrusions

HIGH
South KoreaFinancial SectorIndo-Pacific

01 สถานการณ์

Financial Services Commission (FSC) ของเกาหลีใต้เรียกประชุมฉุกเฉินร่วมกับหน่วยงานกำกับดูแลและสถาบันการเงิน หลังพบเหตุข้อมูลรั่วไหลและการโจมตีทางไซเบอร์ต่อสถาบันการเงินหลายแห่ง ทางการสั่งให้ตรวจสอบระบบและบริการที่เปิดสู่ภายนอก รวมถึง Authentication และ Access Control พร้อมแบ่งปันข้อมูลภัยคุกคามระหว่างหน่วยงาน ขณะเดียวกันมีรายงานจากสื่อและนักวิเคราะห์เกี่ยวกับความเป็นไปได้ที่เครื่องมือ AI อาจถูกใช้ช่วยโจมตี แต่หน่วยงานทางการยังไม่ได้ยืนยันประเด็นดังกล่าว

02 ผลกระทบ

เหตุการณ์ที่เกิดขึ้นกับหลายสถาบันในช่วงเวลาใกล้เคียงกันสะท้อนความเสี่ยงจาก External-facing Systems หรือระบบสนับสนุนที่อาจได้รับการดูแลน้อยกว่าระบบหลัก หากข้อมูลลูกค้าถูกนำไปใช้ต่อ อาจเพิ่มความเสี่ยงต่อ Phishing, Smishing และการหลอกลวงแบบเจาะจง เหตุการณ์นี้มีความเกี่ยวข้องต่อภูมิภาค Indo-Pacific โดยตรงเนื่องจากเกิดกับโครงสร้างพื้นฐานทางการเงินในเอเชีย

03 ข้อเสนอแนะ

ให้หน่วยงานตรวจสอบรายการระบบและบริการที่เปิดให้เข้าถึงจากภายนอก รวมถึง Server หรือ Web Application ที่ใช้สนับสนุนงานภายใน ตรวจสอบ Authentication, Access Control และข้อมูลที่สามารถเรียกดูได้ให้เหลือเท่าที่จำเป็น ควรเพิ่มการเฝ้าระวังการสแกนและการเข้าถึงผิดปกติจากภายนอก พร้อมเตรียมมาตรการป้องกันการนำข้อมูลรั่วไหลไปใช้ใน Social Engineering หากพบเหตุผิดปกติ

4. Midnight Blizzard กลับมาใช้ Captive Portal ส่งมัลแวร์และขโมยข้อมูลผู้เดินทาง

Microsoft observes renewed CaptiveCrunch activity against hospitality networks and travelers

HIGH
Midnight BlizzardCredential TheftHospitality Wi-Fi

01 สถานการณ์

Microsoft Threat Intelligence ระบุว่าเมื่อวันที่ 29 กันยายนพบ Storm-2945 ซึ่งเป็นกลุ่มย่อยของ Midnight Blizzard กลับมาดำเนินแคมเปญ CaptiveCrunch โดยใช้การดัดแปลง DNS/HTTP Traffic และ Captive Portal ในภาค Hospitality เพื่อเปลี่ยนเส้นทางผู้ใช้ไปยังโครงสร้างพื้นฐานของผู้โจมตี แคมเปญนี้สามารถส่งมัลแวร์ที่ปลอมเป็น Browser หรือ OS Update รวมถึงใช้ Device Code Phishing เพื่อขโมย Session และเข้าถึง Microsoft 365 Microsoft ประเมินว่า Storm-2945 เชื่อมโยงกับ Midnight Blizzard และมีการใช้ AI สนับสนุนบางส่วนของปฏิบัติการ

02 ผลกระทบ

ผู้ใช้งานที่เชื่อมต่อ Wi-Fi ของโรงแรม ศูนย์ประชุม หรือเครือข่ายสาธารณะอาจถูกหลอกให้ติดตั้งมัลแวร์หรือยืนยัน Device Code ให้กับ Session ของผู้โจมตี หากสำเร็จ ผู้โจมตีอาจขโมย Credential, Session Token และข้อมูลจากอุปกรณ์ รวมถึงเข้าถึงบริการ Cloud ขององค์กรโดยไม่ต้องรู้รหัสผ่านโดยตรง ความเสี่ยงมีความสำคัญต่อบุคลากรที่เดินทางและต้องเข้าถึงระบบงานจากเครือข่ายภายนอก

03 ข้อเสนอแนะ

ให้ถือเครือข่าย Wi-Fi สาธารณะและ Hospitality เป็นเครือข่ายที่ไม่น่าเชื่อถือ และหลีกเลี่ยงการติดตั้ง Software Update, Certificate หรือเครื่องมือแก้ไขระบบจากหน้า Captive Portal ควรใช้ Mobile Hotspot หรือการเชื่อมต่อที่องค์กรควบคุมเมื่อเข้าถึงข้อมูลสำคัญ พร้อมใช้ Passkey หรือ Phishing-resistant MFA และเฝ้าระวัง Device Code Authentication, Session Token และ Sign-in ที่ผิดปกติ

Dell เปิดเผยช่องโหว่ CVE-2026-86360 ใน Dell System Update (DSU) รุ่นก่อน 2.3.0.0 ซึ่งเป็นเครื่องมือสำหรับบริหารการอัปเดต BIOS, Firmware และ Software บนโครงสร้างพื้นฐาน Server ช่องโหว่เป็น Path Traversal และได้รับคะแนน CVSS 9.6 โดยผู้ผลิตระบุว่าผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนและมี Remote Access อาจใช้ช่องโหว่เพื่อเข้าถึง File System และรันโค้ดด้วยสิทธิ์ Root ได้ ปัจจุบันไม่พบข้อมูลยืนยันจาก Dell ว่ามีการนำช่องโหว่นี้ไปใช้โจมตีจริง

02 ผลกระทบ

หากถูกโจมตีสำเร็จ ผู้โจมตีอาจเข้าควบคุม Application และระบบปฏิบัติการที่เกี่ยวข้องในระดับสูงสุด แก้ไขไฟล์สำคัญ ติดตั้งเครื่องมือเพิ่มเติม หรือนำ Server ไปใช้เป็นฐานสำหรับการโจมตีระบบอื่น ความเสี่ยงจะเพิ่มขึ้นในองค์กรที่ใช้ DSU บริหาร PowerEdge Server จำนวนมากหรือเปิดช่องทางบริหารจัดการจากเครือข่ายที่ไม่จำเป็น

03 ข้อเสนอแนะ

ให้ตรวจสอบ Dell System Update ที่ติดตั้งบนเครื่องแม่ข่ายทั้งหมด และอัปเดตเป็นรุ่น 2.3.0.0 หรือใหม่กว่าตามคำแนะนำของ Dell พร้อมจำกัดการเข้าถึงระบบบริหารจัดการจากเครือข่ายภายนอก ตรวจสอบการเปลี่ยนแปลงไฟล์และคำสั่งที่ใช้สิทธิ์สูงย้อนหลัง หากพบพฤติกรรมผิดปกติให้ดำเนินการตรวจสอบเครื่องแม่ข่ายก่อนนำกลับเข้าสู่การใช้งานปกติ

01 สถานการณ์

Microsoft เปิดเผยช่องโหว่ CVE-2026-96940 ใน Microsoft Exchange Server ซึ่งเกิดจากการควบคุมสิทธิ์ที่ไม่เพียงพอ และเพิ่มการแก้ไขไว้ใน Security Update รุ่น V2 สำหรับ Exchange Server ที่ได้รับผลกระทบ ผู้โจมตีจำเป็นต้องมีการยืนยันตัวตนก่อนจึงจะใช้ช่องโหว่ได้ และอาจเข้าถึง Mailbox ของผู้ใช้อื่นภายในองค์กรเดียวกันเพื่ออ่านข้อความและไฟล์แนบได้ Microsoft ระบุว่ายังไม่พบการโจมตีจริงในขณะเผยแพร่

02 ผลกระทบ

หากผู้โจมตีมีบัญชีในระบบอยู่แล้ว การใช้ช่องโหว่อาจทำให้ขอบเขตการเข้าถึงข้อมูลขยายไปยัง Mailbox ของบุคลากรรายอื่น ส่งผลต่อความลับของอีเมล เอกสารแนบ และข้อมูลภายในองค์กร ช่องโหว่นี้อาจถูกใช้ร่วมกับบัญชีที่ถูกขโมยเพื่อรวบรวมข้อมูลสำหรับ Phishing แบบเจาะจงหรือ Business Email Compromise

03 ข้อเสนอแนะ

สำหรับ Exchange Server แบบ On-premises ให้ตรวจสอบรุ่นที่ใช้งานและติดตั้ง Security Update V2 ที่ Microsoft กำหนดโดยเร็ว พร้อมตรวจสอบ Audit Log และ Account ที่มีพฤติกรรมเข้าถึง Mailbox ผิดปกติ Exchange Online ได้รับการแก้ไขฝั่งบริการแล้ว แต่หน่วยงานที่ยังมี Exchange Server หรือ Exchange Management Tools ภายในองค์กรควรตรวจสอบสถานะการอัปเดตให้ครบถ้วน

01 สถานการณ์

Central Population Register (CPR) ของเดนมาร์กประกาศเมื่อวันที่ 5 ตุลาคมว่าพบการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาตในระบบทะเบียนประชาชน โดยมีการใช้สิทธิ์ที่บริษัทเอกชนแห่งหนึ่งได้รับอนุญาตอย่างถูกต้องเพื่อค้นข้อมูลใน CPR และเข้าถึงชื่อ ที่อยู่ หมายเลข CPR และข้อมูลที่เกี่ยวข้องของผู้ลงทะเบียนประมาณ 8.8 ล้านรายการ CPR ได้ระงับสิทธิ์ของบริษัทดังกล่าวและประสานหน่วยงานคุ้มครองข้อมูลกับตำรวจเพื่อสอบสวนเหตุการณ์

02 ผลกระทบ

ข้อมูลประจำตัวจำนวนมากที่ถูกเข้าถึงอาจถูกนำไปใช้ประกอบการหลอกลวงแบบเจาะจง การสวมรอย หรือ Social Engineering แม้เหตุการณ์นี้ไม่ได้เป็นการเจาะฐานข้อมูลโดยตรง แต่สะท้อนความเสี่ยงจาก Trusted Third-party Access และสิทธิ์ที่ถูกใช้งานเกินวัตถุประสงค์ในระบบที่เก็บข้อมูลสำคัญระดับประเทศ

03 ข้อเสนอแนะ

ให้หน่วยงานที่มีระบบแลกเปลี่ยนข้อมูลกับบุคคลภายนอกทบทวนสิทธิ์ของ Third Party และตรวจสอบว่าข้อมูลที่คู่สัญญาสามารถเข้าถึงได้ถูกจำกัดตามหลัก Least Privilege ควรกำหนดการตรวจจับ Automated Query หรือปริมาณการเรียกข้อมูลที่ผิดปกติ และมีขั้นตอนระงับสิทธิ์ได้อย่างรวดเร็ว หากพบเหตุผิดปกติให้เก็บ Log และหลักฐานเพื่อใช้ในการสืบสวน

01 สถานการณ์

FortiGuard Labs รายงานมัลแวร์ ClingSTUN ซึ่งทำงานเป็น Back-connect Proxy Backdoor และมุ่งโจมตีอุปกรณ์ Linux/IoT ที่เปิดให้เข้าถึงจากอินเทอร์เน็ตผ่านช่องโหว่ที่ทราบอยู่แล้ว แคมเปญมีการใช้ช่องโหว่หลายรายการใน Router, IoT, VPN และอุปกรณ์เครือข่าย เมื่อเข้าควบคุมอุปกรณ์ได้ มัลแวร์จะสร้าง Persistence และใช้บริการ STUN สาธารณะเพื่อค้นหา Public IP/Port Mapping และรักษาการเชื่อมต่อผ่าน NAT

02 ผลกระทบ

อุปกรณ์ที่ถูกยึดอาจถูกนำไปใช้เป็น Proxy เพื่อปกปิดต้นทางของผู้โจมตีหรือสนับสนุนการโจมตีต่อระบบอื่น ทำให้องค์กรตรวจสอบต้นทางของ Traffic ที่ผิดปกติได้ยากขึ้น การใช้ STUN ซึ่งเป็น Protocol ที่มีการใช้งานตามปกติใน VoIP และ WebRTC ยังเพิ่มความยากในการแยก Traffic ที่เป็นอันตรายออกจากการใช้งานที่ถูกต้อง

03 ข้อเสนอแนะ

ให้จัดทำบัญชีอุปกรณ์ Linux/IoT ที่เปิดให้เข้าถึงจากอินเทอร์เน็ต ตรวจสอบ Firmware และช่องโหว่ที่ยังไม่ได้รับการแก้ไข พร้อมปิดบริการที่ไม่จำเป็นและลด Internet Exposure ควรตรวจสอบ STUN/UDP Traffic ร่วมกับ Process และ Outbound Connection ที่ผิดปกติ โดยไม่ควร Block STUN ทั้งหมดจากชื่อ Protocol เพียงอย่างเดียว หากพบอุปกรณ์ต้องสงสัยให้แยกออกจากเครือข่ายและตรวจสอบ Persistence ก่อนนำกลับมาใช้งาน
