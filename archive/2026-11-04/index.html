1. Siemens SIMATIC IoT2050 ช่องโหว่ CVE-2026-58115 ถูกใช้ติดตั้ง Backdoor และ Bot

CVE-2026-58115Siemens IoT2050Active Exploitation

ช่องโหว่ CVSS 10.0 เปิดให้ผู้โจมตีที่ไม่ต้องยืนยันตัวตนสร้าง Node-RED Flow และรันคำสั่งด้วยสิทธิสูงสุด; มีหลักฐานการโจมตีจริง

สถานะ: เร่งอัปเดตและตรวจสอบเผยแพร่: Siemens 11 ส.ค.; รายงานการโจมตี 3 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Siemens ระบุว่า SIMATIC IoT2050 Advanced ที่ใช้ Industrial OS และติดตั้ง Node-RED รุ่นก่อน 4.3.4.1 มีช่องโหว่ Missing Authentication ใน HTTP Interface ทำให้ผู้โจมตีจากระยะไกลสร้าง Malicious Flow และรันคำสั่งด้วยสิทธิสูงสุดได้ VulnCheck ตรวจพบความพยายามโจมตีหลายครั้งเพื่อวาง Web Shell และ Linux Bot

ผลกระทบ

อุปกรณ์ IoT/OT ที่เปิด Node-RED Interface สู่อินเทอร์เน็ตอาจถูกยึดควบคุม ใช้เป็นจุดตั้งต้นเข้าสู่เครือข่ายอุตสาหกรรม หรือเข้าร่วม Botnet หลักฐานการโจมตีจริงมาจากผู้วิจัย ไม่ใช่ข้อความใน Advisory เดิมของ Siemens

ข้อเสนอแนะ

อัปเดตเป็น Industrial OS 4.3.4.1 หรือใหม่กว่า หากยังทำไม่ได้ให้ถอน Node-RED หรือปิดการเข้าถึงจากอินเทอร์เน็ต เปิด HTTPS และ Authentication ตามคู่มือ พร้อมตรวจ Flow, Process และการเชื่อมต่อออกจากอุปกรณ์ย้อนหลัง

Siemens 11 ส.ค.; รายงานการโจมตี 3 พ.ย. 2569

2. Android พฤศจิกายน 2569 แก้ช่องโหว่ร้ายแรงกว่า 200 รายการ รวม RCE ที่ไม่ต้องโต้ตอบ

AndroidCVE-2026-58868Security Patch

Security Patch Level 2026-11-05 แก้ปัญหาทั้งหมดใน Bulletin รวม Critical RCE ใน Framework และ System ที่ไม่ต้องให้ผู้ใช้กดหรือเปิดไฟล์

สถานะ: เร่งอัปเดตเผยแพร่: Android Security Bulletin 2 พ.ย. 2569

สถานการณ์

Android Security Bulletin เดือนพฤศจิกายนระบุ Critical RCE ใน Framework ได้แก่ CVE-2026-58868 และใน System ได้แก่ CVE-2026-58876 กับ CVE-2026-58936 ซึ่งอาจทำงานจากระยะไกลโดยไม่ต้องมีสิทธิหรือการโต้ตอบจากผู้ใช้ นอกจากนี้ยังมี Critical Privilege Escalation และปัญหาใน Kernel Component หลายรายการ

ผลกระทบ

อุปกรณ์ที่ยังไม่ได้รับ Patch อาจเสี่ยงต่อการรันโค้ด ยกระดับสิทธิ เปิดเผยข้อมูล หรือหยุดให้บริการ ทั้งนี้ Bulletin ไม่ได้ระบุว่าช่องโหว่เหล่านี้ถูกใช้โจมตีจริง จึงไม่สรุปสถานะ Active Exploitation

ข้อเสนอแนะ

ตรวจ Security Patch Level ของอุปกรณ์องค์กรและเร่งอัปเดตเป็น 2026-11-05 หรือใหม่กว่า จัดลำดับอุปกรณ์ที่เข้าถึงข้อมูลสำคัญก่อน และติดตาม Bulletin ของผู้ผลิตอุปกรณ์สำหรับตารางปล่อย Patch
