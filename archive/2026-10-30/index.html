1. Cisco ยืนยันการโจมตีช่องโหว่ SSL VPN ที่ทำให้ ASA และ FTD รีโหลดจากระยะไกล

CVE-2026-76418Cisco ASA / FTDActive Exploitation

CVE-2026-76418 ระดับ 8.6 ถูกใช้โจมตีจริง ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนอาจส่งคำขอที่สร้างขึ้นเฉพาะเพื่อทำให้อุปกรณ์รีโหลดและเกิด Denial of Service

ประเด็น: Firewall / Remote Access VPNสถานะ: Cisco PSIRT ยืนยัน Active Exploitationการดำเนินการ: อัปเดตเป็นรุ่นแก้ไขและตรวจอุปกรณ์ที่เปิด SSL VPN
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Cisco เผยแพร่ Security Advisory เมื่อ 28 ต.ค. ยืนยันช่องโหว่ CVE-2026-76418 ใน Remote Access SSL VPN ของ Secure Firewall ASA และ FTD ซึ่งเกิดจาก Logic Error เมื่อ Tunnel Group ใช้ Secondary Authentication ผู้โจมตีจากระยะไกลที่ไม่ผ่านการยืนยันตัวตนอาจส่งคำขอที่สร้างขึ้นเฉพาะเพื่อทำให้อุปกรณ์รีโหลด โดย Cisco PSIRT ระบุว่าพบการใช้โจมตีจริงในเดือนตุลาคม 2569

ผลกระทบ

การรีโหลดอุปกรณ์ Firewall หรือ VPN ทำให้ผู้ใช้ระยะไกลและบริการที่พึ่งพาอุปกรณ์ขาดความพร้อมใช้ การโจมตีซ้ำอาจสร้างภาวะ Denial of Service ต่อช่องทางเชื่อมต่อสำคัญ ทั้งนี้ช่องโหว่นี้ไม่ถูกระบุว่าทำให้ผู้โจมตีอ่านหรือแก้ข้อมูล

ข้อเสนอแนะ

ตรวจสอบ ASA/FTD ที่เปิด Remote Access SSL VPN และใช้ Secondary Authentication อัปเดตเป็น Fixed Release ตามตาราง Cisco โดยเร็ว เนื่องจากไม่มี Workaround ตรวจ Log การเชื่อมต่อ VPN และเหตุอุปกรณ์รีโหลดผิดปกติ รวมถึงเตรียมช่องทางบริหารสำรองระหว่างอัปเดต

2. Alpine Linux สร้าง GitLab ใหม่ทั้งระบบหลังพบความพยายามโจมตีช่องโหว่ CVSS 10.0

CVE-2026-97229GitLabAlpine Linux

ผู้โจมตีส่ง CI Configuration ที่สร้างขึ้นเฉพาะและทำให้ Worker ล่มหลายครั้ง Alpine ไม่พบหลักฐานว่ารันโค้ดสำเร็จ แต่ไม่สามารถตัดความเป็นไปได้จึง Rebuild ระบบและ Reset รหัสผ่าน

ประเด็น: Software Supply Chain / DevOpsสถานะ: ยืนยัน Attempted Exploitation; ยังไม่ยืนยัน Code Execution สำเร็จการดำเนินการ: อัปเดต GitLab และ Ruby พร้อมตรวจ CI/CD Secrets
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Alpine Linux เปิดเผยเมื่อ 28 ต.ค. ว่าผู้โจมตีพยายามใช้ CVE-2026-97229 ต่อ GitLab ของโครงการเมื่อ 20–21 ต.ค. โดยส่ง CI Configuration ที่สร้างขึ้นเฉพาะ ทำให้ Worker Process ล่ม 8 ครั้ง และบางครั้งดำเนิน Exploit ได้บางส่วน Alpine ไม่พบหลักฐานว่าโค้ดของผู้โจมตีทำงานสำเร็จ แต่ไม่สามารถยืนยันได้อย่างเด็ดขาด จึงสร้าง Server ใหม่ เปลี่ยน Secret Key และ Reset รหัสผ่านทุกบัญชี

ผลกระทบ

หาก Exploit สำเร็จ ช่องโหว่ใน Regular Expression Engine ของ Ruby อาจเปิดทางรันโค้ดบน GitLab Server และกระทบข้อมูลบัญชี CI/CD Variable, Runner Token, Integration Credential และ Repository ส่วนตัว Alpine ตรวจสอบแล้วว่า Package, Release และ Signing Key ไม่พบการแก้ไขหรือเปิดเผย

ข้อเสนอแนะ

ผู้ดูแล Self-managed GitLab ที่ใช้ Ruby ของตนเองหรือ Custom Container ต้องอัปเดตทั้ง GitLab และ Ruby เป็นรุ่นแก้ไข ได้แก่ Ruby 3.3.13, 3.4.12 หรือ 4.0.9 ขึ้นไป ตรวจ Pipeline/CI Configuration ผิดปกติ Rotate CI/CD Secrets เมื่อมีข้อสงสัย และทบทวน Log Process Crash กับ Outbound Connection

เหตุ 20–21 ต.ค.; Alpine เปิดเผยและ Rebuild เสร็จ 28 ต.ค. 2569

4. กระทรวงกลาโหมสหรัฐฯ ตรวจสอบเหตุระบบทำความเย็นในฐานทัพขัดข้องว่าอาจเป็นการโจมตีไซเบอร์

MilitaryOT / RefrigerationInvestigation

เหตุเดือนสิงหาคมกระทบร้านค้าภายในฐานทัพอย่างน้อย 6 แห่งและทำให้อาหารเสีย แต่การสอบสวนยังไม่สรุปสาเหตุหรือผู้รับผิดชอบ

ประเด็น: Military / Operational Technologyสถานะ: อยู่ระหว่างสอบสวน; ยังไม่ยืนยันว่าเป็น Cyberattackการดำเนินการ: ตรวจ Controller, Remote Access และ Firmware ของระบบทำความเย็น
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

เจ้าหน้าที่กระทรวงกลาโหมสหรัฐฯ ยืนยันว่าหน่วยสืบสวนหลายหน่วยกำลังตรวจเหตุระบบทำความเย็นใน Commissary ของฐานทัพอย่างน้อย 6 แห่งขัดข้องเมื่อเดือนสิงหาคม บางระบบเข้าสู่ Defrost Mode หรือเพิ่มอุณหภูมิ ทำให้อาหารเสีย การสอบสวนประสานกับหน่วยงานฝรั่งเศสซึ่งกำลังตรวจเหตุคล้ายกัน แต่ยังไม่มีข้อสรุปว่าเหตุในสหรัฐฯ เป็นการโจมตีไซเบอร์

ผลกระทบ

ระบบทำความเย็นที่เชื่อมต่อเครือข่ายเป็น OT ซึ่งหากถูกควบคุมอาจกระทบความปลอดภัยอาหาร การส่งกำลังบำรุง และความต่อเนื่องของสถานที่ปฏิบัติงาน เหตุนี้ยังไม่ควรถูกระบุเป็น Cyberattack ที่ยืนยันแล้วหรือเชื่อมโยงผู้ก่อเหตุใด

ข้อเสนอแนะ

สำรวจ Controller ระบบทำความเย็นที่เปิด Remote Access แยกเครือข่าย OT ออกจาก IT เปลี่ยนรหัสผ่านเริ่มต้น อัปเดต Firmware ตามผู้ผลิต เก็บ Log การเปลี่ยน Setpoint/Defrost Mode และกำหนด Alert เมื่ออุณหภูมิเปลี่ยนผิดปกติ

CVE-2026-93851 ระดับ CVSS 8.0 กระทบส่วน Mention Reminder ของ Mattermost Agents Plugin ซึ่งไม่ตรวจ Target Post ID อย่างเพียงพอ ผู้ใช้ที่ผ่านการยืนยันตัวตนและโพสต์ใน Channel ที่ผู้ดูแลมองเห็นได้ อาจสร้างโพสต์ให้ผู้ดูแลคลิกและทำให้ Browser ส่ง API Request โดยไม่ตั้งใจ ส่งผลให้ Plugin ที่ติดตั้งถูกแทนที่และอาจรันโค้ดบน Server

ผลกระทบ

การรันโค้ดบน Collaboration Server อาจกระทบข้อความ ไฟล์ Credential และระบบเชื่อมต่ออื่น โดยต้องมีบัญชีที่โพสต์ได้และอาศัยการคลิกของผู้ดูแล จึงไม่ใช่การโจมตีแบบไม่ต้องยืนยันตัวตน

ข้อเสนอแนะ

อัปเดต Mattermost เป็นรุ่นที่ผู้ผลิตระบุว่าแก้ไขแล้ว ตรวจ Agents Plugin และ Plugin Installation History จำกัดสิทธิ์ผู้ดูแลให้ใช้บัญชีเฉพาะ ระวัง Mention Reminder ที่ผิดปกติ และตรวจ Audit Log หลังมีการคลิกโพสต์ต้องสงสัย
