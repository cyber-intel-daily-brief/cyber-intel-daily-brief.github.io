1. ผู้โจมตีใช้ช่องโหว่ Collabora Built-in CODE ฝัง Web shell บน Nextcloud

CVE-2026-110447Active Exploitation15 ต.ค. 2569

มีรายงานการใช้ CVE-2026-110447 โจมตีจริงผ่านแอป Collabora Online - Built-in CODE Server สำหรับ Nextcloud โดยอาจรันคำสั่งบนระบบและติดตั้ง Web shell ได้โดยไม่ต้องยืนยันตัวตน

สถานะ: เร่งด่วนการดำเนินการ: ตรวจสอบตาม Advisory
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่ OS Command Injection กระทบ richdocumentscode รุ่นก่อน 26.4.303 และมีผู้ดูแลระบบรายงานพบ Web shell หลังการโจมตี จุดอ่อนอยู่ในรูปแบบการเริ่ม Collabora ของแอป Built-in CODE ไม่กระทบ Collabora Online แบบ Standalone, Nextcloud All-in-One หรือการติดตั้ง Collabora ผ่าน Docker/RPM/DEB ที่ไม่ได้ใช้แอปดังกล่าว

ผลกระทบ

ผู้โจมตีอาจรันคำสั่งด้วยสิทธิ์ของบริการเว็บ สร้างช่องทางกลับเข้าสู่ระบบ เข้าถึงไฟล์ที่ Nextcloud จัดเก็บ และขยายผลไปยังข้อมูลรับรองหรือระบบอื่นตามสิทธิ์ของ Host

ข้อเสนอแนะ

ตรวจว่ามีแอป richdocumentscode หรือไม่และอัปเดตเป็น 26.4.303 หรือใหม่กว่าทันที การ Disable อย่างเดียวอาจไม่ลบ Web shell ที่ติดตั้งแล้ว จึงต้องตรวจ Web root, Process, Cron, Access Log และบัญชีผู้ดูแล หากพบหลักฐานให้แยกระบบ หมุนเวียน Credential และกู้คืนจากแหล่งที่เชื่อถือได้

สถานการณ์

Adobe ระบุว่าช่องโหว่นี้กระทบ Adobe Commerce, Adobe Commerce B2B และ Magento Open Source ตามรุ่นก่อนชุดอัปเดต 2026-oct และออก Bulletin APSB26-153 เมื่อ 13 ตุลาคม Sansec สามารถสร้างเส้นทางโจมตีได้หลายรูปแบบหลังวิเคราะห์ Patch แต่ทั้ง Adobe และ Sansec ยังไม่พบหลักฐานการใช้ช่องโหว่นี้โจมตีระบบจริง ณ เวลารายงาน

ผลกระทบ

ร้านค้าออนไลน์ที่ถูกยึดอาจถูกแก้ไขข้อมูล ติดตั้ง Backdoor ขโมยข้อมูลลูกค้า หรือใช้เป็นฐานโจมตีต่อ ช่องโหว่ไม่ต้องใช้บัญชีและกระทบระบบที่เปิดอินเทอร์เน็ต จึงควรให้ความสำคัญสูงแม้ยังไม่มีหลักฐาน Active Exploitation

ข้อเสนอแนะ

ติดตั้งชุดอัปเดต Adobe Commerce/Magento รุ่น 2026-oct หรือ Isolated Patch ที่ตรงกับรุ่น ตรวจยืนยันว่า Patch เดือนกันยายน CVE-2026-75650 ยังคงติดตั้งครบถ้วน และตรวจ Web Log, Template, PHP File และบัญชีผู้ดูแลเพื่อค้นหาความผิดปกติ

สถานการณ์

Citizen Lab ระบุว่าแพลตฟอร์ม Controlium ของ Discover-Tech ช่วยระบุตัวตน ทำ Fingerprint และส่งโค้ดโจมตีไปยังเป้าหมายเฉพาะ มีหลักฐานเชื่อมโยงโฆษณากับ Candiru Spyware และประเมินด้วยความเชื่อมั่นสูงว่าอุปกรณ์ของ Al Jazeera อย่างน้อย 45 เครื่องถูกโจมตีในปี 2567–2568 ข้อมูลนี้เป็นผลการวิจัยของแหล่งต้นทาง ไม่ได้หมายความว่าโฆษณาทุกชิ้นในเครือข่ายดังกล่าวเป็นอันตราย

ผลกระทบ

บุคลากรระดับสูง นักข่าว หน่วยงานรัฐ ทหาร และองค์กรโครงสร้างพื้นฐานอาจถูกติดตามหรือเจาะอุปกรณ์โดยไม่ต้องมีปฏิสัมพันธ์กับข้อความลวง ทำให้แนวทางป้องกันที่พึ่งการไม่คลิกลิงก์เพียงอย่างเดียวไม่เพียงพอ

ข้อเสนอแนะ

สำหรับบุคลากรความเสี่ยงสูง ให้ใช้ Browser/Device ที่ได้รับการจัดการ เปิดระบบป้องกันขั้นสูงของผู้ผลิต ลด Ad Tracking ใช้ DNS/Web filtering และ Ad blocking ตามนโยบายองค์กร แยกอุปกรณ์ภารกิจกับอุปกรณ์ส่วนบุคคล และส่ง Network Telemetry ไปตรวจจับการเชื่อมต่อผิดปกติ

5. Burger King Japan เปิดเผยข้อมูลสมาชิกแอปประมาณ 11.18 ล้านรายการรั่วไหล

Data BreachJapan15 ต.ค. 2569

ผู้ดำเนินงาน Burger King ในญี่ปุ่นเปิดเผยว่าผู้ไม่หวังดีเข้าถึง Server จัดการข้อมูลสมาชิกแอปโดยไม่ได้รับอนุญาต ส่งผลให้ข้อมูลประมาณ 11.18 ล้านรายการถูกเปิดเผย

สถานะ: เฝ้าระวังและดำเนินการการดำเนินการ: ตรวจสอบตาม Advisory
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

บริษัทระบุว่าการเข้าถึงโดยไม่ได้รับอนุญาตเกิดระหว่าง 2–7 ตุลาคม และยืนยันเหตุเมื่อ 13 ตุลาคม ข้อมูลที่เกี่ยวข้องครอบคลุม Member ID, Email, จังหวัด, เพศ, วันเกิด, ชื่อ และหมายเลขโทรศัพท์ โดยบริษัทระบุว่า Server ดังกล่าวไม่ได้จัดเก็บหมายเลขบัตรเครดิต และยังไม่พบหลักฐานว่าข้อมูลเข้าสู่ระบบถูกเข้าถึง

ผลกระทบ

ข้อมูลส่วนบุคคลจำนวนมากอาจถูกนำไปทำ Phishing, Smishing, ปลอมตัวตน หรือสร้างข้อความหลอกลวงที่เจาะจงผู้รับมากขึ้น แม้ไม่มีข้อมูลบัตรเครดิตใน Server ที่ได้รับผลกระทบ

ข้อเสนอแนะ

องค์กรควรเฝ้าระวัง Domain และข้อความปลอมที่อ้าง Burger King Japan แจ้งผู้ใช้ให้ระวังคำขอข้อมูลเพิ่มเติม ตรวจ Mail/SMS Gateway สำหรับแคมเปญที่ใช้ข้อมูลส่วนบุคคล และให้ผู้ใช้ยืนยันการแจ้งเตือนผ่านแอปหรือเว็บไซต์ทางการโดยตรง

6. ผู้โจมตียึดอุปกรณ์ Edge ใน 34 ประเทศเพื่อขายต่อ Bandwidth เป็น Residential Proxy

ProxyjackingEdge Devices15 ต.ค. 2569

GreyNoise พบแคมเปญ Proxyjacking ที่ติดตั้ง Pawns.app บนอุปกรณ์โดยเจ้าของไม่ยินยอม และยืนยันการยึดอุปกรณ์อย่างน้อย 143 เครื่องใน 34 ประเทศ

สถานการณ์

ผู้โจมตีใช้ช่องโหว่ที่ทราบแล้วกับ D-Link ShareCenter NAS, Ubiquiti UniFi Video NVR และ SAP NetWeaver Visual Composer เพื่อสร้างรายได้จาก Bandwidth ของเหยื่อผ่านเครือข่าย Residential Proxy บางระบบถูกเพิ่ม SSH Key เพื่อคงช่องทางเข้าถึงสำรอง GreyNoise ระบุ CVE ที่ใช้ตรงตามเทคโนโลยีในรายงานต้นทาง

ผลกระทบ

อุปกรณ์ที่ถูกยึดอาจถูกใช้ปกปิดต้นทางของกิจกรรมโจมตี ทำให้องค์กรมีความเสี่ยงด้านชื่อเสียง การสืบสวน และการใช้ทรัพยากรโดยไม่ได้รับอนุญาต อีกทั้งช่องทาง SSH ที่เพิ่มไว้ช่วยให้ผู้โจมตีกลับเข้าสู่ระบบได้

ข้อเสนอแนะ
