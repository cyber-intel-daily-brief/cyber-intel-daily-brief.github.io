CVE-2026-102764Zero-day Exploitation15 ต.ค. 2569

BeyondTrust และ Mandiant เปิดเผย CVE-2026-102764 ระดับ Critical ซึ่งผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนอาจใช้ดำเนินการกับไฟล์บนอุปกรณ์ Remote Support และมีหลักฐานว่าถูกใช้โจมตีจริงก่อนเปิดเผยช่องโหว่

สถานการณ์

BeyondTrust ระบุว่า CVE-2026-102764 มีคะแนน CVSS 9.3 กระทบ Remote Support ทุกเวอร์ชันถึง 26.2.3 ส่วน Mandiant พบกลุ่มที่ติดตามในชื่อ ARMORY CASTLE ใช้ช่องโหว่นี้เป็น Zero-day เมื่อปลายเดือนสิงหาคม เพื่ออัปโหลดไฟล์ ยกระดับสิทธิ์ สร้าง Persistence และเข้าถึงข้อมูลรับรองที่อุปกรณ์จัดเก็บหรือเป็นตัวกลาง โดย Google Threat Intelligence Group ประเมินว่าเป็นกลุ่มจารกรรมที่เชื่อมโยงกับจีน

ผลกระทบ

อุปกรณ์ Remote Access เป็นจุดเชื่อมต่อสิทธิ์สูง หากถูกยึด ผู้โจมตีอาจควบคุม Host เข้าถึง Credential เคลื่อนย้ายไปยังระบบภายใน และลบ Log เพื่อหลบเลี่ยงการตรวจจับ ผู้ผลิตเตือนว่าระบบ Self-hosted ที่ยังไม่ติด Patch มีความเสี่ยงเร่งด่วน

ข้อเสนอแนะ

ตรวจสอบ Remote Support แบบ Self-hosted และติดตั้ง BT26-05-RS patch ทันที รุ่นเก่ากว่า 24.3.1 ต้องอัปเกรดก่อน ส่ง Syslog ออกจาก Appliance ไปยัง SIEM ตรวจบัญชีและ Session สิทธิ์สูง รวมทั้ง Web shell หรือช่องว่างของ Log หากพบหลักฐานต้องสงสัยให้แยกระบบ เก็บหลักฐาน และหมุนเวียน Credential หลัง Patch หรือ Rebuild แล้ว

CISA เพิ่ม CVE-2026-21589 เข้าบัญชี Known Exploited Vulnerabilities เมื่อ 15 ตุลาคม ยกระดับความเร่งด่วนของช่องโหว่อ่านไฟล์โดยไม่ต้องยืนยันตัวตนในผลิตภัณฑ์ Atlassian Data Center หลายรายการ

สถานการณ์

Atlassian จัด CVE-2026-21589 เป็น Critical คะแนน CVSS 9.3 กระทบ Bitbucket, Confluence, Jira Service Management, Jira Software, Bamboo, Crowd, Crucible และ Fisheye Data Center รุ่นก่อนเวอร์ชันแก้ไข ช่องโหว่อนุญาตให้ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนเข้าถึงไฟล์เฉพาะภายใน Web Application Root เมื่อทราบชื่อและ Path ที่ถูกต้อง การเพิ่มเข้า KEV เป็นหลักฐานยืนยันว่ามีการใช้ช่องโหว่นี้โจมตีจริง

ผลกระทบ

ไฟล์ที่ถูกอ่านอาจมีข้อมูลสำคัญและช่วยขยายผลเข้าสู่ระบบพัฒนา ซอร์สโค้ด หรือระบบจัดการงานขององค์กร ความเสี่ยงสูงในระบบ Data Center ที่เข้าถึงจากอินเทอร์เน็ต ส่วน Atlassian Cloud ได้รับการแก้ไขแล้วและผู้ผลิตไม่พบหลักฐานการโจมตีลูกค้า Cloud

ข้อเสนอแนะ

ตรวจทุกผลิตภัณฑ์ Atlassian Data Center ในรายการและอัปเดตเป็น Fixed Version ตาม Advisory ทันที หากยัง Patch ไม่ได้ให้ตัดการเข้าถึงจากอินเทอร์เน็ตหรือใช้ Mitigation ของ Atlassian ตรวจ Access Log โดยถอดรหัส URL และค้นหารูปแบบ Directory Traversal พร้อมตรวจไฟล์หรือบัญชีผิดปกติย้อนหลัง

CRITICAL

3. Next.js ออกอัปเดตฉุกเฉินแก้ช่องโหว่ RCE สองเส้นทางและ DoS

CVE-2026-96889Remote Code Execution14 ต.ค. 2569

โครงการ Next.js ออกเวอร์ชัน 16.4.1 และ 15.5.28 เพื่อแก้ช่องโหว่ RCE แบบไม่ต้องยืนยันตัวตนใน Cache Components และ Image Optimization API รวมทั้งช่องโหว่ DoS ใน Server Actions

สถานะ: เร่งด่วนการดำเนินการ: ตรวจสอบตาม Advisory
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่แรกกระทบแอปที่ใช้ App Router ร่วมกับ Cache Components เมื่อฟังก์ชัน use cache ส่งคืน Typed Array หลายรายการ และไม่มีวิธีแก้ชั่วคราว ช่องโหว่ที่สองคือ CVE-2026-96889 ในไลบรารีที่ Image Optimization ใช้ อาจนำไปสู่ RCE เมื่อประมวลผล SVG บน Linux ที่ใช้ glibc ส่วนช่องโหว่ที่สามทำให้ Crafted Request ใช้ CPU สูงจนบริการไม่ตอบสนอง

ผลกระทบ

เว็บแอปที่เข้าข่ายอาจถูกสั่งรันโค้ดจากระยะไกลหรือหยุดให้บริการได้โดยไม่ต้องมีบัญชี โดยเฉพาะระบบที่เปิดสาธารณะและประมวลผลรูปภาพหรือใช้ App Router ความเสี่ยงอาจกระจายผ่าน Dependency ในโครงการจำนวนมาก

ข้อเสนอแนะ

อัปเดต Next.js เป็น 16.4.1 หรือ 15.5.28 และสร้าง Deployment ใหม่ ตรวจ Lockfile และ Runtime Image ว่าใช้เวอร์ชันแก้ไขแล้ว สำหรับ CVE-2026-96889 หากอัปเดต Next.js ยังไม่ได้ให้ใช้ sharp 0.35.5 หรือใหม่กว่า พร้อมตรวจ Log คำขอผิดปกติและ Crash ของบริการ

4. Drupal แก้ช่องโหว่ Remote Code Execution ใน Field UI ที่มีเส้นทางโจมตีไม่ต้องยืนยันตัวตน

CVE-2026-108097Drupal14 ต.ค. 2569

Drupal Security Team เปิดเผย CVE-2026-108097 ระดับ Critical ในโมดูล Field UI โดย Core เพียงอย่างเดียวไม่ถูกโจมตีโดยตรง แต่ Contributed Module หรือ Custom Code บางรูปแบบอาจเปิดเส้นทางสู่ RCE และอย่างน้อยหนึ่งเส้นทางไม่ต้องยืนยันตัวตน

สถานะ: เร่งด่วนการดำเนินการ: ตรวจสอบตาม Advisory
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่กระทบ Drupal ตั้งแต่ 8.9.0 ก่อน 10.6.19, Drupal 11 ก่อน 11.3.19 ในสาย 11.3, ก่อน 11.4.10 ในสาย 11.4 และ Drupal 12.0.0-alpha1 ก่อน 12.0.0-beta2 ผู้ผลิตระบุว่าการปิดโมดูล field_ui ช่วยลดความเสี่ยงชั่วคราวได้ แต่ Drupal Steward ไม่ครอบคลุมเส้นทางโจมตีทั้งหมด

ผลกระทบ

เว็บไซต์ที่ใช้ส่วนขยายหรือโค้ดซึ่งเปิดใช้ฟังก์ชันที่มีช่องโหว่อาจถูกสั่งรันโค้ดและกระทบความลับ ความถูกต้อง และความพร้อมใช้ของระบบ โดยเว็บภาครัฐหรือองค์กรที่เปิดสาธารณะควรเร่งตรวจสอบ

ข้อเสนอแนะ

อัปเดตเป็น Drupal 10.6.19, 11.3.19, 11.4.10 หรือรุ่นที่ใหม่กว่าตามสายที่รองรับ ตรวจ Contributed Module และ Custom Code ที่เกี่ยวข้อง หากยังอัปเดตไม่ได้ให้ถอนการติดตั้ง Field UI ชั่วคราว สำรองข้อมูล และตรวจ Web/Application Log รวมถึงไฟล์ใหม่หรือเปลี่ยนแปลงโดยไม่ได้รับอนุญาต

5. CISA เตือนช่องโหว่หลายรายการใน Eclipse Milo ที่ใช้กับระบบ OPC UA

OT / ICSEclipse Milo15 ต.ค. 2569

CISA เผยแพร่ Advisory สำหรับ Eclipse Milo ซึ่งเป็นชุดไลบรารี OPC UA โดยช่องโหว่หลายรายการอาจทำให้ลบข้อมูลที่ได้รับการป้องกัน กู้คืนข้อมูลรับรอง สวมรอยผู้ใช้ หรือทำให้ Server ไม่ตอบสนอง

สถานะ: เฝ้าระวังและดำเนินการการดำเนินการ: ตรวจสอบตาม Advisory

สถานการณ์

Advisory ระบุว่า Eclipse Milo รุ่น 0.6.0 ถึง 1.1.4 หรือ 1.0.0 ถึง 1.1.4 ได้รับผลกระทบแตกต่างกันตาม CVE และแนะนำให้อัปเดตเป็น 1.1.5 ช่องโหว่ครอบคลุมการตรวจสอบสิทธิ์ การประมวลผล Username Token และการจัดการทรัพยากรของ Server โดย CISA ระบุการใช้งานในภาค Chemical, Critical Manufacturing, Energy และ Water and Wastewater ทั่วโลก

ผลกระทบ

ระบบ OT/ICS ที่ใช้ OPC UA เพื่อแลกเปลี่ยนข้อมูลอาจถูกเข้าถึงข้อมูลที่ป้องกันไว้ ถูกสวมรอย หรือหยุดตอบสนอง ส่งผลต่อการมองเห็นและความต่อเนื่องของกระบวนการ แม้ยังไม่พบข้อมูลยืนยันการใช้ช่องโหว่ชุดนี้โจมตีจริงจากแหล่งอ้างอิง

ข้อเสนอแนะ

จัดทำ Inventory ของแอปพลิเคชันและ Gateway ที่ฝัง Eclipse Milo อัปเดตเป็น 1.1.5 หรือรุ่นที่ผู้ผลิตรับรอง จำกัดการเข้าถึง OPC UA จากอินเทอร์เน็ต แยกเครือข่าย OT ออกจากเครือข่ายธุรกิจ และใช้ VPN ที่อัปเดตพร้อม MFA เมื่อต้องเข้าถึงจากระยะไกล

6. NGINX แก้ช่องโหว่ห้ารายการในรุ่น 1.31.7 และ 1.30.6

NGINXMemory Safety15 ต.ค. 2569

NGINX เผยแพร่สถานะแก้ไขช่องโหว่ระดับ Medium ห้ารายการ ครอบคลุม Buffer Overflow, HTTP/3 Request Body Injection, การปลอม TLS Session Ticket และ Use-after-free

สถานการณ์

รายการล่าสุดประกอบด้วย CVE-2026-15176, CVE-2026-93479, CVE-2026-95101, CVE-2026-97629 และ CVE-2026-97205 โดยขอบเขตรุ่นที่กระทบต่างกันตามฟังก์ชันและการตั้งค่า NGINX ระบุว่า 1.31.7 และ 1.30.6 หรือใหม่กว่าไม่อยู่ในขอบเขตช่องโหว่ชุดนี้ และไม่พบข้อมูลยืนยันการใช้โจมตีจริงจากหน้าประกาศต้นทาง

ผลกระทบ

ผลกระทบอาจเป็น Memory Corruption, การแทรก Request Body, การปลอม Session หรือการหยุดให้บริการตามโมดูลที่เปิดใช้ ระบบ Reverse Proxy และ Web Gateway ที่เปิดอินเทอร์เน็ตควรตรวจสอบแม้คะแนนแต่ละรายการอยู่ระดับ Medium

ข้อเสนอแนะ

ตรวจรุ่น NGINX และ Module ที่เปิดใช้ อัปเดตเป็น 1.31.7, 1.30.6 หรือแพ็กเกจที่ผู้จัดจำหน่าย Backport การแก้ไขแล้ว ทดสอบ Configuration ก่อน Deploy และเฝ้าระวัง Crash, Core Dump, HTTP/3 Traffic และ TLS Session ที่ผิดปกติ
