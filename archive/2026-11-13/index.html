3. Apache HTTP Server CVE-2026-119618 เปิดทาง RCE ผ่าน HTTP/2

Apache HTTP ServerCVE-2026-119618RCE

ช่องโหว่ Race Condition ใน mod_http2 กระทบ Apache HTTP Server 2.4.55–2.4.70 และได้รับการแก้ไขใน 2.4.71; ยังไม่พบหลักฐานยืนยันการโจมตีจริง

สถานะ: Patch Available; ยังไม่พบ Active Exploitationเผยแพร่: แหล่งข้อมูลวันที่ 11–12 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Apache Software Foundation เปิดเผย CVE-2026-119618 ซึ่งเป็น Race Condition ใน mod_http2 ที่อาจทำให้ Heap Corruption และนำไปสู่ Remote Code Execution โดยไม่ต้องยืนยันตัวตน ช่องโหว่กระทบ Apache HTTP Server 2.4.55 ถึง 2.4.70 และ mod_h2 2.0.8 ถึง 2.0.42 เมื่อเปิดใช้งาน HTTP/2 เวอร์ชัน 2.4.71 แก้ไขปัญหาแล้ว และ ณ เวลารายงานยังไม่พบหลักฐานยืนยันการโจมตีจริง

ผลกระทบ

หากโจมตีสำเร็จ ผู้โจมตีอาจรันคำสั่งด้วยสิทธิของ Web Server Process และใช้เป็นจุดเริ่มต้นเข้าถึงข้อมูลหรือระบบหลังบ้าน Server ที่เปิด HTTP/2 สู่อินเทอร์เน็ตควรได้รับความสำคัญสูงเนื่องจากไม่ต้องมีบัญชีผู้ใช้

ข้อเสนอแนะ

ตรวจสอบ Version และการเปิดใช้ HTTP/2 บน Apache HTTP Server และอัปเดตเป็น 2.4.71 หรือใหม่กว่าโดยเร็ว หากยังอัปเดตไม่ได้ ให้ประเมินการปิด h2/h2c ชั่วคราวและจำกัดเป็น HTTP/1.1 พร้อมเฝ้าระวัง Crash, Child Process และคำสั่งผิดปกติจาก Web Server

สถานการณ์

Microsoft Security Research ตรวจพบผู้โจมตีหลายกลุ่มนำ GSocket ซึ่งเป็น Remote-access Tool แบบ Open Source ไปใช้บน Linux Server ที่ถูกยึด โดยเน้น Web Application และ Hosting Environment เครื่องมือเชื่อมต่อออกไปยัง Shared Relay จึงไม่ต้องมี Inbound Listener หรือ C2 Domain ของผู้โจมตี และมีการซ่อน Process รวมถึงสร้าง Persistence ผ่าน cron, systemd และ Shell Startup Files

ผลกระทบ

ข้อเสนอแนะ

อย่าถือว่าการติดตั้งแพตช์จบการแก้ไข ให้ตรวจและลบ GSocket, Redundant Copies, cron, systemd และ Shell Profile ที่ผิดปกติ ตรวจ Outbound Connection ไปยัง Relay Infrastructure และใช้ Egress Allowlist เมื่อทำได้ หากพบการทำงานด้วยสิทธิสูงให้พิจารณาสร้างระบบใหม่จากแหล่งที่เชื่อถือได้

นักวิจัย Abdelhamid Naceri เผยแพร่ Proof of Concept ชื่อ SignDrop และอ้างว่าสามารถใช้พฤติกรรมของ Common Log File System Authentication Mitigation เพื่อยกระดับสิทธิ Local User เป็น SYSTEM โดยบังคับให้ Process สิทธิสูงเปิดไฟล์ที่จัดเตรียมไว้ นักวิจัยระบุว่าทดสอบกับ Windows 11 26H2 และ Windows Server 2025 รุ่นทดลอง แต่ ณ เวลารายงานยังไม่มี CVE, Microsoft Advisory หรือหลักฐานยืนยันการโจมตีจริง

ผลกระทบ

หากข้อค้นพบได้รับการยืนยัน ผู้โจมตีที่มีสิทธิรัน Code บนเครื่องอยู่แล้วอาจยกระดับสิทธิและหลบ Tamper Protection ของผลิตภัณฑ์ป้องกันบางประเภท อย่างไรก็ตาม ขอบเขต Version และผลกระทบจริงยังเป็นคำกล่าวอ้างของผู้วิจัยและไม่ควรตีความว่า Windows ทุกเครื่องได้รับผลกระทบ

ข้อเสนอแนะ

จำกัดสิทธิ Local User และการรันไฟล์ที่ไม่เชื่อถือ เพิ่ม Monitoring ต่อการสร้าง CLFS Container/Authentication File และ Process ที่ร้องขอสิทธิผิดปกติ ติดตามคำแนะนำจาก Microsoft และติดตั้ง Patch เมื่อมี โดยไม่แนะนำให้ปิด CLFS Mitigation เองเพราะอาจเปิดความเสี่ยงอื่น
