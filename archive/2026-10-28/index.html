CISA เพิ่ม CVE-2026-111497 ใน Google Brotli และ CVE-2026-48356 ใน Adobe Commerce/Magento เข้า Known Exploited Vulnerabilities Catalog เมื่อ 27 ต.ค. ซึ่งเป็นพัฒนาการใหม่จากรายงานก่อนหน้าและเป็นหลักฐานว่ามีการใช้โจมตีจริง รายการ KEV กำหนดให้หน่วยงานรัฐบาลกลางสหรัฐฯ ดำเนินการภายในวันที่ 10 พ.ย. 2569

ผลกระทบ

Brotli อาจถูกใช้ทำให้หน่วยความจำเสียหาย เปิดเผยข้อมูล ทำให้บริการล่ม หรืออาจรันโค้ดผ่านข้อมูลบีบอัดที่สร้างขึ้นเฉพาะ ส่วนช่องโหว่ Adobe Commerce/Magento เกี่ยวข้องกับการอัปโหลดไฟล์อันตรายซึ่งอาจนำไปสู่การรันโค้ดในบริบทของผู้ใช้และยกระดับการเข้าถึง

ข้อเสนอแนะ

สำรวจบริการที่ถอดรหัส Brotli และระบบ Adobe Commerce/Magento โดยเฉพาะระบบที่เปิดสู่อินเทอร์เน็ต ตรวจรุ่นตาม Advisory ของผู้ผลิต ใช้แพตช์หรือ Mitigation ที่กำหนด Rebuild แอปแบบ Self-contained/NativeAOT เมื่อเกี่ยวข้อง และตรวจ Log เพื่อหาพฤติกรรมผิดปกติก่อนและหลังอัปเดต

ผลกระทบ

ข้อเสนอแนะ

ร้านค้าที่ใช้ Convertr ควรขอผลยืนยันขอบเขตจากผู้ให้บริการ แจ้ง Payment Provider และตรวจ Client-side Script ผู้ซื้อที่ชำระผ่าน Checkout ดังกล่าวตั้งแต่ 24 ต.ค. ควรติดต่อธนาคารเพื่อตรวจสอบหรือเปลี่ยนบัตร ทั้งนี้ Sansec สงสัย CVE-2026-8467 เป็นช่องทางเริ่มต้นแต่ยังไม่มีหลักฐานยืนยัน

CVE-2026-80097Microsoft AuthenticatorIdentity

CVE-2026-80097 ระดับ 8.6 ทำให้แอปอันตรายเลียนแบบแอป Microsoft และขอ Token ของบัญชีงานได้; แก้ไขแล้วในรุ่น 6.2606.4246

ประเด็น: Mobile Identity / Microsoft 365สถานะ: มีแพตช์; ยังไม่มีหลักฐานการโจมตีจริงการดำเนินการ: อัปเดต Authenticator และตรวจ Token/Session ผิดปกติ
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Enclave เปิดเผย AuthMask ซึ่งอาศัย Exported Activity ใน Microsoft Authenticator for Android เพื่อให้แอปที่ไม่มี Permission อ้างตัวเป็นแอป Microsoft ที่ติดตั้งอยู่และขอ Token ของบัญชีงาน ในการทดสอบ Token สามารถเข้าถึง Mail, File และ Calendar ได้ Microsoft ติดตามเป็น CVE-2026-80097 ระดับ CVSS 8.6 และแก้ไขแล้ว

ผลกระทบ

หากมีแอปอันตรายอยู่บนอุปกรณ์ที่ลงชื่อเข้าใช้บัญชีงานผ่าน Authenticator ผู้โจมตีอาจได้ Token ที่มีสิทธิ์เข้าถึงข้อมูล Microsoft 365 โดยไม่ต้องรู้รหัสผ่าน ทั้งนี้ Enclave และ Microsoft อธิบายเงื่อนไข User Interaction ต่างกัน จึงควรยึด Advisory ของ Microsoft ในการประเมินเฉพาะระบบ

ข้อเสนอแนะ

อัปเดต Microsoft Authenticator for Android เป็น 6.2606.4246 หรือใหม่กว่า ตรวจ Mobile Application Inventory และ Sign-in/Token Activity ที่ผิดปกติ เพิกถอน Session เมื่อสงสัย และจำกัดการติดตั้งแอปจากแหล่งที่ไม่ผ่านการอนุมัติบนอุปกรณ์องค์กร

Microsoft แก้ไข 8 ก.ย.; งานวิจัยเผยแพร่ 23 ต.ค. และรายงานต่อเนื่อง 27 ต.ค. 2569

5. Microsoft ออก OOB Update เพิกถอนความเชื่อถือ Certificate Hierarchy ของ eMudhra

PKIeMudhraWindows OOB Update

Private Key ของ Intermediate CA แปดชุดสามารถกู้คืนได้จากข้อผิดพลาดการสร้างกุญแจ; Microsoft ปิดกั้น Key ที่ได้รับผลกระทบและนำ Root เจ็ดรายการออกจาก Trust List

ประเด็น: Certificate Trust / Windowsสถานะ: CA ถูกเพิกถอนและมี OOB Update สำหรับอุปกรณ์ที่ไม่รับ CTL อัตโนมัติการดำเนินการ: ตรวจเครื่อง Offline และ Certificate Chain ที่พึ่งพา eMudhra
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Microsoft ระบุว่า Private Key ของ eMudhra Intermediate CA แปดชุด ได้แก่ TLS หกชุดและ Code-signing สองชุด สามารถกู้คืนได้ จึงอัปเดต Windows Disallowed Certificate Trust List และ Edge/WebView2 พร้อมออก OOB Update เมื่อ 26 ต.ค. เพื่อนำ Certificate ที่เกี่ยวข้องเจ็ดรายการออกจาก Trust List ด้าน eMudhra ยอมรับว่า Script Error ทำให้สร้าง Key ที่อ่อนแอและเพิกถอน Intermediate ที่ได้รับผลกระทบแล้ว

ผลกระทบ

หากระบบยังเชื่อถือ Certificate Chain ที่ได้รับผลกระทบ ผู้ถือ Key อาจสร้าง Certificate หรือเซ็นเนื้อหาให้ดูเหมือนมาจาก CA ที่เชื่อถือได้ ความเสี่ยงยังคงอยู่ในเครื่อง Offline, ระบบที่ปิด Automatic CTL Update และอุปกรณ์ฝังตัวที่ Trust Store ไม่ได้รับการปรับปรุง

ข้อเสนอแนะ

ปล่อย Windows Certificate Trust Update และ Edge Component Update ให้ครบ ตรวจเครื่อง Offline/Isolated Network และ Azure Image ที่ไม่รับ Update อัตโนมัติ ติดตั้ง OOB Package ตามรุ่น ตรวจ Certificate Dependency และจัดหา Chain ทดแทนก่อนนำ Trust เดิมออก

Microsoft และ eMudhra ปรับปรุงประกาศ 26–27 ต.ค. 2569

ประเด็น: Malware-as-a-Service / Credential Theftสถานะ: Controller หนึ่งชุดถูกตัดการเชื่อมต่อ; ความเสี่ยงจาก Credential เดิมยังอยู่การดำเนินการ: ตรวจ Endpoint และเพิกถอน Session/รหัสผ่านที่อาจถูกขโมย
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ASD ให้ข้อมูลแก่ ABC ว่าปฏิบัติการเชิงรุกสามารถเข้าถึง Backend ของผู้ใช้ Amadey รายหนึ่ง ซึ่งควบคุมเครื่องติดเชื้อประมาณ 180,000 เครื่องทั่วโลก จากนั้นตัดการเชื่อมต่อ Controller กับเครื่องเหล่านั้น Amadey เป็น Malware Loader ที่สามารถขโมยข้อมูลรับรอง ติดตั้งมัลแวร์เพิ่มเติม และให้ Remote Access

ผลกระทบ

การตัด Controller ลดความสามารถของผู้โจมตีรายนั้นในการควบคุมหรือขโมยข้อมูลต่อ แต่ไม่ได้ยืนยันว่ามัลแวร์ถูกลบจากทุกเครื่อง และไม่ทำให้ Credential หรือ Session ที่ถูกขโมยไปก่อนหน้ากลับมาปลอดภัยโดยอัตโนมัติ

ข้อเสนอแนะ

ห้ามใช้ซอฟต์แวร์เถื่อนหรือ Installer จากแหล่งไม่ยืนยัน ตรวจ Endpoint ด้วย EDR/AV และหา Persistence เมื่อสงสัยว่าติด Amadey ให้แยกเครื่อง เก็บหลักฐาน Reset รหัสผ่านจากเครื่องสะอาด เพิกถอน Active Sessions และตรวจบัญชีสำคัญย้อนหลัง
