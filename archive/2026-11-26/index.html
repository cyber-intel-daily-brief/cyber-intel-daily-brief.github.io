1. Palo Alto Networks ยืนยันการใช้ Fragnesia โจมตี PAN-OS ที่เปิด Management Interface สู่อินเทอร์เน็ต

PAN-OSCVE-2026-46300Active Exploitation

Palo Alto Networks ยืนยันว่าพบการใช้ CVE-2026-46300 หรือ Fragnesia เพื่อยกระดับสิทธิ์บน PAN-OS โดยเหตุที่สังเกตได้ทั้งหมดมุ่งเป้าระบบซึ่งเปิด Management interface สู่อินเทอร์เน็ต

สถานะ: Active exploitation observed; fixes availableเผยแพร่: 25 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ประกาศ PAN-SA-2026-0015 ระบุว่า Fragnesia เป็นช่องโหว่ยกระดับสิทธิ์ใน Linux kernel และวิธีโจมตีที่ทราบต้องเริ่มจากการใช้ PHP2Shell ผ่าน Management interface ที่เข้าถึงจากอินเทอร์เน็ต ผู้ผลิตไม่ทราบวิธีโจมตีอื่น และให้รายการรุ่น PAN-OS ที่แก้ไขแล้วแยกตามสายผลิตภัณฑ์

ผลกระทบ

หากผู้โจมตีเข้าถึง Management interface และใช้ช่องโหว่ในห่วงโซ่สำเร็จ อาจยกระดับสิทธิ์เป็นระดับสูงสุดบนอุปกรณ์ ส่งผลต่อการตั้งค่า Firewall และความปลอดภัยของเครือข่ายที่อุปกรณ์ควบคุม

ข้อเสนอแนะ

ตรวจสอบรุ่นกับตารางแก้ไขใน PAN-SA-2026-0015 และอัปเดตทันทีหาก Management interface เข้าถึงจากอินเทอร์เน็ต จำกัดการบริหารให้เฉพาะ Trusted internal IP และตรวจ Log สำหรับการเข้าถึงหรือคำสั่งผิดปกติ ผู้ผลิตระบุว่าระบบที่แก้ PHP2Shell ตามประกาศ CVE-2026-109618 แล้วได้รับการป้องกันจากเส้นทางที่ทราบ

2. Drupal ออกแพตช์ฉุกเฉิน CVE-2026-136716 หลังพบการใช้โจมตีจริง

Drupal CoreCVE-2026-136716Active Exploitation

Drupal Security Team เปิดเผยช่องโหว่ Access bypass ระดับ Highly Critical ใน Drupal core ซึ่งอาจนำไปสู่การยึดเว็บไซต์ที่อยู่ในสถานะติดตั้งไม่สมบูรณ์ และยืนยันว่าพบการใช้โจมตีจริง

สถานะ: Active exploitation; security updates availableเผยแพร่: 25 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

SA-CORE-2026-019 ระบุว่าบางเว็บไซต์ยังคงมี install.php เข้าถึงได้จากระยะไกลหลังการแก้ SA-CORE-2026-017 ทำให้เว็บไซต์ที่อยู่ในสถานะผิดปกติหรือไม่สมบูรณ์ยังอาจถูกยึดได้ รุ่นที่ได้รับผลกระทบคือ Drupal ต่ำกว่า 10.6.23, รุ่น 11.0.0 ถึงต่ำกว่า 11.3.23 และรุ่น 11.4.0 ถึงต่ำกว่า 11.4.14

ผลกระทบ

การโจมตีอาจทำให้ผู้ไม่หวังดีข้ามการควบคุมการเข้าถึงและยึดเว็บไซต์ รวมถึงเปลี่ยนบัญชีผู้ดูแลหรือใช้เว็บไซต์เป็นฐานโจมตีต่อไป เว็บไซต์ที่ถูกยึดแล้วอาจไม่แสดงสถานะเสี่ยงอย่างชัดเจนในหน้าจอผู้ดูแล

ข้อเสนอแนะ

อัปเดตเป็น Drupal 10.6.23, 11.3.23 หรือ 11.4.14 ตามสายรุ่น จากนั้นรัน update.php และปิดการเข้าถึง Installer ตามคำแนะนำ ตรวจ Log และการเปลี่ยนแปลงบัญชี user 1 โดยเฉพาะอีเมลกับรหัสผ่าน หากพบหลักฐานผิดปกติให้ดำเนิน Incident response เต็มรูปแบบ

Drupal Security Advisory SA-CORE-2026-019

3. Danfoss เตือนช่องโหว่ไม่ต้องยืนยันตัวตนในระบบควบคุมความเย็น AK-SM 8xxA

Danfoss AK-SM 8xxACVE-2026-129713ICS

Danfoss เปิดเผย CVE-2026-129713 ระดับ Critical (CVSS 9.3) ใน CGI handler ของ AK-SM 8xxA ซึ่งอาจทำให้หน่วยความจำเสียหาย Web server รีสตาร์ต และอาจรันโค้ดด้วยสิทธิ์ของ Web server โดยยังไม่มีแพตช์ในขณะนี้

สถานะ: Unpatched; mitigation required; fix planned for 5.5.xเผยแพร่: 24–25 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่ Stack-based buffer overflow กระทบ AK-SM 8xxA รุ่น 5.4.0 และต่ำกว่า ผู้โจมตีจากระยะไกลสามารถส่ง HTTP/S POST ที่สร้างขึ้นเฉพาะโดยไม่ต้องยืนยันตัวตน ผู้ผลิตวางแผนแก้ไขในซอฟต์แวร์ 5.5.x และไม่ได้ระบุว่าพบการใช้ CVE นี้โจมตีจริง

ผลกระทบ

อุปกรณ์ดังกล่าวใช้บริหารระบบทำความเย็น HVAC และแสงสว่างในธุรกิจอาหาร หากระบบ Web service หยุดทำงานหรือถูกควบคุม อาจกระทบการเฝ้าระวังอุณหภูมิและการดำเนินงานของสถานประกอบการ

ข้อเสนอแนะ

นำอุปกรณ์ออกจาก Public IP ให้ Remote access ผ่าน VPN หรือเครือข่ายป้องกันเท่านั้น เปิด Strict mode ใช้รหัสผ่านรัดกุม แยกเครือข่ายควบคุมจากเครือข่ายสำนักงาน และติดตามซอฟต์แวร์ 5.5.x จาก Danfoss โดยตรง

Danfoss Security Advisory DSA-2026-12-01BleepingComputer

4. 1Password เปิดเผยเหตุผู้โจมตีใช้บัญชี GitHub พนักงานแทรกโค้ดอันตรายสู่ Backend

1PasswordGitHub AccountCustomer Data

1Password ระบุว่าผู้โจมตีเข้าถึงบัญชี GitHub ของพนักงานและใช้สิทธิ์ดังกล่าวแตะต้อง Source code กับ CI/CD ก่อนผลักโค้ดอันตรายไปยัง Backend เพื่อดาวน์โหลดข้อมูลบัญชีของลูกค้าบางส่วน

สถานะ: Contained; credentials rotated; investigation ongoingเผยแพร่: 25–26 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ข้อมูลที่ถูกคัดลอกสำหรับผู้ใช้บางส่วนรวมชื่อ อีเมล รหัสระบุบัญชี เวลาเปิดบัญชีและ Sign-in ล่าสุด Public key พารามิเตอร์ SRP และ Token ในลิงก์เชิญหรือกู้คืนบางประเภท บริษัทปิดบัญชี GitHub ที่ได้รับผลกระทบ เพิกถอน Token และหมุนเวียนข้อมูลรับรองภายในแล้ว

ผลกระทบ

1Password ยืนยันว่า Vault, รายการใน Vault, Account password, Secret Key และกุญแจป้องกัน Vault ไม่ถูกเข้าถึง อย่างไรก็ตามข้อมูลบัญชีที่รั่วไหลอาจถูกใช้ทำ Phishing ที่อ้างการเชิญใช้งานหรือกู้คืนบัญชี

ข้อเสนอแนะ

ระวังอีเมล ข้อความ หรือโทรศัพท์ที่อ้าง 1Password โดยเฉพาะการกู้คืนบัญชีและคำเชิญ ห้ามเปิดเผย Account password หรือ Secret Key และเข้าผ่านแอปหรือพิมพ์เว็บไซต์ทางการด้วยตนเอง องค์กรควรแจ้งผู้ใช้ที่เกี่ยวข้องและตรวจคำขอกู้คืนที่ผิดปกติ
