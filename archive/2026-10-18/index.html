CRITICAL

1. Credential ของ ConnectWise Cloud Backup ถูกใช้เข้าถึง Microsoft 365 หลายองค์กร

Supply ChainMicrosoft 36517 ต.ค. 2569

ConnectWise ยืนยันการเข้าถึง Application Identity โดยไม่ได้รับอนุญาต ขณะที่ Huntress พบการ Sign-in สำเร็จมากกว่า 300 Tenant และพฤติกรรมเพิ่มสิทธิ์หรือสร้าง Credential เพื่อคงการเข้าถึงในบาง Tenant

สถานะ: เร่งด่วนการดำเนินการ: ตรวจสอบตาม Advisory
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ConnectWise ปิดการเข้าถึง Cloud Backup และแอปที่เกี่ยวข้องระหว่างสอบสวน เหตุการณ์เกี่ยวข้องกับ ConnectWise Cloud Backup เดิมชื่อ SkyKick ซึ่งมีสิทธิ์เข้าถึง Mailbox, OneDrive, SharePoint, Teams และ Directory ตามสิทธิ์ที่ลูกค้าเคยอนุมัติ Huntress ระบุว่าพบกิจกรรม Sign-in จากแหล่งที่เกี่ยวข้องเกือบ 1,000 Tenant และมากกว่า 300 รายการสำเร็จ แต่การ Sign-in สำเร็จไม่ได้ยืนยันว่าข้อมูลทุก Tenant ถูกเข้าถึงหรือขโมย

ผลกระทบ

ผู้โจมตีที่ถือ Credential ของแอปอาจใช้สิทธิ์เดิมของ Service Principal เข้าถึงข้อมูล Cloud และในบางกรณีเพิ่ม Credential ให้แอปอื่นเพื่อคงอยู่ในระบบ การโจมตีแบบ App-only อาจไม่ถูก MFA ของผู้ใช้สกัดกั้น

ข้อเสนอแนะ

ปิดใช้งานแอป ConnectWise ที่ผู้ผลิตและ Huntress ระบุจนกว่าจะมีคำยืนยันให้เปิดใหม่ ตรวจ Service Principal Sign-in, Directory Role, OAuth Grant และ Credential ที่ถูกเพิ่มตั้งแต่ 15 ตุลาคม ลบ Credential ที่ไม่รู้จักและประสานผู้ให้บริการเพื่อยืนยันความสมบูรณ์ของ Backup และ Restore

2. พบการโจมตี Langflow CVE-2026-105740 เพิ่มขึ้นอย่างรวดเร็ว

CVE-2026-105740Active Exploitation17 ต.ค. 2569

Previdian ตรวจพบความพยายามโจมตี CVE-2026-105740 จำนวน 2,039 ครั้งในช่วงเจ็ดวัน โดยเพิ่มขึ้น 2,005 ครั้งและยังพบกิจกรรมล่าสุดเมื่อ 17 ตุลาคม ช่องโหว่นี้มี CVSS 9.9 และเปิดให้ผู้ใช้ที่ผ่านการยืนยันตัวตนรันคำสั่งบน Server ได้

สถานะ: เร่งด่วนการดำเนินการ: ตรวจสอบตาม Advisory
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่อยู่ใน MCP Stdio Transport ของ Langflow ซึ่งนำคำสั่งที่ผู้ใช้กำหนดไปเรียกผ่าน Shell โดยไม่มีการตรวจสอบที่เพียงพอ GitHub Advisory ระบุว่ากระทบ Langflow 1.8.3 และแก้ไขใน 1.9.0 ส่วน Previdian จัดสถานะว่าพบการโจมตีจริงด้วยความเชื่อมั่นยืนยันแล้ว แต่ยังไม่อยู่ใน CISA KEV ณ เวลารายงาน

ผลกระทบ

บัญชีผู้ใช้ทั่วไปของ Langflow ที่ถูกยึดหรือถูกสร้างโดยมิชอบอาจรันคำสั่ง อ่านหรือแก้ไขไฟล์ ขโมย Environment Variable สร้าง Backdoor และเคลื่อนย้ายไปยังระบบภายในตามสิทธิ์ของบริการ

ข้อเสนอแนะ

อัปเดต Langflow เป็น 1.9.0 หรือใหม่กว่าทันที จำกัดการเข้าถึงระบบจากอินเทอร์เน็ต ตรวจ MCP Server Configuration, Process, Environment และ Log สำหรับคำสั่งผิดปกติ หมุนเวียน Secret หรือ API Key ที่ระบบสามารถเข้าถึงได้หากพบหลักฐานการโจมตี

สถานการณ์

WordPress เปิดเผยและแก้ไขช่องโหว่ตั้งแต่เดือนกรกฎาคม โดย CVE-2026-63030 กระทบ WordPress 6.9.0–6.9.4 และ 7.0.0–7.0.1 เมื่อใช้ร่วมกับ CVE-2026-60137 อาจนำไปสู่ Remote Code Execution รุ่นแก้ไขคือ 6.9.5 และ 7.0.2 และมีการเปิด Forced Auto-update สำหรับรุ่นที่ได้รับผลกระทบ

ผลกระทบ

เว็บไซต์ที่ยังไม่อัปเดตอาจถูกยึด แก้ไขเนื้อหา ติดตั้ง Web shell ขโมยฐานข้อมูล หรือใช้เป็นฐานโจมตีต่อไปยังผู้ใช้งานและระบบภายใน

ข้อเสนอแนะ

ตรวจยืนยันรุ่น WordPress จริงแทนการสมมติว่า Auto-update สำเร็จ อัปเดตเป็น 6.9.5, 7.0.2 หรือรุ่นที่ใหม่กว่า ตรวจ Core File, Theme, Plugin, ผู้ดูแลระบบ และ Web Log เพื่อค้นหาความผิดปกติ พร้อมเปลี่ยน Credential หากพบการบุกรุก
