1. Linux Kernel CVE-2026-98432 เปิดทาง Zero-click Remote Code Execution บน MPTCP Server

CVE-2026-98432Linux KernelMPTCP

Anthropic สาธิตการส่ง Packet ไปยัง MPTCP Listener เพื่อรันคำสั่งเป็น Root โดยไม่ต้องมี Credential หรือ User Interaction; ช่องโหว่ถูกแก้และ Backport แล้ว

สถานะ: เร่งดำเนินการเผยแพร่: Anthropic เผยแพร่ 27 ต.ค.; รายงานทางเทคนิคแพร่หลาย 30 ต.ค. 2569

สถานการณ์

Anthropic เปิดเผยการสาธิตช่องโหว่ CVE-2026-98432 ซึ่งเป็น Race Condition ที่ทำให้เกิด Use-After-Free ใน Linux Kernel Networking Stack ผู้โจมตีจากระยะไกลสามารถส่ง Packet ไปยัง Server ที่เปิด Multipath TCP Listener เพื่อหลบ KASLR และรันคำสั่งในสิทธิ Root โดยไม่ต้องยืนยันตัวตนหรือให้ผู้ใช้ดำเนินการ ช่องโหว่ได้รับการแก้ใน Upstream และ Backport ไปยัง Stable Kernel ที่ยังได้รับการดูแลแล้ว

ผลกระทบ

ระบบที่เปิด MPTCP Listener อาจถูกยึดควบคุมระดับ Root จากระยะไกลภายใต้เงื่อนไขที่งานวิจัยสาธิต สำหรับ TCP ปกติพบว่าช่องโหว่มีผลเช่นกัน แต่ยังไม่มีการสาธิต Remote Code Execution ในรายงานเดียวกัน Red Hat ประเมินความซับซ้อนและผลกระทบต่ำกว่าคะแนน Upstream

ข้อเสนอแนะ

ตรวจสอบ Kernel และสถานะ MPTCP Listener ด้วยเครื่องมือของระบบ อัปเดต Security Kernel จากผู้ดูแล Distribution โดยเร็ว จำกัดการเข้าถึง Service ที่ใช้ MPTCP จากอินเทอร์เน็ต และติดตามคำแนะนำของ Distribution แทนการอ้างอิงเพียง Version Number ทั่วไป
