1. N-able ปิด N-central Hosted ชั่วคราวหลังมีการเปิดเผยช่องโหว่ Able2Shell

N-able N-centralRMMAble2Shell

มีการเผยแพร่ช่องโหว่ที่รายงานว่าเชื่อมต่อกันเป็น Exploit Chain เพื่อ Remote Code Execution และยกระดับสิทธิ Root; N-able ปิด Hosted Environment ชั่วคราวและสั่งลูกค้า On-premises ให้ปิดระบบระหว่างจัดทำ Hotfix

สถานะ: เร่งตรวจคำแนะนำล่าสุดก่อนเปิดระบบเผยแพร่: N-able / Huntress 9 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

นักวิจัยเผยแพร่รายละเอียดช่องโหว่ 33 รายการใน N-able N-central ซึ่ง Huntress ระบุว่าสามารถเชื่อมต่อเป็น Exploit Chain สี่แบบ โดยสามแบบนำไปสู่ Remote Code Execution และหนึ่งแบบยกระดับสิทธิเป็น Root N-able ปิด Hosted N-central ชั่วคราวและแนะนำให้ลูกค้า On-premises ปิด Server จนกว่าจะมีคำยืนยันว่าปลอดภัย บริษัทระบุ ณ เวลารายงานว่ายังไม่พบหลักฐานการโจมตีจริงหรือการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต

ผลกระทบ

N-central เป็นระบบ Remote Monitoring and Management ที่มีสิทธิควบคุม Endpoint จำนวนมาก หากถูกยึดอาจเปิดทางให้ผู้โจมตีควบคุมระบบของ MSP และลูกค้าหลายองค์กรจากศูนย์กลาง ความเสี่ยงจึงสูงแม้ยังไม่มีหลักฐานการโจมตีจริง

ข้อเสนอแนะ

คง N-central Server แบบ On-premises ไว้ Offline จนกว่า N-able จะออกคำแนะนำล่าสุดและ Hotfix ที่ผ่านการตรวจสอบ ห้ามนำระบบกลับออนไลน์จากข้อมูลเก่า สำรวจ Account ผู้ดูแล การเปลี่ยนรหัสผ่าน การสร้าง Account ใหม่ และ Command/Process ผิดปกติ พร้อมเตรียมหมุนเวียน Credential ที่ N-central ใช้เชื่อมต่อระบบลูกค้า

2. พบความพยายามโจมตี CVE-2026-123158 เพื่อข้ามการยืนยันตัวตน OpenSSH

CVE-2026-123158OpenSSHActive Exploitation

Previdian ยืนยันการตรวจพบความพยายามโจมตี OpenSSH บน Linux ที่ใช้ musl โดยไม่ใช้ PAM; ช่องโหว่อาจทำให้บัญชีบางรูปแบบยอมรับรหัสผ่านที่ยาวผิดปกติ

สถานะ: พบ Exploitation Attempts; เร่งอัปเดตเผยแพร่: Previdian อัปเดต 9 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Previdian รายงานการตรวจพบความพยายามโจมตี CVE-2026-123158 จำนวน 20 ครั้งจาก 13 แหล่งใน 9 ประเทศ ระหว่าง 6–8 พฤศจิกายน ช่องโหว่กระทบ OpenSSH ก่อน 10.6p2 บน Linux ที่ใช้ musl libc โดยไม่ใช้ PAM และอาจทำให้บัญชีบางรูปแบบยอมรับรหัสผ่านยาวผิดปกติ หลักฐานดังกล่าวยืนยันความพยายามโจมตี แต่ไม่ได้ยืนยันว่าเป้าหมายทุกแห่งมีช่องโหว่หรือถูกยึดสำเร็จ

ผลกระทบ

หากระบบตรงตามเงื่อนไขและเปิด SSH สู่อินเทอร์เน็ต ผู้โจมตีอาจข้ามการยืนยันตัวตนและได้สิทธิของบัญชีเป้าหมาย ซึ่งอาจนำไปสู่การรันคำสั่ง ขโมย Credential หรือสร้าง Persistence บน Linux Server

ข้อเสนอแนะ

อัปเดต OpenSSH เป็น 10.6p2 หรือแพ็กเกจที่ Distribution แก้ไขแล้วทันที หากยังทำไม่ได้ให้ปิด PasswordAuthentication หรือจำกัด SSH ผ่าน VPN/Allowlist ตรวจ Authentication Log สำหรับรหัสผ่านยาวผิดปกติและการ Login ของบัญชีที่ไม่ควรใช้ Password พร้อมแยกและตรวจพิสูจน์ระบบที่สงสัย

Previdian อัปเดต 9 พ.ย. 2569

York University แจ้งเหตุผู้ไม่หวังดีเข้าถึง Web Form ของหลายหน่วยงานและขโมยข้อมูลส่วนบุคคลที่ใช้สำหรับการลงทะเบียน การสมัครที่พัก แบบสำรวจ และงานมหาวิทยาลัยอื่น ๆ เหตุถูกตรวจพบเมื่อ 25 ตุลาคม และมหาวิทยาลัยได้ควบคุมระบบพร้อมว่าจ้างผู้เชี่ยวชาญสอบสวน

ผลกระทบ

ข้อมูลที่ได้รับผลกระทบแตกต่างกันในแต่ละบุคคล โดยส่วนใหญ่เป็น York ID และข้อมูลติดต่อ แต่บางรายมี Government ID หรือข้อมูลบัญชีการเงิน มหาวิทยาลัยระบุว่ายังไม่พบหลักฐานว่าผู้โจมตีเข้าถึงระบบ IT ส่วนอื่นนอกเหนือจาก Web Form ที่ได้รับผลกระทบ

ข้อเสนอแนะ

ผู้ได้รับแจ้งควรระวังอีเมล โทรศัพท์ และข้อความที่ขอข้อมูลส่วนบุคคล ตรวจบัญชีการเงิน ใช้รหัสผ่านไม่ซ้ำและเปิด MFA ผู้ที่ได้รับข้อเสนอ Credit Monitoring ควรลงทะเบียนตามช่องทางทางการ ส่วนองค์กรควรทบทวน Retention ของข้อมูลใน Web Form และแยกข้อมูลอ่อนไหวออกจากระบบรับแบบฟอร์มทั่วไป
