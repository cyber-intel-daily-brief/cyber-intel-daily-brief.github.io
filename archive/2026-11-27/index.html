1. Mitel MiCollab ถูกใช้โจมตีก่อนมีแพตช์และขยายผลถึง Active Directory

Mitel MiCollabZero-day ExploitationActive Directory

Accenture APEX Labs ประเมินด้วยความเชื่อมั่นสูงว่าผู้โจมตีใช้ช่องโหว่หลายรายการใน Mitel MiCollab ก่อน Mitel เผยแพร่แพตช์ โดยพบ Web shell ก่อนประกาศและการขยายผลจากระบบ MiCollab ไปยัง Active Directory อย่างรวดเร็ว

สถานะ: Pre-patch exploitation confirmed; fixes available; threat hunting requiredเผยแพร่: 25–26 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

MISA-2026-0012 ครอบคลุม CVE-2026-133275, CVE-2026-133303, CVE-2026-133311, CVE-2026-133323 และ CVE-2026-133324 ใน AWV component ของ MiCollab 10.3 (10.3.0.18) และต่ำกว่า Accenture พบการยึด Web shell ภายในประมาณ 12 นาทีและหลักฐานว่ากิจกรรมเริ่มก่อน Mitel ออกประกาศวันที่ 16 พฤศจิกายน

ผลกระทบ

ในเหตุที่ยืนยัน ผู้โจมตีใช้เวลาประมาณ 20 นาทีจาก Web shell ไปสู่สิทธิ์ Root และบัญชี Active Directory ทำให้การยึด MiCollab ต้องพิจารณาเป็นเหตุที่อาจกระทบระบบตัวตนและข้อมูลธุรกิจ ไม่ใช่เพียง Application server เครื่องเดียว

ข้อเสนอแนะ

อัปเกรดเป็นรุ่นที่ Mitel รองรับและติดตั้งแพตช์สำหรับ 10.3.0.18 หรือใหม่กว่า จำกัดการเข้าถึง AWV component และทำ Threat hunting ย้อนหลังแม้ติดตั้งแพตช์แล้ว ตรวจ Web shell, Process, Account และการเชื่อมต่อจาก MiCollab ไปยัง Domain Controller หากพบหลักฐานให้แยกระบบและหมุนเวียน Credential ที่เกี่ยวข้อง

2. CISA ยืนยันการใช้ช่องโหว่ Juniper Session Smart Conductor โจมตีจริง

Juniper Session SmartCVE-2026-103406CISA KEV

CISA เพิ่ม CVE-2026-103406 ใน Known Exploited Vulnerabilities Catalog หลังพบหลักฐานการใช้โจมตี ช่องโหว่นี้เปิดให้ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนรันคำสั่งบน Session Smart Conductor ได้

สถานะ: Active exploitation confirmed by CISA; fixes availableเผยแพร่: 25–26 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Juniper จัดช่องโหว่นี้ระดับ Critical CVSS 9.8 กระทบ Session Smart Conductor ก่อนรุ่น 7.0.5, 7.1.7 และ 7.2.3 โดยเกิดในกระบวนการ Key management ประกาศเดิมระบุว่ายังไม่พบการโจมตี แต่การเพิ่มเข้า CISA KEV วันที่ 25 พฤศจิกายนเป็นหลักฐานใหม่ว่ามีการใช้จริง

ผลกระทบ

การรันคำสั่งโดยไม่ต้องยืนยันตัวตนอาจนำไปสู่การควบคุมระบบบริหารเครือข่ายด้วยสิทธิ์สูง กระทบความลับ ความถูกต้อง และความพร้อมใช้ของระบบ Routing ที่อยู่ภายใต้การบริหาร

ข้อเสนอแนะ

อัปเดตเป็น 7.0.5, 7.1.7, 7.2.3 หรือรุ่นใหม่กว่าตามสายผลิตภัณฑ์ จำกัดหน้า Management ให้เข้าถึงเฉพาะเครือข่ายที่เชื่อถือได้ ตรวจ Command, Account และการเปลี่ยนแปลง Key management ย้อนหลัง และหากพบหลักฐานผิดปกติให้ปฏิบัติเป็นเหตุยึดระบบระดับ Root

3. พบความพยายามใช้ช่องโหว่ GeoServer ที่เชื่อมเป็นห่วงโซ่ RCE โดยไม่ยืนยันตัวตน

GeoServerActive ExploitationUnauthenticated RCE Chain

หน่วยงาน Cyber Centre ของแคนาดาและงานวิจัย watchTowr รายงานกิจกรรมโจมตีช่องโหว่ GeoServer หลายรายการ ซึ่งสามารถเชื่อมต่อกันเพื่ออ่านไฟล์ ข้ามกฎบริการ ปลอม Session ผู้ดูแล และนำไปสู่ Remote code execution

สถานะ: Exploitation activity observed; patched releases availableเผยแพร่: 25–26 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

กิจกรรมเกี่ยวข้องกับช่องโหว่ในห่วงโซ่ ได้แก่ CVE-2026-120705 และ CVE-2026-129243 พร้อมช่องโหว่อื่นที่ GeoServer อธิบายในประกาศเดียวกัน โครงการ GeoServer ออกแพตช์เป็น 3.0.2, 2.28.6 และ 2.27.7 ส่วน watchTowr ระบุว่าพบการ Probe เพื่อยืนยันระบบที่มีช่องโหว่ แต่ไม่เปิดเผย Attribution

ผลกระทบ

ห่วงโซ่อาจทำให้ผู้โจมตีเข้าถึงไฟล์ภายใน ทำ SSRF ข้ามข้อจำกัดบริการ ปลอม Administrator session และรันโค้ดบน Server หากระบบยังใช้รุ่นที่ไม่ได้แก้ไข

ข้อเสนอแนะ

อัปเดต GeoServer เป็น 3.0.2, 2.28.6 หรือ 2.27.7 ตามสายรุ่น ตรวจ Stored query, JDBC user/role service และ Administrator session ที่ไม่ได้สร้างโดยผู้ดูแล หากยังอัปเดตไม่ได้ให้บล็อกค่า service ที่มีเครื่องหมาย Slash และปิด Remember-me ชั่วคราวตามคำแนะนำโครงการ

สถานการณ์

แคมเปญเริ่มพบตั้งแต่ 16 ตุลาคมและยังดำเนินอยู่ โดยติดตั้งโปรแกรม Wallpaper ที่ใช้งานได้จริงควบคู่กับองค์ประกอบอันตราย Extension รองรับ Chrome, Edge และ Firefox และใช้กลไกบริหาร Browser กับ Device เพื่อบังคับติดตั้งและทำให้ผู้ใช้ถอนออกได้ยาก Bitdefender พบ Traffic จากหลายประเทศและประเทศไทยอยู่ในกลุ่มที่พบปริมาณสูง

ผลกระทบ

5. Remus Stealer ปลอมเป็น Google Sheets Extension เพื่อขโมยข้อความ Gmail

Remus StealerChrome ExtensionGmail Theft

Gen Threat Labs ยืนยันว่าความสามารถที่ผู้พัฒนา Remus อ้างว่าเป็น Gmail Zero-day แท้จริงเกิดจาก Extension อันตรายที่ติดตั้งเงียบใน Chrome และอ่านอีเมลจาก Session ที่ผู้ใช้ลงชื่อเข้าใช้อยู่

สถานะ: Malware capability confirmed; no Gmail zero-day verifiedเผยแพร่: 24–26 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Remus แก้ไข Chrome profile เพื่อเพิ่ม Extension แบบ Unpacked และเปิด Developer mode โดยปลอมชื่อ Google Sheets กับคำอธิบายจาก Google Docs Offline Extension ตรวจอีเมลที่ยังไม่อ่านเป็นระยะและส่งหัวข้อ เนื้อหา ผู้ส่ง กับที่อยู่อีเมลไปยัง Command-and-control

ผลกระทบ

การเปลี่ยนรหัสผ่านหรือเพิกถอน Session เพียงอย่างเดียวอาจไม่ลบ Extension ที่ฝังอยู่ เมื่อผู้ใช้ลงชื่อเข้าใช้ใหม่ ความสามารถขโมยอีเมลอาจกลับมาทำงาน จึงเสี่ยงต่อข้อมูลธุรกิจ Reset link และข้อความยืนยันตัวตน

ข้อเสนอแนะ

ตรวจ chrome://extensions หา Extension ที่ไม่รู้จัก ตรวจการเปิด Developer mode โดยไม่ได้ตั้งใจ ลบ Extension และ Malware ต้นเหตุจากเครื่องก่อนเปลี่ยนรหัสผ่านหรือเพิกถอน Session ใช้ซอฟต์แวร์จากแหล่งทางการและตรวจ Browser policy ที่ผิดปกติ

6. พบแพ็กเกจ NuGet อันตราย 13 รายการในแบบทดสอบสมัครงาน .NET ปลอม

NuGetFake Job AssessmentDeveloper Targeting

Socket พบแพ็กเกจ NuGet อันตราย 13 รายการที่ใช้ในแบบทดสอบสมัครงานปลอมสำหรับนักพัฒนา Windows .NET โดยการ Build หรือ Run โครงการอาจดาวน์โหลด Payload จาก GitHub ทำ DLL side-loading หรือรันไฟล์อันตราย

สถานะ: Packages identified; most removed; developer endpoints remain at riskเผยแพร่: 23–26 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

แพ็กเกจส่วนใหญ่ปลอมเป็น Control สำหรับ WinUI 3 และ WPF โครงการล่อกำหนดให้ผู้สมัคร Build ด้วย Visual Studio บน Windows และห้ามแก้ส่วนของ Control ที่เป็นตัวกระตุ้น Payload Socket ระบุว่า 12 รายการถูกนำออกแล้วขณะเผยแพร่งานวิจัย และหนึ่งรายการยังอยู่ ณ เวลาดังกล่าว

ผลกระทบ

ข้อเสนอแนะ

ห้ามทำแบบทดสอบสมัครงานที่ไม่ผ่านการตรวจบนเครื่ององค์กร ใช้ VM หรือ Sandbox แยก ตรวจ NuGet dependency และ Script ก่อน Build ค้นหาแพ็กเกจตามรายชื่อในรายงาน Socket พร้อมตรวจ GitHub download, DLL side-loading รอบ osk.exe และหมุนเวียน Credential หากพบการรัน
