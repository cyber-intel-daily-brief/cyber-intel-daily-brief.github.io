2. ไฟล์ติดตั้ง Q-Dir และ DesktopOK จากเว็บไซต์ทางการถูกฝัง Python RAT

Q-Dir / DesktopOKSupply ChainPython RAT

AhnLab ASEC ยืนยันว่าพบไฟล์ติดตั้ง Q‑Dir และ DesktopOK บางรุ่นจากเว็บไซต์ SoftwareOK ถูกดัดแปลง รวมถึงพบการสร้างไฟล์อันตรายระหว่างกระบวนการอัปเดตของโปรแกรมที่ติดตั้งอยู่แล้ว

สถานะ: Trojanized installers confirmed; infection review requiredเผยแพร่: 27 พ.ย. 2569

สถานการณ์

ไฟล์ที่ถูกดัดแปลงเปิดโปรแกรมจริงเพื่อหลบการสังเกต พร้อมดาวน์โหลด Python-based RAT ซึ่งรองรับการรันคำสั่ง ส่งและรับไฟล์ จับภาพหน้าจอ และเก็บข้อมูลระบบ ASEC ยืนยันรุ่นที่พบ ได้แก่ Q‑Dir 12.83.0.0–12.85.0.0 และ DesktopOK 12.82.0.0 กับ 12.85.0.0 แต่ยังไม่ยืนยันสาเหตุที่ช่องทางแจกจ่ายถูกแก้ไข

ผลกระทบ

ผู้ใช้ที่ดาวน์โหลดหรืออัปเดตผ่านช่องทางทางการในช่วงที่ได้รับผลกระทบอาจติด RAT แม้โปรแกรมหลักยังทำงานตามปกติ เครื่องปลายทางอาจถูกควบคุม ขโมยข้อมูล หรือใช้เป็นจุดเริ่มต้นขยายผลเข้าสู่ระบบภายใน

ข้อเสนอแนะ

ตรวจรุ่นและ Hash ของไฟล์ที่ดาวน์โหลดจาก SoftwareOK ค้นหา Scheduled task และ Python runtime ตาม IOC ที่ ASEC เผยแพร่ และตรวจการเชื่อมต่อภายนอกย้อนหลัง การถอนโปรแกรมอย่างเดียวอาจไม่ลบ RAT หากพบหลักฐานให้แยกเครื่อง อัปเดต Endpoint protection และประเมิน Credential ที่เคยใช้งานบนเครื่องนั้น

4. Linux NFS2ROOT อาจทำให้ผู้โจมตีระยะไกลได้สิทธิ์ Root บน NFS Server

Linux KernelCVE-2026-99362NFSv4.1 / NFSv4.2

Linux Kernel CVE Team และ Red Hat เปิดเผย CVE‑2026‑99362 ซึ่งเป็น Out-of-bounds write ใน nfsd ผู้โจมตีที่ไม่ผ่านการยืนยันตัวตนอาจทำให้ Kernel crash หรืออาจรันโค้ดได้ โดยมี PoC เผยแพร่แล้ว

สถานะ: Critical vulnerability; public PoC; fixes availableเผยแพร่: 26–27 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่เกิดระหว่างการจัดการ SEQUENCE reply ของ NFSv4.1 และ NFSv4.2 เมื่อ Server ยอมรับขนาด Cached reply ที่เล็กเกินไป Red Hat ให้คะแนน CVSS 9.4 และระบุว่าการติดตั้งตามค่าเริ่มต้นซึ่งไม่ได้เปิด nfsd ไม่อยู่ในพื้นผิวโจมตีนี้

ผลกระทบ

ระบบที่เปิด NFS Server ให้เครือข่ายที่ไม่น่าเชื่อถือเข้าถึงอาจเกิด Memory corruption, Kernel panic และหยุดให้บริการ หรืออาจถูกยึดด้วยสิทธิ์ Root ความเสี่ยงสูงกว่าสำหรับ File server ที่เชื่อมต่อหลายระบบและเก็บข้อมูลร่วม

ข้อเสนอแนะ

อัปเดตเป็น Linux Kernel รุ่น Stable ล่าสุดตามผู้จัดจำหน่าย หากไม่จำเป็นให้หยุด nfs-server และหากต้องใช้งานให้จำกัด TCP/UDP 2049 เฉพาะ Client ที่เชื่อถือได้ ตรวจ Kernel log และเหตุ Crash ผิดปกติ พร้อมทดสอบผลกระทบต่อ NFS session ก่อนเปลี่ยน Firewall หรือหยุดบริการ

Red Hat — CVE-2026-99362Linux Kernel CVE announcement
