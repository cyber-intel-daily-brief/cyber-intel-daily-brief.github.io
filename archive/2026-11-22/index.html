1. AI Agent ใช้ช่องโหว่ Zero-day ใน MONAI Label ยึด Server ระดับ Root

MONAI LabelAutonomous AIZero-day Exploitation

Amazon Threat Intelligence พบผู้ปฏิบัติการที่เชื่อมโยงกับจีนใช้ Cairn AI agents ค้นพบ Path Traversal ในแอปพลิเคชันภาพการแพทย์ และพัฒนาไปสู่ Reverse Shell สิทธิ์ root ภายในเวลาสั้น

สถานะ: Exploited; Fix released by projectเผยแพร่: 20 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Amazon ระบุว่า Cairn agents ได้รับคำสั่งเพียงให้เข้าถึง Shell จากนั้นสำรวจ API พบพารามิเตอร์ชื่อไฟล์ที่ทำ Path Traversal ได้ และใช้เขียนไฟล์ Python ซึ่งถูกโหลดอัตโนมัติเพื่อเปิด Reverse Shell ระดับ root เหตุการณ์มุ่งเป้าไปยังมหาวิทยาลัยในเอเชียตะวันออกนอกจีน โดย Amazon ประเมินความเชื่อมโยงกับผู้ปฏิบัติการที่ใช้ภาษาจีนในระดับความเชื่อมั่นปานกลาง

ผลกระทบ

ระบบ MONAI Label ที่เปิดรับจากเครือข่ายและยังไม่ได้แก้ไขอาจถูกเขียนไฟล์และยึดควบคุม Server ส่งผลต่อข้อมูลภาพการแพทย์ งานวิจัย และทรัพยากรประมวลผล

ข้อเสนอแนะ

ตรวจสอบประกาศและ GitHub Security Advisory ของโครงการ ติดตั้งรุ่นหรือ Commit แก้ไขที่ผู้ดูแลระบุ จำกัดการเข้าถึง API จากอินเทอร์เน็ต และค้นหาร่องรอยไฟล์ sitecustomize.py หรือ Process Python ที่ผิดปกติ โดยไม่พึ่งการตรวจแบบ Manual เพียงอย่างเดียว

2. Cisco Expressway CVE-2026-76466 ถูกยืนยันการใช้โจมตีจริง

Cisco ExpresswayCVE-2026-76466CISA KEV

CISA เพิ่ม CVE-2026-76466 เข้า Known Exploited Vulnerabilities หลังพบหลักฐานการโจมตีจริง; ช่องโหว่ Hard-coded Credentials อาจเปิดให้ผู้โจมตีจากระยะไกลรันคำสั่งระบบในสิทธิ์ root

สถานะ: Actively Exploited; Patch availableเผยแพร่: 20 พ.ย. 2569 (KEV)
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

Cisco จัดช่องโหว่นี้ระดับ Critical CVSS 9.8 กระทบ Database service ของ Expressway-C และ Expressway-E โดยผู้โจมตีที่เข้าถึงอุปกรณ์ผ่านเครือข่ายสามารถใช้ข้อมูลรับรองที่ฝังไว้เพื่อรันคำสั่งระบบได้ ทั้งนี้ CISA ยืนยันการใช้โจมตีจริงเมื่อ 20 พฤศจิกายน

ผลกระทบ

การยึดอุปกรณ์ Expressway ที่เชื่อมต่อขอบเครือข่ายอาจนำไปสู่การควบคุมระบบ การเข้าถึงบริการสื่อสาร และการเคลื่อนย้ายต่อไปยังเครือข่ายภายใน

ข้อเสนอแนะ

ตรวจ Inventory ของ Expressway-C/E และอัปเกรดเป็นรุ่นแก้ไขตาม Cisco Advisory โดยเร่งด่วน เนื่องจากไม่มี Workaround พร้อมตรวจ Log คำสั่ง การยืนยันตัวตน และการเชื่อมต่อจากต้นทางที่ไม่คุ้นเคยย้อนหลัง

3. Apache Tomcat TLS-PSK บน TLS 1.3 ไม่ตรวจสอบ Peer

Apache TomcatCVE-2026-133325Cluster Security

Apache เปิดเผย CVE-2026-133325 ระดับ Critical ซึ่งทำให้ Node ที่ไม่ผ่านการยืนยันตัวตนเข้าร่วม Cluster ได้ เมื่อใช้ TLS 1.3 ร่วมกับ TLS-PSK

สถานะ: Critical; Mitigation requiredเผยแพร่: 19–21 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ช่องโหว่กระทบ Tomcat 11.0.28–11.0.29, 10.1.62 และ 9.0.124 ภายใต้การตั้งค่า Cluster TLS-PSK ที่ใช้ TLS 1.3 โดยกระบวนการแลกกุญแจไม่ยืนยันตัวตนของ Peer อย่างถูกต้อง

ผลกระทบ

ผู้โจมตีที่เข้าถึงเครือข่าย Cluster อาจเชื่อม Node ที่ไม่ได้รับอนุญาต ส่งผลต่อความลับและความน่าเชื่อถือของข้อมูล Session หรือทราฟฟิกภายใน Cluster

ข้อเสนอแนะ

สลับ Cluster encryption ไปใช้ TLS 1.2 กับ TLS-PSK ชั่วคราว และอัปเกรดเป็น Tomcat 11.0.30, 10.1.63 หรือ 9.0.125 เมื่อเผยแพร่ ระหว่างนี้จำกัด Cluster port เฉพาะเครือข่ายบริหารและตรวจสมาชิก Cluster ที่ไม่รู้จัก

4. Microsoft Entra Connect Health เปิดเผยข้อมูล Tenant จากช่องโหว่ API

Microsoft EntraCloud IdentityConfirmed Breach

Microsoft ยืนยันว่าผู้โจมตีใช้ช่องโหว่ Entra Connect Health API เพื่อเข้าถึงข้อมูลติดต่อผู้ดูแลและข้อมูลกำหนดค่า Tenant แบบอ่านอย่างเดียว ก่อนบริษัทแก้ไขฝั่งบริการเมื่อ 19 พฤศจิกายน

สถานะ: Exploited; Service-side fix deployedเผยแพร่: 21 พ.ย. 2569
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

ข้อมูลที่อาจถูกเข้าถึงประกอบด้วยอีเมลผู้ดูแล Tenant ID ชื่อโดเมน ประเทศ ระดับ License และสถานะ Directory synchronization โดย Microsoft ระบุว่าไม่พบการเปิดเผย Password, Password hash, Authentication token หรือกุญแจเข้ารหัสที่ยังใช้งานได้ และไม่พบการแก้ไข Configuration ที่ไม่ได้รับอนุญาต

ผลกระทบ

แม้ไม่มีข้อมูลรับรองรั่วไหลตามผลสอบสวน ข้อมูลผู้ดูแลและโครงสร้าง Tenant สามารถเพิ่มความแม่นยำของ Phishing และ Social Engineering ที่มุ่งเป้าบัญชีสิทธิ์สูง

ข้อเสนอแนะ

หน่วยงานที่ได้รับ Azure Service Health notification ควรแจ้งทีม SOC เพิ่มการเฝ้าระวัง Phishing กับผู้ดูแล ใช้ MFA แบบต้าน Phishing ตรวจ Entra Audit/Sign-in logs และทบทวน Connect Health configuration

5. SAP NetWeaver CVE-2025-42884 ถูกเพิ่มเข้า CISA KEV

SAP NetWeaverCVE-2025-42884CISA KEV

CISA เพิ่มช่องโหว่ JNDI Injection ใน SAP NetWeaver Enterprise Portal เข้า KEV เมื่อ 20 พฤศจิกายน เนื่องจากมีหลักฐานการใช้โจมตีจริง

สถานะ: Actively Exploited; Vendor patch availableเผยแพร่: 20 พ.ย. 2569 (KEV)
ดูรายละเอียดสถานการณ์ ผลกระทบ และข้อเสนอแนะ

สถานการณ์

SAP ระบุว่าช่องโหว่ CVE-2025-42884 กระทบ EP-BASIS 7.50 และ EP-RUNTIME 7.50 ผู้โจมตีที่ไม่ยืนยันตัวตนอาจแทรกค่า JNDI environment หรือ URL เพื่อชี้ไปยัง JNDI provider ที่ไม่ควรเข้าถึง

ผลกระทบ

อาจนำไปสู่การเปิดเผยหรือแก้ไขข้อมูลของ Server และเพิ่มความเสี่ยงต่อระบบ Portal ที่เปิดให้เข้าถึงจากภายนอก แม้คะแนนพื้นฐานของผู้ผลิตอยู่ระดับ Medium แต่หลักฐานการใช้จริงยกระดับความเร่งด่วน

ข้อเสนอแนะ

ตรวจสอบ SAP Note 3660969 และติดตั้ง Security Note โดยเร็ว จำกัดการเข้าถึง Enterprise Portal จากอินเทอร์เน็ต ตรวจ JNDI lookup และ URL ผิดปกติใน Log พร้อมประเมินการถูกเจาะก่อนติดตั้งแพตช์
